# 视频词工艺细则（段视频 prompt 怎么写）

> `render-contracts.md` §4 是**帧词**（静态定格）的配方，`keyframe-craft.md` 是帧词工艺。
> 本文件是**视频词**（动态分镜脚本）的配方。
> **两者是不同层，规则不同，不要互相套用。**

## 0. 分层禁令（开篇必读，每次写视频词前先看这一条）

| 层 | 文件 | 时间轴 | 动作动词 | 点名 |
|---|---|---|---|---|
| **帧词**（kf1/kf2 出图） | `keyframe-craft.md` | ❌ 禁（静态定格） | ❌ 禁 | 禁点名未出场角色 |
| **视频词**（段视频生成） | 本文件 | ✅ **必须** | ✅ **必须**，且带幅度/速度 | 禁代词、禁群体量词 |

- **视频词禁止整段复用帧词**（帧词没有动作，套上去视频就是静帧漂移）。
- **帧词禁止复用视频词**（`render-contracts.md` §4.10 静态化铁律：两个时刻被拼进同一 prompt
  = 模型复制角色分别演绎两个姿态 = 重复人）。
- 视频词里的**角色形象描述同样只来自 ref**，禁重描五官/发色/服装细节；
  允许的只有**标志色**这一个例外口（见 `render-contracts.md` §4.7 禁令 1）。

## 1. 段内时间轴分拍（`craft_default`，本文件最重要的一条）

### 1.0 术语先定死（否则「拍」是歧义词）

| 词 | 本链路定义 |
|---|---|
| **场（scene）** | 一个连续空间内不切机位的一段戏 |
| **拍（beat）** | **= 一个生成单元 = 一个机位不动的连续时间片**。本链路的「拍」既是节拍也是切点 |
| **切（cut）** | 换机位。**每拍必然带一次切**，因为每拍是独立生成的 |
| **镜（镜头）** | 段视频里的一拍。⚠️ 外部 skill 主张「beat 不等于 cut」，**在我们这里不成立**——我们每拍独立生成，切点是硬事实 |

> 之所以要写死：外部 skill 明确拒绝「强制统一拍数/秒数」，理由是「没有通用规律」。
> **对真人口播成立，对我们不成立**——我们每段是独立任务、下游是固定档位 + 固定 TTS，
> 所以「末拍终点 = duration」必须是可机检的硬事实，不是可以放松的创作建议。

每段视频词按**连续时间拍**写，硬约束三条：

1. **各拍时间码首尾相接**，不重叠、不留空（`0-3s` → `3-6s` → `6-10s`）
2. **末拍终点 = 该段 `duration` 档位秒数**（3/5/10/18），不多不少
3. **每拍必须含三件套**：机位 + 动作 + 声音（缺一即不合格）

```
[10s 段 · 三拍]
0-3s   <中全景，平视>  赤焰立于碑前，右手缓缓抬起按在碑面。
       声音：<环境低频嗡鸣 + 布料摩擦声> 音乐：() 低沉弦乐渐入
3-6s   <近景，缓推>    碑面浮起赤色纹路，自下而上蔓过她的手背。
       声音：<石面共振嗡鸣> 台词：{冰璃：这是……共鸣？}
6-10s  <过肩镜，静止>  赤焰侧脸，视线未离碑面，肩线绷紧。
       声音：<> 远处甲胄摩擦 台词：{赤焰：别动。}
```

**为什么要分拍**（`reviewed_invariant`）：
- 段视频是「一张关键帧 + 一段时间」的运动插值，模型默认会把整段理解成**一个连续动作**，
  动作越长越容易累积漂移/穿模/中途变脸。分拍 = 把长动作切成多个短目标，
  每拍都有明确的「起止姿态」，漂移被限制在一拍之内。
- 时间码首尾相接是**可机检**的（`qa_manifest.sh` 校验末拍终点 = duration）。

**镜头数建议**（与 §3 台词字数预算配套）：

| 段时长 | 镜头数 | 每拍时长 |
|---|---|---|
| 3s | 1-2 | 1.5-3s |
| 5s | 1-2 | 2.5-5s |
| 10s | 2-3 | 3-5s |
| 18s | 3-4 | 4-6s |

## 2. 运动幅度白名单（视频层的安全阀）

**优先（低缓、连续、末端可定姿态）**：
缓慢行走 / 轻轻抬手 / 顺势坐下 / 缓缓转头 / 微微低头 / 收势站定 / 衣摆随动作轻摆

**默认拆镜（大动态，模型不稳）**：
狂奔 / 大跳 / 翻滚 / 摔倒 / 复杂打斗 / 连续多次翻转

- 拆镜判定：动作需要「一次连续完成且中途无可定姿态」→ 拆成两段或换成局部镜头（只拍手/脚/道具）。
- **每个动作词必须带三个修饰**：部位 + 幅度 + 速度。
  - ❌ `她转身` → ✅ `她缓缓向左转身（约 45 度，两秒内完成）`
  - ❌ `他拔剑` → ✅ `他右手向上拔出长剑（半掌距离，缓慢）`
  - 理由：没有幅度的动作词，模型自行决定幅度 → 大概率给一个**大幅度慢动作**（最像定格动画的一种失真）。

## 3. 情绪具象外化（禁抽象情绪词）

禁 `很悲伤` / `非常愤怒` / `十分紧张` / `情绪低落`。改写为身体细节：

| 情绪 | 身体细节写法 |
|---|---|
| 悲伤 | 眼睑下垂，视线下移避开他人，肩线下沉，呼吸幅度变小，喉部吞咽一次 |
| 喜悦 | 眼尾上扬，嘴角先动后带动面颊，肩线抬起，身体重心前移半步 |
| 紧张 | 呼吸变浅变快，指尖收拢，颈侧肌腱可见，瞳孔收缩，视线快速扫过 |
| 愤怒 | 下颌收紧，眉头下压，鼻翼张开，握持物指节发白，肩背上提 |
| 释然 | 呼出一口长气，肩线落下，视线重新聚焦，嘴角极小幅度上扬 |

> **纯机械检查**：`validate_prompt.py` 应能扫出「很/非常/十分/极其 + 情绪词」并报 warn。
> 帧词层因是静态定格，情绪只能靠姿态+光影表达，**禁止写任何情绪词**——同上表但只取姿态部分。

## 4. 受控词表（消除同义漂移）

同一含义只允许一种写法——同义漂移会让模型把三件事当三件事处理。

**景别 7 级**：
大特写 / 特写 / 近景 / 中景 / 中全景 / 全景 / 大远景
> 常用补充：`过肩镜`（两人镜默认用它，优于并排，天然带层级）、`主观视角 POV`

**角度 6 类**：
正面 / 侧面 / 半侧 3-4 / 背面 / 仰拍 / 俯拍 / 平视

**光影 3 维度**：
- 质感：硬光 / 柔光 / 伦勃朗
- 方向：顺光 / 侧光 / 逆光 / 底光
- 色调：暖 / 冷 / 中性

**运镜词表**（只写在【时间轴分镜】层，**不进帧词 `[CAMERA]` 段**）：
- 基础 5 种：推 / 拉 / 摇 / 移 / 升降
- 情绪 4 种：环绕 / 手持感 / 呼吸感 / 希区柯克变焦
- 动作 4 种：甩镜 / 格挡震动 / 子弹时间 / 冲刺跟拍

**机位运动也必须带幅度 + 速度 + 稳定性三档**（P1，抄自 doublesq97-ui `:81`）：

```
✅ 缓推（小幅度·慢速·稳定机位）        ✅ 快速右移（大幅度·快速·稳定机位）
✅ 轻微手持浮动（小幅度·慢速·主观）    ❌ 推镜头
```

- 只对**主体动作**要求三档是不够的——机位运动没幅度，模型会给一个**大幅度慢推**，
  和主体动作的慢速叠加后整段变成定格动画的观感。
- **表演/证据主导的拍用固定机位**（`craft_default`）：这一拍的戏在脸上，不在运镜上。

> ⚠️ **炫技运镜词（希区柯克变焦/子弹时间/甩镜）在本链路慎用**：
> 它们在帧词层是纯噪声（静态图无运镜），在视频层又容易触发剧烈形变。
> 只有剧情强需求 + 该段可重出时才用。

**POV 纪律**：
- POV 镜头**不得出现该角色完整正脸**（否则视角自相矛盾）。
- POV **不得写成**自拍 / 监控画面 / 无人机视角 / 过肩——那些是别的镜头类型。

**转场必写**：每拍末尾标 `[硬切]` / `[叠化]`，末拍转场须与下一段第一拍的 `[接续状态]` 对齐。

## 5. 声音层

- `()` 音乐 / `<>` 音效 / `{}` 台词 / `『』` 旁白（符号契约见 `SKILL.md` §3.1）
- **全局质感连续性**：整集用同一套底噪环境声（该剧的「世界底噪」），
  段与段之间不断层——每段都是独立任务，模型不知道全集基调，必须在每段视频词里**重新声明**。
- ⚠️ 声音信息只影响模型对画面的**运动节奏感**（本链路段视频最终 `-an` 去音轨），
  **不产生可交付音轨**。写它是为了让动作节奏与情绪对齐，不要指望它出现在成片里。

## 6. 视频词末尾固定禁令

```
末尾必带：禁止字幕、禁止文字、禁止 LOGO、禁止水印；
禁止人物面部漂移、禁止服装变化、禁止无关角色乱入；
禁止角色数量变化（同一角色在整段内只出现一次）；
无穿模、无肢体畸变、无中途变脸。
```

> **角色数量变化**这一条是从《花语战歌》重复人事故反向提取的：
> 帧词层用「人数前置 + EXCLUDE」治，视频层因为是运动插值，模型可能在运动中
> 复制出一个「跟着动的人」——所以视频词也要显式禁。

## 7. 事前复杂度预算（`structural_invariant` 的事前形态）

> **与 `skill-optimization-loop.md` §缺陷处置五选的区别**：
> 处置五选是**失败之后**怎么修；本节是**动手之前**就不该开工。
> 两节互补，**不要互相替代**——写成一条是重复，写成两步才是闭环。

**出图/渲影前**用 7 轴过一遍，任一轴超阈就按下表处置，**不许靠加长提示词硬扛**。

| 轴 | 判据 | 本链路阈值 | 超阈处置 |
|---|---|---|---|
| 1 可见身份数 | 同框可辨识角色数 | **≤2**（ref≤2 的必然结果） | 拆镜，或只留视觉主角 |
| 2 说话角色数 | 同段开口人数 | ≤2 | 拆段 |
| 3 接触/交接类动作 | 打斗/进食/**物件转移**/载具/变身 | 同时 ≤1 | 换结构（拆成 before-contact-after） |
| 4 **机位运动 + 主体大幅运动同时发生** | 两者都是「大幅度」 | **禁止同时** | 二选一：改固定机位，或降主体幅度 |
| 5 口型/重叠语音/长对白 | 精确口型或两人同时说话 | 精确口型 = 0 | 移到画外 / 用反应镜代替 |
| 6 可读文字/屏幕/反射/镜面/透明面 | 画面内需要读出字 | **一律 0** | 全部移后期（`mov_text` 软字幕） |
| 7 状态转场 | 换光/换天气/换服装/受伤在同段内 | 同段 ≤1 | 拆段 |

**拍数与硬切数**（第 8 轴，绑定段档位）：

| 段时长 | 上限拍数 | 硬切数上限 |
|---|---|---|
| 3s | 2 | 1 |
| 5s | 2 | 1 |
| 10s | 3 | 2 |
| 18s | 4 | 3 |

**6 条降级选项**（超阈时按此顺序试，**每次都要落台账**）：

1. 改善 ref（换更净的图 / 减到 1 张）— 但**不许**把资产板挂回来
2. 简化走位（blocking）：去掉穿越、去掉背对镜头的移动
3. 减少同时发生的动作数
4. 把「插入镜」（insert）单独成段
5. 拆段（**注意**：拆段会改变总时长与段数，须回 §1 重新配平）
6. 移到后期（文字/字幕/音效/精确口型）

> **铁律**：**绝不用更长的提示词掩盖制作风险**（"Never hide production risk behind a
> longer prompt"）。把风险写长一点，只会让下一次失败失去可比性。

## 8. 机检建议（`craft_default`，未接入前为人工自检）

| 检查项 | 判据 | 级别 |
|---|---|---|
| 末拍终点 == 段 `duration` | 时间码解析 | `structural_invariant` |
| 时间码首尾相接 | 相邻拍 `t_end == t_start` | `structural_invariant` |
| 每拍三件套齐全 | 机位词 + 动作词 + 声音标记 | `reviewed_invariant` |
| 7 轴复杂度预算（§7） | 见 §7 表 | `structural_invariant`（事前） |
| 台词字数 ≤ 段档位预算 | 5-6 字/秒 × duration | `craft_default`（待校准） |
| 抽象情绪词 | `很/非常/十分/极其` + 情绪词 | warn |
| 连续两个 `--` | 疑似外部 skill 所称的模型截断符 | warn（**该断言无出处，待本模型验证**） |
| 炫技运镜词 | 希区柯克/子弹时间/甩镜 | warn（提示成本） |
| 机位运动缺幅度/速度 | 运镜词后无「幅度·速度·稳定性」 | warn |
| **拍点缺少因果句** | 动作描述只有结果无原因（如"她拔剑"无"因为她被攻击"） | warn |
| **声音层未重写** | 未声明该剧的世界底噪（环境音连续性） | warn |
