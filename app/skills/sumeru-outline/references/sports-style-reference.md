# 竞技体育风格参考库
> ⚠️ 合规提示：涉及真实赛事体系（奥运会式、世界杯式）与职业俱乐部时建议虚构化处理（如「环球运动会」「大陆冠军联赛」），或使用已停办的远古赛事背景。

## 题材分类参考
### 热门项目
篮球（团队对抗爽感强）、足球（世界第一运动）、电竞（联动游戏电竞库）、围棋（智力竞技）、乒乓球、羽毛球、网球、游泳、田径（短跑/跨栏）、滑雪冰雪项目、赛车、拳击格斗

### 题材细分
职业联赛文、校园体育文（社团/校队/大赛）、体校成长文、退役复出文、天才陨落再崛起文、教练文、体育经纪人文、残障运动员励志文

## 成长/赛事体系参考
### 运动员晋升线（从低到高）
校队 -> 区县级比赛 -> 市队/青训营 -> 省队 -> 国青队 -> 国家队 -> 洲际大赛 -> 世界之巅
职业线：青训梯队 -> 预备队 -> 一线队首发 -> 核心主力 -> 队长 -> 联赛MVP式个人荣誉 -> 世界大赛冠军

### 虚构赛事名称
全国青少年锦标赛、城市篮球联赛、大陆职业联盟（CBA式虚构：华冠篮球联赛）、洲际冠军杯、环球运动会、世界排球大奖赛式（环球排球巅峰赛）、钻石联赛式（星耀田径系列赛）

## 经典桥段
- 热血向：绝杀逆转、带伤上阵、黑马爆冷掀翻豪门、卫冕之战、为国出线
- 成长向：被质疑的天才用表现打脸、青训淘汰者逆袭、低谷重塑技术
- 情感向：队友羁绊（接力/团体赛）、师徒传承（接过退役传奇的号码）、双雄对决惺惺相惜
- 争议向：黑哨误判、兴奋剂污蔑、天价转会、商业化与纯粹的冲突

## 写作要点
- 竞技文核心爽点：实力碾压、绝境翻盘、荣誉时刻、打脸质疑者
- 技战术描写要专业（读者多为项目爱好者，细节错误易劝退），虚构选手但技术体系要真实
- 比赛节奏张弛有度：常规赛快写，关键分/决胜局慢镜头逐拍描写
- 训练线与比赛线交替，成长曲线与对手强度同步升级
