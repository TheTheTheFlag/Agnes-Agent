# 游戏电竞风格参考库
## 题材分类参考
### 游戏类型设定
- MMO网游：副本开荒、公会争霸、全服首杀、装备打造
- FPS射击：战术射击、大逃杀、爆破模式
- MOBA：对线运营、团战、职业联赛
- 全息VR：沉浸式体验、意识操作、痛觉同步
- 卡牌/策略：构筑卡组、天梯上分、赛事
- 生存沙盒：基建、开荒、PVP夺资源

### 电竞题材细分
职业联赛文、退役复出文、天才新人文、网吧大神文、女子战队文、幕后教练/经理文、解说视角文

## 赛事体系参考（从低到高）
网吧赛 -> 城市赛 -> 高校联赛 -> 次级联赛/发展联盟 -> 顶级职业联赛 -> 季后赛 -> 国际邀请赛/世界总决赛

### 队伍位置分工
- 射击类：指挥、突击手、狙击手、自由人、辅助位
- MOBA类：上单、打野、中单、射手、辅助
- 通用：队长、核心C位、替补、数据分析师、教练、领队

## 常见金手指/设定
重生回到职业生涯起点（带着未来版本理解）、超凡反应手速、数据化视野（能看到弹道预测）、全位置精通、伤病复原体质、系统外挂级意识、天赋觉醒（鹰眼/绝对专注）、跨游戏全才、粉丝加持 buff

## 常见角色配置
天才新人（性格张扬/寡言两种流派）、过气老将、魔鬼教练、毒舌解说、美女领队、数据宅分析师、富二代老板、宿敌选手、网恋对象=对手选手

## 经典桥段
逆风翻盘让二追三、绝境一穿三、天价转会风波、代打/开挂污蔑风波、手伤隐瞒带伤出战、退役仪式泪目、网吧路人王吊打职业哥、双排上分网恋奔现、老将重返世界赛、新王加冕卫冕之战、赛前垃圾话、赛后采访名场面、队友内讧到和解、青训营魔鬼考核

## 写作要点
- 战斗描写强调「操作细节+临场决策」，避免只喊招式名
- 电竞文核心爽点：实力碾压、逆袭翻盘、荣誉加身、团队羁绊
- 注意虚构所有战队/选手/赛事名，避免映射真实电竞俱乐部与选手
