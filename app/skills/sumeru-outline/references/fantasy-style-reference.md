# 西幻奇幻风格参考库
## 种族设定参考
### 常见种族
人类、精灵（森精灵/高等精灵/暗精灵）、矮人（山地矮人/锻造氏族）、兽人、龙族、半身人、地精、巨人、亡灵、恶魔、天使、泰坦、鱼人、蜥蜴人、翼人、兽耳种族（猫人/狐人/狼人）

### 种族特性速查
- 精灵：长寿、弓术与魔法天赋、亲近自然
- 矮人：锻造大师、嗜酒、固执重诺
- 兽人：体魄强横、崇尚武力、萨满信仰
- 龙族：傲慢强大、喜欢囤积财宝、血脉即力量

## 职业体系参考
### 职业列表
战士、骑士、法师、牧师、游侠、盗贼、刺客、圣骑士、死灵法师、德鲁伊、吟游诗人、炼金术士、附魔师、召唤师、魔剑士、狂战士、魔导工程师

### 等级划分（从低到高）
1. 见习 -> 正式 -> 精英 -> 大师 -> 宗师 -> 传奇 -> 神话
2. 一阶 -> 二阶 -> 三阶 -> ... -> 九阶 -> 圣域 -> 神境
3. 青铜 -> 白银 -> 黄金 -> 铂金 -> 钻石 -> 史诗 -> 传说（冒险者公会制）

## 魔法体系参考
### 魔法分类
元素系（火/水/风/土/雷/冰）、光暗系、时空系、召唤系、幻术系、附魔系、亡灵系、血脉魔法、符文魔法、神术（信仰驱动）、奥术（研究驱动）

### 法术环阶
一环戏法 -> 三环正式法师 -> 五环高阶 -> 七环大法师 -> 九环传奇 -> 禁咒（每环对应等级门槛）
