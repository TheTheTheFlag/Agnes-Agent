# 画风选择机制（★ 任务起始第一步：先选画风，再出任何图/视频）

角色/场景/道具资产板、分镜首帧、关键帧、视频提示词 —— 本 skill 范围内**一切**出图/出视频产物，
**必须在画风确定之后才能生成**。画风未定前，禁止出任何图/视频。

## 〇、执行铁则
1. 任务开始（首次出图/出视频之前）的第一步：**确认/选择画风**。
   - 用户明确指定画风 → 直接采用；
   - 用户未指定 → 从下方画风库**询问**，用户选定后才开始；
   - 延续既有工程/资产 → 沿用既有画风，但必须向用户明示沿用。
2. 画风选定后，本任务内全部出图词 / 出视频词**必须并入所选画风的风格档**（见画风库表）。
3. 画风与「形象」解耦：角色五官/年龄/服饰由**角色资产板与参考图（`--ref`）**及角色设定决定；
   画风只决定渲染方式/质感/色彩语言/描边，**绝不**用画风的风格档去改写角色外貌。
   各年龄段的形象按角色设定推导（继承家族标记，不套用其他年龄段的服饰与气质词）。

## 二、执行方式
- 出图词写法：`画面主体：…。{风格档}`（风格档逐字并入，位于画面描述之后）。
- 出视频词写法：`{风格档}，电影运镜：…`（风格档位于运镜描述之前）。
- 分镜首帧/关键帧即时续用该画风，保证画风一致；换画风 = 换项目/换任务，需重新确认。

## 三、与资产台账
- 资产板 prompt 记录所选画风编码（如 STYLE-02），见 `asset-spatial-ledger.md` / 剧组产出册。
