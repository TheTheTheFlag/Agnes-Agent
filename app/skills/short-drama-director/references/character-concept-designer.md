## 一、 风格自适应原则（★ 禁止默认国风古装）

必须根据小说提供的**时代背景、题材类型、文化元素**，自动判断并选用合适的美术风格参考。

| 题材元素（命中即用） | 风格类型 | 参考体系 | 服装/材质要点 |
|---|---|---|---|
| 修仙、武侠、宫廷、古代地名/官职、冷兵器、丝绸锦缎 | **国风写实** | 《逆水寒》《永劫无间》《天涯明月刀》 | 丝绸、织锦，国风剪裁 |

## 二、 通用美学标准（自然苗条版 · 光影升级）

### 1. 皮肤（风格自适应）
- 国风/现代/民国：冷白瓷肌或健康小麦色，通透如玉石；
- 科幻：可带金属光泽或霓虹色纹路；
- 西幻：可带雀斑或淡金光泽；
- 中式克苏鲁：青灰、惨白、蜡黄、纸浆白等**非自然肤色**，允许极细微裂纹、陈旧缝合线或瓷质开片感（不得写实毛孔），呈现"陶俑活化 / 纸人还魂"的诡异质感；
- **禁止：塑料感、硅胶感。**

### 2. 五官（差异化自适应系统 · 拒绝模板化脸盲）
> 每个角色的脸型、眉、眼、鼻、唇必须根据性格、年龄、身份、风格背景**差异化选择**；提示词必须明确写出所选的具体脸型、眼型、眉形等，**不得写笼统"精致五官"**。

**脸型与骨相**（不设固定脸型，选一种或融合）：
| 脸型 | 气质 |
|---|---|
| 鹅蛋脸 | 温婉端庄，线条流畅 |
| 瓜子脸（非锥子） | 娇俏灵动，下巴微尖但不过分 |
| 圆润苹果脸 | 减龄幼态，胶原蛋白感强（活泼/善良型） |
| 方中带圆脸（柔和方颌） | 英气倔强，有力量感 |
| 长菱形脸 | 高冷疏离，颧骨微宽，下颌收窄（反派/御姐） |
| 心形脸 | 甜美精致，额头宽下巴尖 |
| 【中式克苏鲁】不对称脸/轻度变容 | 一侧颧骨略高、眼位微错、嘴唇歪斜，保持整体可辨识，表现"非人感" |

- 骨相：轮廓分明但不生硬，颧骨和下颌角有适度存在感（按脸型），拒绝充气感与锥子下巴。

**眉形**（至少给出具体眉型名称）：
- 清冷疏离型：远山眉（眉尾微垂弧度缓）/ 柳叶眉（细长淡雅）；
- 英气干练型：剑眉（眉峰上扬，线条直）/ 水弯眉（略挑）；
- 妩媚娇柔型：秋波眉（弯如新月）/ 挑眉（眉峰高挑）；
- 中性少年感：野生平眉（浓密自然，无明显眉峰）；
- 【中式克苏鲁】诡异淡漠型：八字眉（眉尾下垂愁苦状）/ 断眉（眉中缺口）/ 极淡眉（近乎无毛，纸人感）；
- 要求：形状自然，毛流感清晰，不千篇一律。

**眼型**（搭配对应眼神）：
| 眼型 | 特征与适配 |
|---|---|
| 丹凤眼 | 内尖外翘，眼尾高于眼头（凌厉/高傲/心机） |
| 桃花眼 | 眼型细长，眼尾微弯，眼神含情（妩媚/温柔/风流） |
| 杏眼 | 圆润清澈，眼头眼尾宽度相近（天真/善良/无辜） |
| 瑞凤眼 | 眼头勾曲，眼尾上挑但较丹凤眼更圆（聪慧/机敏/腹黑） |
| 狐狸眼 | 眼尾极度上挑，眼型狭长（妖艳/魅惑/反派） |
| 下垂眼（狗狗眼） | 眼尾低于眼头（忧郁/无辜/楚楚可怜） |
| 柳叶眼 | 介于杏眼和丹凤眼之间，细长而内尖（古典/内敛） |
| 【中式克苏鲁】多瞳/无瞳/瞳中瞳 | "双瞳重叠"/"瞳孔中浮现第二瞳孔"/"眼白占据大半，仅有针尖大小黑瞳"（合规描述），眼神空洞或诡异聚焦 |

- 要求：眼眸深邃清澈，瞳孔颜色按设定（深黑、浅褐、琥珀、灰蓝、血红、全黑等），睫毛浓密卷翘；眼神与气质匹配（清冷/凌厉/温柔/狡黠/迷茫/坚毅/空洞/恶寒/慈悲而诡异等）。

**鼻型**（拒绝固定描述）：
- 高挺直鼻：御姐/精英/冷艳；略带驼峰鼻：英气混血感（强势）；
- 小巧翘鼻：甜美/灵动/少女；鼻头圆润带肉感：亲和无攻击（善良/可爱）；
- 希腊鼻（鼻梁笔直，鼻尖微勾）：高贵/严谨；
- 【中式克苏鲁】缺损鼻/鼻梁歪斜：腐朽或非人塑造感；
- 所有鼻型必须自然，**禁止锥子鼻或过度尖窄**。

**唇形与唇色**（避免统一话术）：
- 薄唇轻抿：清冷/寡淡/克制/薄情；厚唇微翘：性感/娇憨/元气/热情；
- M 唇（唇峰明显）：精致/娇媚/高傲；嘴角平直或下垂：坚毅/冷淡/忧郁；
- 【中式克苏鲁】嘴角上扬固定弧度（纸人笑）：似笑非笑的"假笑感"；
- 唇色按风格/时代（裸色、豆沙、红棕、水红、浆果、朱砂红、黑紫、惨白等），质感可选哑光/水润/干裂。

**妆容（风格自适应，不再强制"清冷仙子妆"）**：
| 风格 | 妆容 |
|---|---|
| 现代职场 | 大地色眼影，极细眼线，自然唇色，底妆清透 |
| 赛博朋克 | 荧光眼线，金属高光，彩色睫毛，几何贴片 |
| 国风仙侠 | 眼尾上挑眼线，花钿，咬唇妆，额间点缀 |
| 西幻 | 雀斑，金色眼影，神秘图腾纹身，烟熏眼妆 |
| 中式克苏鲁 | 额间点血痕或朱砂符，面颊贴纸钱碎屑，眼周晕染黑红，嘴唇中央一抹朱红而周边惨白，眼角/嘴角绘制细小眼睛图腾或裂口纹样。妆容传递"诡异的神圣、腐朽的华丽" |

### 3. 发丝
- 顺滑蓬松、根根分明、精致发型、发量浓密；
- 现代：披肩/马尾/编发；科幻：束发/半剃头/发光发丝；
- 中式克苏鲁：发髻散乱插纸钱、白发如枯草、发丝末端焦黑。

### 4. 服装（传说级奢华升级 · 自然修身）
**剪裁结构**：按风格选服装品类。外层服装必须采用符合人体曲线的立体剪裁——流畅衣身线条、侧身拼接、内藏式收省等高级定制手法，肩部到腰胯自然过渡；腰线符合真实人体比例，呈现"穿衣显瘦"的自然苗条感。
- 【中式克苏鲁】结构可解构：国风袍服出现不合理褶皱、反向领口、多出的袖管、纸扎般僵硬折痕，但保持可穿着的逻辑（"诡异的立体剪裁"、"不符合人体又仿佛专为它设计"）；
- **腰带/腰封**：若需要，只能用宽度≤手掌的极细束带或细链自然轻束；**严禁"宽腰封/紧束/勒紧"等词**；更推荐无腰带，仅凭剪裁体现线条；
- 裙摆/衣摆：可不对称、鱼尾、开衩（安全高度）；袖型可宽大或贴身，躯干经立体剪裁贴合天然曲线。

**材质对撞（≥4 种以上高级材质混搭）**：
- 国风：丝绸、织锦；现代：羊毛、真丝、科技面料；
- 科幻：高光尼龙、碳纤维纹理、液态金属；西幻：丝绒、粗花呢、哑光金属；
- 中式克苏鲁：破旧缂丝、褪色蜀锦、浸蜡麻布、纸质感材料、锈蚀青铜片、黏腻漆皮；
- 辅料/宝石/特效按风格适配（中式克苏鲁可用纸钱、铜铃、破旧桃木符、干枯莲蓬、眼球状珠子）。

**装饰细节**（极尽奢华，贴合风格及气质）：刺绣/印花/纹样、镶滚、珠宝镶嵌、金属配饰等按风格自适配。
- 中式克苏鲁刺绣：**"腐烂的仙鹤""流泪的佛像""纠缠的触手与云纹结合"**。

**领口与露肤（安全合规）**：使用"高领/小立领/衬衫领/V 形金属领缘/一字领（非低胸）"等安全描述，允许"显露锁骨"；**禁止任何暴露胸部的设计**。
- 中式克苏鲁：多层交领、歪斜的领口、纸扎领。

**鞋履**：必须穿着符合风格的华丽鞋靴，**禁止赤足**。
- 中式克苏鲁：绣花鞋、云头履（做旧沾土）、铜钱纹布鞋。

**特殊效果**：衣料有真实物理垂坠感；可添加静态微光或反射效果。
- 中式克苏鲁：衣料表面浮现水渍般的暗纹、边缘焦黑碳化但不燃烧。

### 5. 身材（安全版）
- 女性：高挑曼妙，九头身，腰肢自然纤细，腿部笔直修长，肩颈线条优美，胸部自然饱满，臀部自然圆润；
- 男性：宽肩窄腰，身形挺拔如松，胸背肌肉线条流畅有力，双腿修长；
- 【中式克苏鲁】允许"肢体比例轻微失调（手指过长、脖子异常纤细）"，不露骨、不强烈不适，保持"类人而非人"的微妙违和感。

### 6. 姿态与镜头（纯白背景 · 自然站立）
- 全身站立：双肩自然平放，双手自然交叠于腹前或垂于身侧；身体微侧呈 3/4 面朝镜头，下巴微抬；姿态端庄，衣袍自然垂坠，**无飘动**；
- 面部朝向：正面或微侧，自然站立；
- 表情：面部平静，通过眉眼传递气质；
- 中式克苏鲁："无表情却透出悲悯/空洞"、"嘴角固定微笑但眼神冰冷"。

### 7. 光影与画质
- 布光：均匀柔和正面光 + 精致轮廓光/侧逆光（边缘光晕），增强立体感；**拒绝强阴影**；
- 中式克苏鲁：可增加"阴翳氛围"，保留较低角度暖黄补光模拟烛火，侧逆光带一丝青蓝色，阴影区域允许少量噪点质感（非强阴影）；
- 画质按输出风格：
  - 3D 渲染风格：C4D / 八猴 / 虚幻引擎5，次世代高模，光线追踪，8K，极致细节，艺术站风格；
  - 真人实拍风格：超高清摄影，写实人像，8K，电影级柔光布光；
  - 中式克苏鲁真人实拍可加入"胶片颗粒感""老照片划痕"作氛围选项。

## 四、 与资产管线衔接要点

1. 本文件生成的形象词 → 作为角色出图词主体，**逐字并入所选 STYLE 风格档**（`art-style-selection.md`），再按 4 View 资产板布局出图（`asset-spatial-ledger.md` §二 / `character-lineage-and-sheets.md`）；
2. 半身 4:3 ≈ Face Close-up（五官/妆容/材质特写载体），全身 9:16 ≈ 无头 Front View 全身（姿态/服装/鞋履载体），两者与 4 View 布局互补；
3. 同一角色的 3D 渲染 / 真人实拍两版用于资产确认；锁定后以资产板 + `--ref` 为跨镜唯一形象来源；
4. 五官差异化（脸型/眉/眼/鼻/唇具体选型）需同时写入 4 View 资产板的 Face Close-up 描述，避免资产板与设定图脸模漂移；
5. 题材风格判断先于写作：内部先标 `风格类型：[…]`，混合题材融合对应元素并保持写实基调。
