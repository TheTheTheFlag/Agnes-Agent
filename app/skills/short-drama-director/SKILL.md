## 〇、 任务前置强制锁定：A·模型通道 / B·画幅 / C·交付形态 / D·段缝衔接方式 / E·画风（最高优先级 · 每个任务第一步）

> **每个任务动笔前必须先完成 A、B 两道创作锁；多段任务加 D 锁（段缝衔接方式三选一）。任一项用户未指定 = 任务不开始，禁止默认跳过。C·交付形态未指定时默认「③ 两者都交付」，不阻塞创作（见下）。**

### A · 模型通道：agnes 单通道（本部署唯一模型锁）

> 本部署**不再询问「模型版本三选一」**——模型统一为 agnes：出图 `agnes-image-2.5-flash`、
> 出视频 `agnes-video-v2.0`（flash 档/旧档为备选）。**投喂正文一律为 agnes 纯文本**：不写任何官方
> 字符（`{}`/`<>`/`()`/`【】`），不投 H3 字段；声音/台词以文字写入正文。
> 语法与封装细节见 `references/agnes-media-adapter.md`（★权威）；拍摄/描写方法论照常执行。

- **出图能力**：文生图 / 图生图（`--ref` 多图锁形象）；`--ratio` 按 B 锁（16:9 / 9:16 / 21:9 / 1:1 / 3:4 / 4:3 / 2:3 / 3:2）；`--size` 1K~4K（默认 2K）。
- **出视频能力（三模式）**：
  - **img2vid**（`--image` 单图锁首帧形象 → 动作延续）；
  - **keyframes 关键帧动画**（`--keyframes`，**2~3 张**参考图，首/中/末锁定过渡轨迹——锁形象一致性首选，**服务器要求 ≥2 张**）；
  - **ti2vid 文生视频**（无图无关键帧，纯文本）。
- **无首尾帧**：agnese 不具备首尾帧/参考图绑定能力（编辑页无此栏目），跨镜一致性与首末帧过渡全部由 **keyframes（2~3 图）/ img2vid** 承担。
- **时长档位**：`--duration 3|5|10|18`（→ 81/121/241/441 帧 @24fps，必须 8n+1）；**不传默认 121 ≈ 5s**。
- **参考图红线**：一律用已入库作品 / 本地生成的图；**禁投现实真人照片素材**（官方红线，画风写实不禁）。
- **任务超时**：默认 300s；超时后 `fetch --task-id <TASK_ID>` 续查（后端 6h 内自动重试），**禁止重建任务**。
- **产物落点**：唯一落作品库（stdout `FILE=`），功率条见 adapter §6。

### B · 画幅强制三选一（与 A 同规格铁律）
- 用户必须明确选择：**16:9 横屏** 或 **9:16 竖屏** 或 **21:9 宽幕**（官方另支持 1:1，仅用户明确指定时采用）；
- 未指定时，唯一正确动作是**停下询问用户**，禁止以任何理由默认跳画幅；
- 锁定后全流程（资产构图 / 分镜机位 / 提示词模板 / agnes `--ratio` 回填 / 质检）一律按该画幅版本执行，禁止混用、禁止被示例或模板带偏；画幅细则路由见 `references/aspect-ratio-adaptation.md`（★权威）。

### C · 交付形态三选一（A/B 锁定后顺带确认；未指定默认 ③，不阻塞创作）
- **① 只要离线看板**：项目 md 照常创作（它是看板的唯一编译源，不写 md 就没有看板），但最终**只交付看板 HTML**，md 留作工作底稿；
- **② 只要 markdown 文档**：交付 md，不编译看板；
- **③ 两者都交付（默认）**：md + 编译好的单文件离线看板。
- **依赖关系必须向用户讲清**：md 是唯一真相，看板由 md 编译生成——**看板离不开 md，不存在"跳过 md 直接写看板"**；C 只决定最后交付哪份文件，几乎不影响出稿速度。

> **A、B 两锁齐备才动笔（多段任务加 D 锁）**：A·模型通道 与 B·画幅 全部锁死，才允许进入 P1 之后的任何环节；C·交付形态可后置（默认 ③）；**D·段缝衔接方式仅多段任务适用，未指定 = 停下询问**。

### D · 段缝衔接方式三选一（V6.9 新增锁 · 多段任务与 A/B 同规格）

> **背景（V6.9 粉丝实测反馈）**：AI 模型每段零记忆——上一段的站位/姿态/互动在下一段全部归零，段缝处必然跳切、动作断层（"段落间衔接生硬"的病根）。V6.9 把段缝衔接升格为前置锁，三种方案可叠加，规程见 `segment-splicing.md`（★权威）。

- **用户必须明确选择（多段任务）**；未指定时唯一正确动作是**停下询问**；**单段任务不涉及此锁，不询问**；
- **① 末态双保险（默认推荐 · 连续剧情多段标配）**：每段【接续状态】写**具体末帧画面**（谁+在哪+姿态+关键道具/互动状态，禁套话，机检 C11 告警）＋ **按上一段结尾状态绘制段缝分镜参考图**锁定末态，作为下一段首镜依据（按 keyframes 投喂）——一致性最强，成本 +1 张图/段缝；
- **② 换机位硬切**：段缝两侧**强制更换机位/景别**（禁同机位硬接），把两段做成两个镜头的剪辑关系——最快、零出图成本，动作戏段缝首选；
- **③ 空镜过渡**：段缝处插 **1~2s 带戏剧任务的空镜**（情绪空镜+BGM 不搭人声 / 音效桥空镜声音先入 / 时空转场空镜，搭声不搭皆可），单集 ≤3 处——情绪段、转场段首选；
- **叠加规则**：①+② 为连续剧情多段的默认组合；③ 可与 ①② 叠加；无论选哪种，【接续状态】尾行必带（C11 机检兜底），工作流规则词（末态继承/拼接节点/换机位）禁进投喂正文（C12）。

### E · 默认直接出图出视频（Agnes 本地化改写 · 2026-09-26 用户确认铁律）

> 原「默认只出提示词」在**本部署已被用户实锤改写（2026-09-26）**：**默认直接调用 agnes-media
> 出图、出视频**（用户指示「出图/出视频统一指定 agnes-media」）。仅保留 P2 分批确认门禁：
> 先给《资产清单》确认批次，确认后立即执行，不再让用户手工跑图；分镜/投喂稿机检通过后直接 `media.py video` 执行。

- **本 skill 默认执行形态 = 直接出图/出视频**（经 agnes-media 单通道），不再只交付提示词文本。
- 资产图/参考图（角色 4 View、场景母版、道具图、分镜关键帧/首帧图等）同样默认直接出图。
- **保留的分寸**：`asset-first-pipeline.md` 门禁不可跳——资产清单先确认批次、分批出图逐批确认；P2 后出视频不受此限。
- 与 `short-drama-produce`（确认制生产 skill）协作时：出图执行仍走它的确认闸门，本 skill 按此执行。

### F · agnes 时长档位铁律（Agnes 本地化改写 · 与 E 同级）

- **时长档位由内容量倒推**：`--duration` 三档 3/5/10/18（秒），**禁止把 5s 当默认值、禁止全片统一卡一档**；
  段长按剧情内容量倒推（台词按 3.5~5 字/s、动作按节拍/信息量），一场戏 7s 讲完就 7s 收，需要更长就用 10/18s。
- **单段上限 18s**（agnese 支持的最大档）；多段长剧情按段拆分，每组独立投喂。
- **总时长同样由内容倒推、禁拉伸凑满**：内容不饱满时诚实变短（允许比剧本标注短 -25%），禁止把氛围镜/过渡镜拉长凑满。

### G · 台词/音效默认视频内出（2026-09-16 用户确认 · 与 E/F 同级）

- **台词与人声音效默认写入投喂正文、由视频模型在成片内生成**——台词走声音层锁口型与对白，**禁止默认"全走后期配音"**；
- **唯一例外 = 用户明确逐次指定「不出台词」/「台词走后期配音」**：此时台词不写入生成或标注后期合成；
- **音效同理**：默认随视频生成（正文写"声音：…"），仅用户明确指定才走后期层。

### H · 素材红线边界澄清：禁「真人照片素材」≠ 禁「写实/仿真人风格」（2026-09-18 用户确认 · 与 E/F/G 同级）

- **红线只约束参考素材来源，不约束输出画风**：agnese 通道 **不支持上传含真人人脸的参考图/视频**——即**禁止把现实真人的照片 / 真人脸图**当参考素材投喂；这与画风无关。
- **写实 / 仿真人（次世代 3D / 实拍级质感）风格完全支持，不属红线**：本包「R1 写实克制」动作档、`audiovisual-aesthetic-presets.md` 的「东方诗意写实」预设、角色资产板标准画质词「次世代 3D / 实拍级全身模型拆解」均为正式支持用法。
- **判定口径一句话**：看**素材来源**，不看**画风**——AI/CG 生成的写实仿真人（超写实渲染）= 可用；翻拍/下载的**现实真人照片** = 红线。
- 红线四条完整表述见 `references/model-adapters.md` §5（官方限制）；投喂自查见 `references/★ prompt-feeding-checklist.md`。

## 二、 核心特性：多平台 Agent 与 agnes 通道深度兼容

### 1. 多 Agent 运行平台适配
- **WorkBuddy 适配**：支持 P0 立项锁定 → P1 剧本门控 → **P2 数字资产包（资产图先于分镜）** → P3 空间调度 → P4 投喂 → P5 质检六阶段会话流转，自动挂载《剧组_资产图册.md》与 2x2 顶视图；
- **豆包智能体 / 扣子 (Coze) 适配**：支持输出结构化 JSON 块，自动分块（Chunking）防止对话上下文截断；
- **OpenClaw 适配**：原生 CLI 部署与 Tool-Call 完整兼容；
- **Dify / 通用大模型适配**：支持单文件 Prompt 独立运行模式。

### 2. agnes 单通道媒体执行（本部署唯一媒体通道）
- **统一通道**：出图/出视频全部经 `app/skills_builtin/agnes-media/media.py`（内部创作台 127.0.0.1:8081，复用页面 `/api/image/generate` 与 `/api/video/generate` 端点）；调用前必须 `export AGENT_INTERNAL_TOKEN=$(cat /home/mirror/Agnes-Agent/data/internal_token)`；
- **出图**：默认 `agnes-image-2.5-flash`；`--ratio`（B 锁画幅）、`--size 2K`、`--ref` 多图锁形象；
- **出视频**：默认 `agnes-video-v2.0`；三模式 img2vid（单图）/ keyframes（2~3 图，关键帧动画）/ ti2vid（纯文本）；`--duration 3|5|10|18`；
- **投喂正文**：一律 agnes 纯文本（无官方字符、无 H3 字段）；
- **提示词语言铁律（2026-09-29）**：出图/出视频提示词一律中文（仅 2K/8K 等规格词、专有英文名除外），禁止英文质量后缀（masterpiece / best quality / cinematic lighting 等）与英文描述词；
- **产物落点**：唯一作品库（`data/users/<user>/data/{image|video}_library`，stdout `FILE=`），**不产生 output 重复副本**（已规避 `_sync_skill_outputs` 二次登记）；
- **长任务后台化（2026-09-28 铁律）**：批量出图/出视频脚本一律 `nohup python3 脚本.py > 脚本.log 2>&1 &` 立即返回，再用 `read_file` 轮询日志；**禁止前台 sleep 等待**。前台命令超时 = 整条进程组已被强制终止（`killed=True`），先读日志确认已完成部分，**只补缺段、禁止整批重跑**；
- **防重复生成**：任何生成动作前先重读 `data/users/<user>/data/{image|video}_library/manifest.json`，目标段/seed 已有 `status=completed` 则跳过；重复 take 判定 = 同 seed + 同用途多条 completed；
- **禁止手写 HTTP 直调**：出图/出视频只走 `media.py`（手写脚本直调 `/api/video/generate` 会因响应顶层无 `task_id` 取到 `None` 而死循环轮询 404，且中文 prompt 经 Git Bash 内联参数会乱码）；
- **红线**：禁现实真人照片素材（画风写实不禁，见〇节 H）。

## 三、 核心工业法则一览

0. **Asset-First 六阶段管线（最高原则）**：全流程严格按 `asset-first-pipeline.md`（★权威）执行 P0 立项锁定 → P1 剧本门控 → **P2 数字资产包**（提取全部实体 → 资产清单确认 → 角色/场景/道具分批出图锁定 → 交付《资产图册》）→ P3 空间调度+分镜 → P4 投喂生成 → P5 质检。**资产图先于分镜，无图不进分镜**（P2/P3 硬门禁）。

1. **剧本五阶门控 (Gate 1~5)**：Premise $\rightarrow$ 30%/50%/20% 结构 $\rightarrow$ 因果节拍表 $\rightarrow$ 世界观与实体边界 $\rightarrow$ 专业剧本页。
2. **《剧组产出册》工业台账**：标准化输出角色（`CHR-`）、声音（`AUD-`）、道具（`PRP-`）、场景（`SCN-`）与分集单元（`U01~Uxx`）。
3. **12 节拍全片情绪张力曲线**：量化 12 个因果驱动节拍点（0~10 分），锁定第 9 节拍 9.5+ 终极爽点反杀。
4. **角色资产板与亲缘推导**：A/B 级 16 项锁，T1（男女主）至 T2（亲属配角）40%~60% 骨相与五官关联遗传推导。
5. **空间顶视图与机位调度 (2x2 网格)**：俯视平面绘制走位与 CAM1~CAM4，180° 轴线防护与合法越轴。
6. **台词七维体检与语速自检**：对白 3.5~5 字/秒，留出 0.3~0.8 秒落口发酵空间，强制语速门禁扫描。
7. **打戏 15 秒动力链 PREVIS（R1/R2/R3 三档）**：0~1.5s 开局硬撞，11 环动力链，防守三态，最后一帧定格。**R3 玄幻档切换法术语言**——法宝媒介+五行术法+术法攻防+能量具象化+对军清场（见 `xuanhuan-magic-combat.md` ★权威），不硬套武侠物理打斗。
8. **时长档位前置协议（Agnes 改写）**：3 分钟剧本强制展开为 14~15 段，**每段按内容倒推时长**——用 agnes `--duration 3|5|10|18` 档位落地（≤18s/段，单段独立可投喂生成）；中文投喂词每组 ≤500 字、英文 ≤1000 词（官方字数门禁）。
9. **P0~P2 独立质检门禁**：阻断超时、跳轴与后台词外显；对白 ($0\text{ dB}$) $>$ 物理音效 ($-6\text{ dB}$) $>$ BGM ($-14\text{ dB}$)。
10. **画幅铁律（B 锁·用户指令优先）**：最终画幅比例一律以**用户指定为准**——用户说 16:9 必须全部走横屏模板并回填 agnes `--ratio 16:9`，严禁被示例/模板里的 `9:16` 或竖屏构图带偏；画幅三选一（16:9 / 9:16 / 21:9）与模型通道同属〇节前置锁定，**用户未指定 = 任务不开始，禁止默认 9:16**。**全流程画幅路由见 `references/aspect-ratio-adaptation.md`（★权威）**。
11. **资产图册唯一事实来源**：《剧组资产图册》（CHR/SCN/PRP 全附资产参考图）是 P3/P4 的唯一权威事实来源；分镜/投喂引用的 `@锚点` 必须指向已锁定资产图，禁止以文字描述替代资产图。
12. **改动后复验铁律**：改稿禁止只复验改动处——必须按「① 局部验证（改动处自检）→ ② 联动冲突检查（伏笔/角色/信息量/因果节拍/资产/时长/画幅七项交叉扫描）→ ③ 全量审核（整片重跑 P0~P2）」三步闭环；修改交付文末必须附《改动复验报告》（改动清单+联动检查结论+全量审核结论），未附视为未完成复验、禁止交付（见 `references/quality-gate-review.md` §三）。
13. **表情 FACS 化（微表情管理）**：人物表情/微表情一律禁止写"开心/难过/邪魅"等空泛结果词，必须按 FACS 落成 AU 动作单元——「眉/眼/颧颊/嘴下颌」四区写全 + 〔痕/显/强〕强度三档 + "起—hold—落"时序（峰值对齐台词重音）；真笑必带 AU6、假笑只给 AU12、惊讶/恐惧靠有无 AU4 区分（见 `references/★ facs-micro-expression.md` ★权威；**FACS 为增强模块、按需触发**——简单文戏用正常影视表演语言〔仍禁"开心/难过/邪魅"类空泛结果词〕，仅特写/微表情/情绪关键拍/表情易崩镜头才展开 AU 配方与 cue 表）。
14. **投喂主格式七段式（不借用外部示范）**：视频投喂提示词固定为七段式，段序、站位声明写法、接续状态尾行、镜行原生格式的**唯一权威定义见 `model-adapters.md` §5**；「七段式」为全包唯一命名，禁用"八段式/六栏/九栏"等别名。**Agnes 本地化封装**：七段式各段的写作方法照旧，最终交付投喂正文时按 `agnes-media-adapter.md` §3/§4 封装的 agnes 纯文本执行（不写官方 `{}`/`<>`/`()`/`【】` 字符、不投 H3 字段）。外部示范格式只作语法参考，其括号五要素连写、`（本镜唯一开口者）`、`跟随@谁`、末尾【参数契约】行、ASCII 空间图等变体一律禁用（完整禁写清单见 `references/model-adapters.md` §5.1）。
15. **交付满额铁律（不许漏执行项目）**：契约要求的字段/模板段落必须逐条写满才算完成——角色出图必须走 **4 View 资产板（头部近景/面部特写 + 无头正面/90°侧面/背面三联全身）+ 五官 10 项 + 服装材质 6 项**，战斗场景必须用**战斗角色站位版**（占位/轴线/禁入画/空中高位预留），分镜必须逐镜带到场名单 + 站位声明 + 行内声音台词 + 接续状态。**示例与演示产物同样按满血标准写**，禁止两三条简笔交差；交付前自查缺项。
16. **按需触发分级（V6.8·降无效加载不减能力）**：① 空间站位 S0~S4 分级——S0 单人（简版站位：位置+朝向+动作一行，免轴线免位移链）/ S1 双人静态（一行式站位+轴线）/ S2 多人静态（全员具名四要素+轴线）/ S3 多人移动（逐人位移因果链）/ S4 复杂战斗·多空间切换（才启用顶视图 CAM1~4 调度、合法越轴与 V3 备查），见 `asset-spatial-ledger.md` §三·5；② 资产依赖 A0~A3 分级——A0 纯文字/单镜/无一致性要求不强制资产链 / A1 单角色单镜资产可选 / A2 跨镜一致性启用相关资产 / A3 多人·多场景·连续剧集完整 Asset-First，见 `asset-first-pipeline.md` §〇·6；③ FACS 触发条件见法则 13。判定不清按高一级处理。
17. **镜长节奏铁律（禁止"为规整而规整"）**：镜长时间**必须由剧情倒推**，严禁机械等分——**正确顺序 = 剧情 → 情绪节拍 → 时长**（台词镜按 3.5~5 字/秒 字数倒推 + 情绪停顿；无台词镜按情绪节拍定长），**错误顺序 = 先定 `段长÷镜数` 再往里填内容**。全篇镜长必须**快慢呼吸交替**，覆盖 ≥3 个取值（如 {3,4,5}s），每单元节奏骨架不重复；**爆发/爆点镜快切、金句/高潮镜长镜留白**（最高张力点给足时间压住）。**「全片镜长雷同、无快慢节奏」是 `quality-gate-review.md` 明列的 P1 结构缺陷（自动修复项）**；完播率公式中「节奏呼吸」占 30% 权重（`camera-specs-15rules.md`），同节奏连续 ≤5 秒（`action-previs-15grid.md`）。**出稿机检 C13 自动拦截**：同段 ≥4 镜且同值镜长占比 ≥70% 即告警（`scripts/validate_prompt.py`）。**判定要点：平滑来源于情绪，不来源于算术均分——「规整」本身是缺陷信号。** **总时长同样由内容倒推、禁拉伸凑满**：上游剧本标注的【本集时长】只是**参考锚，不是必须铺满的硬指标**——分镜总时长 = 各镜内容量之和（台词÷3.5~5 字/s + 动作节拍 + 转场），允许比剧本标注**短至 -25%**；**内容不饱满时必须让总时长诚实地变短，严禁把氛围镜/过渡镜拉长凑满剧本标注时长**——一句 ≤40 字的 △ 动作行展开总时长 ≤6s、无台词氛围镜单镜 ≤5s、纯氛围段 ≤10s，把"暴雨 13 秒三连镜"式拉伸凑时视为**废稿级错误**（上游剧本注水是病根，下游拉伸是放大器——上游按弹性篇幅写饱满，下游按本法则诚实倒推）；同时**钩子前置**：剧本【黄金前3秒钩子】对应的台词/信息必须落在全片 00:00-00:05 首镜，剧本首行氛围 △ 镜压缩为 ≤4~5s 铺垫并与钩子台词同段，禁止把钩子挤到 13s 之后。机检 **C15** 自动拦截（无台词镜 >5s / 纯氛围段 >10s 告警，`scripts/validate_prompt.py`）。
18. **段缝末态继承与画外声规程（V6.9 新增）**：**段缝（上一段末镜→下一段首镜）按 D 锁选定方式衔接**——【接续状态】必写具体末帧画面（禁"严格继承"套话，C11 告警）＋ 段缝分镜参考图锁（①末态双保险）/ 段缝两侧强制换机位（②）/ 1~2s 带任务空镜（③，单集 ≤3 处）；工作流规则词禁进投喂正文（C12）。**画外声（OS 内心独白/VO 旁白）三纪律**：篇幅卡口（VO+OS 占声音容量 ≤30%，60~80 字/分钟）、OS 声画分离红线（独白发声画面角色必须闭口，禁用锁定口型通道）、VO 冷漠审视法则（不复述画面）——OS/VO 一律走"声音："段，台词字段只装画内开口对白（C14 机检兜底）。分别见 `segment-splicing.md` / `vo-os-weaving.md`（★权威）。

19. **对白三要素·语气位必写（V6.9.3 新增 · 全规格必写）**：官方对白规范三要素 = **WHO SPEAKS + WHAT THEY SAY + HOW THEY SOUND**。台词统一写 **`台词：【角色（语气）："…"】`**——语气紧贴角色名、写在冒号前的括号内（与画外声 `（OS·音色）` 同构），**不新增字段、不新增段**，七段式段数不变。四条铁律：① **声音词只进语气位，禁写进画面段**——写进画面段会被模型当视觉信息渲染（画出一张冷笑的脸），实测高发（机检 C16a）；② 语气按**四维**写（情绪色 / 力度 / 音质 / 节奏），每句 ≤3 词、允许演进 `（压抑→破防）`，**禁空泛结果词**（开心/难过/愤怒，C16c）；③ 语气是**文本层**信息，**必写**（C16b 缺失率告警）；④ **音色为可选增强**（有素材就锁、没有就写文字音色描述）——**不做资产体系、不设前置门禁**。**声音层（语气位 / `声音：` 段 / 【音效】）豁免反形容词规则**（声音没有肌肉动作可写），但同样禁空泛结果词。**⑤ 道具动作与语气一致（V6.9.7 续增 · C16d）**——闲适把玩类动作（把玩/摩挲/拨弄）只配慢悠悠/玩味语气；语气位是宣判/一字一顿/嘶吼/咆哮/质问等强情绪时，必须换成**攥紧/捏住/垂手握着**（实测病灶：段1 镜4 宣判台词配"直起身把玩玉佩"，用户："他已经在俯视了，你还在那儿玩？"）。规程见 `model-adapters.md` §5.2（★权威）+ §5.0.3 道具动作条，出稿机检 C16（a 声音词错位 / b 缺失率 / c 空泛词 / d 道具动作与语气冲突）兜底。

20. **人物账连续·摆位必入画（V6.9.3 续 · 跨段防穿帮）**：模型每段零记忆——**上一段画面里的人，这一段凭空消失、下一段又出现，是最典型的跨段穿帮**。四条铁律：① **摆位必入画**：【站位声明】摆了位的每个人，本段镜行**至少带到一次**（正拍/焦外身影/全景群像/反应镜头均算），实在给不了镜头就在站位括号里写明 `段末离画 / 退场·去向`（机检 C17）；② **入画要交代**：写明离场的人重新入画时，站位必须写 `段初自门口入画` 等方式；③ **站位不漂移**：相邻段之间没写移动的人，位置/朝向/依托物不得无交代改变；④ **（在场）标记口径**：【核心人物】行无标记=本段有台词或明确动作反应，`（在场）`=画面可见但无台词无反应——两级的人都必须进站位声明，禁自创其他标记。规程见 `model-adapters.md` §5.0.1，出稿机检 C17 兜底（单人站位段不触发）。

21. **首镜锚定·景别一致·姿态延续·视线指派（V6.9.4 新增 · 单段防废镜）**：四条铁律（病灶全部来自实拍废镜复盘）：① **首镜人物锚**——每段第 1 镜必须让站位人物至少一人入画（人名或注明归属的身体局部，如「她枯瘦的手」），空镜开场须镜行首写明「空镜：…」且每段至多 1 镜；首镜无锚，模型渲染出空场景（机检 C18a）；② **景别三一致**——特写/紧特写只承载单一局部主体，空间级事件（暴雨砸漏房顶/全屋火起）由中景以上承载，禁「特写+顶拍+全屋事件」混装（机检 C18d）；③ **姿态延续**——撑起/坐起/起身等变化一旦发生，同段后续镜必须显式「保持撑坐/已坐起」或焦外交代，倒下要写明跌回/瘫倒过程，禁无声回退（机检 C18b）；④ **视线指派**——说话镜必须写明视线对象「目光落在 XX 脸上」，手持/把玩道具说话必须补「视线不落在道具上」（举向光源的道具最抢视线，模型默认让角色盯着道具看，机检 C18c）。规程见 `model-adapters.md` §5.0.2，出稿机检 C18 兜底。**拉片反馈增补（§5.0.3）**：道具光效双保险（反光道具镜行写正向材质描写，机检 **C18e**）/ 表情锚（冷硬台词必显式写具体面部肌肉动作，模型对年轻女性默认甜笑）/ 外观锚（核心人物行写年龄锚、特写复述「同一张脸」，防换脸）/ 跨镜在场与方位复述（非主体人物镜行内复述「画面右后」，段末镜再带到）/ 禁模型自加镜头。

22. **禁令失效三改法 + 栏目纪律（V6.9.5 新增三改法 / V6.9.6 续增栏目纪律）**：**视频模型对否定不敏感、对词根敏感**——「禁空镜」里的空镜、「不发光」里的发光、「面无笑意」里的笑，被禁概念的词根本身留在提示词里（哪怕挂着"不/禁"），就会被当画面词渲染（实测三条否定式禁令两轮全部被无视：空房间开场、玉佩全片自发光、宣判词配露齿甜笑）。高关联视觉概念（光效/表情/开场镜头）必须三改：① **换词**——被禁词根在提示词**任何位置**（含强制禁止项）零出现，改写正向描述（道具→「深青色实心哑光石质，玉面呈青玉原色」，**零光效描写**，见 C20d；表情→「双唇抿紧、嘴角向下压、下颌绷紧」；首帧→「画面主体：<人名>…」单主体开头）；② **主体优先句式**——每段镜1第一个分句即画面主体（人名/身体局部/「画面主体：」/人称），环境前置词开头会诱导空场景开场；③ **触发器移除**——诱发被禁效果的动作/构图换掉（道具不与灯火共现：只把玩/佩戴，不靠近任何光源）。**栏目纪律（V6.9.6 续增）**：【强制禁止项】被模型当"规避清单"读，**只装负面清单**（画面：变形/手部异常/服装变化/现代元素/字幕/Logo/水印；文字；音频）——**正向执行指令禁入该栏**（写进去既不当禁令也不当指令），**否定式禁令同样禁入该栏**（被禁词根＝画面词），正向指令一律回落【时间轴分镜】镜行/【画幅风格】/【站位声明】。水印/变形等**低关联瑕疵**仍走否定式兜底，两类不冲突。**具象光源映射（C19d）**：反光道具镜行禁写「映出/倒映火苗」——模型不理解「反射」，会把「映出+光源名词」读成光源出现在道具上；**零光效描写**，只写材质本色（「玉面呈青玉原色」）。**镜行少形容词**：正向描写每镜只留必要项（主体/动作/材质/光各一处），修饰词堆叠会稀释关键信息、拉低服从率。规程见 `model-adapters.md` §5.0.4，出稿机检 **C19**（a 裸禁令词/b 光路触发器/c 首镜主体优先/d 具象光源映射/e 禁止项栏目纪律）兜底（全量出稿机检 C1~C19）。

23. **首镜单主体锚定与具象化（V6.9.7 新增 · 防"两张脸"）**：三条铁律（病灶来自实拍拉片，用户原话："总共生成了两张脸，最大的祸首就是这儿"）：① **锚定句只许一个具名主体**——**禁「X 与 Y 同框」类并列主体句式**：模型把并列名词 +「同框」读成"画面里有两个主体"，于是把同一主体的手与脸渲染成**两个头**（❌「首帧即这只手与她的脸同框」→ ✅「画面主体：她蜷卧土炕、病容苍白。她的一只手搭在破被外」）；确需两个人物同镜，由【站位声明】具名双主体承载，**镜行内不写「同框 / 同在画面 / 一同入画」**（机检 C20a）；② **指代词必须带归属**——「这只手 / 那张脸」无先行词时模型会**自己补一个主体**（补出一个头），一律写「她的一只手 / 他的右手」（机检 C20b）；③ **抽象形态·程度副词一律删**——「成线 / 成串 / 如注 / 轻蜷 / 微蜷」描述的是**模型无法命名的过程形态**，AI 只渲染可命名的具象形态（❌「漏雨成线砸在手背上」+「手指轻蜷」→ ✅「雨滴砸在手背上溅开」）。**判据一句话：这句里每个词都能画出来吗？画不出来的就是形容词——删掉或换具象动作。** ④ **反光道具零光效描写（V6.9.7 续增 · C20d）**——光斑/受光/照射/照在/亮起类从句一律不写，道具不靠近灯火，只写材质本色（「玉面呈青玉原色」/「哑光金属本色」）。规程见 `model-adapters.md` §5.0.2 / §5.0.3 / §5.0.4，出稿机检 **C20**（a 并列主体 / b 悬空指代 / c 抽象形态 / d 道具光效·贴近光源）兜底。

24. **示范句验证纪律（V6.9.7 根因复盘新增 · 治"规则层产毒"）**：历轮废镜的共同源头是**示范句先验创作**——当轮凭理解新造、未实拍验证就写成 ✅ 正例（甚至嵌进机检修复建议文案），产物照抄后成为下一轮翻车源。铁律：**正例只准从实拍通过的产物回收【实证】；新造句必须标【待验证·未实拍】且禁入机检修复建议文案；修复建议只写判据不造句；判据升级必须同轮清扫全部下游文档**。规程见 `model-adapters.md` §5.0.5，包级机检 **⑰ 规则自洽门**兜底（规则文档自己过自己的禁令）。

25. **角色概念设计·题材风格自适应（防脸盲与题材错配）**：角色形象出图词一律按 `character-concept-designer.md` 生成——先按题材命中判断风格类型（国风/现代/科幻/西幻/民国/中式克苏鲁，**禁止默认国风古装**）；五官必写具体选型（脸型/眉形/眼型/鼻型/唇形，**禁笼统"精致五官"**），按角色气质差异化；服装按风格库配 ≥4 种材质对撞、合规领口与鞋履（禁赤足/禁暴露胸部）；形象词并入所选 STYLE 画风档与 4 View 资产板出图锁定，半身 4:3 / 全身 9:16 分别作 Face Close-up / Front View 的载体；跨镜唯一形象来源仍为资产板 + `--ref`。**中式克苏鲁题材**额外启用怪诞变体（非自然肤色/多瞳/纸人笑/解构服装等），但保持"类人而非人"、不露骨不引起强烈不适。
