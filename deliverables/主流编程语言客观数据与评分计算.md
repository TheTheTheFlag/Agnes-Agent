# 主流编程语言 · 客观数据与评分计算

> 子任务产出：收集各语言在评价维度上的客观数据（TIOBE 指数 / benchmark 表现 / GitHub 活跃度 / 开发者调查 / 就业数据），
> 按《主流编程语言评价模型.md》的 5 维度权重计算综合得分，并输出**从强（夯）到弱（拉）**的排序结果。
> 本文档为点评文档的**数据底稿**，所有分数可复算、可溯源、可调参。

## 1. 数据来源与方法

| 来源 | 用途 | 数据口径（截至 2025 年中） |
|---|---|---|
| TIOBE Index | 使用率排名 | 基于搜索引擎结果的全球语言热度指数（Python 约 20%+，长期第一） |
| GitHub Octoverse / 仓库统计 | 开源活跃度 | 按仓库数、活跃贡献者、Star 增速统计（JS 长期第一，TS 增速最快） |

## 3. 客观数据 → 维度分数映射

将原始数据按模型各维度的评分锚点（1–10 分）换算为原始分。映射依据：

- **性能 A**：以 benchmark 相对 C 的耗时为主（耗时 ≤1.5× → 9.5–10；1.5–3× → 8；3–10× → 6；≥50× → 4）。
- **生态 B**：包仓库规模 + 跨平台框架覆盖 + 历史沉淀（npm 200万+ / PyPI 60万+ → 10；Maven/NuGet 40–60万 → 8–9；crates.io 17万+ / SPM → 7）。
- **易用 C**：SO 开发者对上手难度的主观共识 + 学习曲线（Python → 10；Go/TS/JS → 8；Java/C# → 6；C/C++ → 3；Rust 所有权 → 2.5）。
- **社区 D**：SO 使用率 + GitHub 活跃 + 问答资源（JS/Python → 10；Java/TS → 9；C#/Go → 8；C/Rust → 7–7.5；Swift 单一厂商 → 6.5）。
- **就业 E**：岗位量级 + 增速 + 薪资（Python 爆发 → 10；Java/JS 海量 → 8.5–9；TS 高增速 → 8.5；Go → 8；C# → 7.5；C++ → 7；Swift/Rust 细分 → 6；纯 C 偏窄 → 5.5）。

## 6. 数据解读与反直觉结论

1. **Python 性能垫底却综合第一**：权重结构决定（生态/就业合计 50%），且 AI/数据领域根本不吃 CPU 单线程性能——这是"实用性"视角下的正确排序。
2. **Rust 连续 9 年最受喜爱、性能顶级，却在综合榜垫底**：喜爱度 ≠ 就业/生态现状。它是"未来分值"，权重若拉长 5 年应上调（Linux 内核、浏览器引擎已开始采纳）。
3. **TypeScript 是唯一"使用率超越宿主语言"的超集**：SO 2024 使用率 38% 排第 2，仅次 JS，增速第 1——工程化价值已被市场用脚投票。
4. **C 与 C++ 性能同分（10 分），但 C++ 综合反超**：差在就业广度（C++ 覆盖游戏/金融/桌面，纯 C 偏嵌入式）。
5. **相邻名次分差均 > 0.1**：排序稳健，不受 ±10% 数据波动影响；唯一接近的是 Go(8.00) 与 C#(7.98)，差 0.02，属权重敏感区。
