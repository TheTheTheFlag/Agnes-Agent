## 4. 缺陷清单与修复

| ID | 缺陷描述 | 严重度 | 修复方案（v1.3） |
| --- | --- | --- | --- |
| D1 | 按住空格/P/M 时 keydown 重复触发，暂停/开始/静音被高频抖动切换 | 高 | keydown 增加 `e.repeat` 拦截 |
| D2 | 切出标签页/窗口失焦不暂停，切回时可能瞬间误撞 | 高 | `blur` + `visibilitychange` 时若 play 则自动 pause 并清空按键 |
| D3 | 触摸仅点按变道、无法拖动；滑动出画布丢方向 | 中 | `pointermove` 连续变道 + `setPointerCapture` + pointercancel 清理 |
| D4 | 帮助文案声称"↑↓/WS 微调速度"但代码未实现 | 高 | 新增 `speedAdj`（±80 钳制、松键缓回）并计入目标速度 |
| D5 | 金币与同车道车辆重叠生成，视觉与判定冲突 | 中 | 生成时随机打乱车道顺序，优先选择无车车道，全占时兜底 |
| D6 | 高速低帧率下碰撞"隧穿"：单帧位移（≤26px）可越过 48px 判定带漏判 | 高 | 新增扫描体 `PX.sweptV`（竖直区间连续相交判定）+ dt 上限降至 0.04 |
| D7 | 无敌期穿过车辆仍计"贴边 +15" | 低 | 贴边判定增加 `invincible <= 0` 条件 |
| D8 | HUD 心形用字符 '♥'，部分系统/字体渲染为方块 | 低 | 改为像素心形精灵（离屏预渲染） |
| D9 | 粒子/飘字频繁 new 对象，长局 GC 抖动 | 低 | 对象池复用（freeParts/freePopups） |
| D10 | 每帧数千次逐像素 `fillRect` 与 `fillStyle` 切换（性能瓶颈） | 高 | 精灵与静态背景离屏预渲染，运行时仅 `drawImage`（见 §5） |
| D11 | `canvas.getContext('2d')` 未判空，异常环境直接抛错白屏 | 中 | 判空 + 页内友好错误提示 |
| D12 | 游戏中 HUD 的 BEST 不实时刷新（破纪录不显示） | 低 | 运行中实时更新 best；结束时按 `bestBefore` 判定"新纪录"再落盘 |
| D13 | 无 `requestAnimationFrame` 的旧环境直接报错 | 低 | rAF → setTimeout 降级兜底；keyCode 兼容 |

## 5. 性能优化措施与量化

| 编号 | 优化 | 说明 | 量化 |
| --- | --- | --- | --- |
| P1 | 精灵离屏预渲染 | 玩家/4 色车/金币/树/心形一次性绘制到小 canvas，运行时 `drawImage` | 消除 v1.2 中约 1500+ 次/帧逐像素矩形 |
| P2 | 静态背景预渲染 | 草地棋盘格 + 路面 + 路缘合并为单张背景位图 | 140+ 次矩形 → 1 次 `drawImage` |
| P3 | 动态元素最小化 | 车道虚线仍动态滚动（保持动效），仅 ~30 矩形/帧 | 保持视觉正确性 |
| P4 | 对象池化 | 粒子、飘字对象复用 | 降低长局 GC 压力 |
| P5 | 非 play 态短路 | `update()` 在非 play 状态直接返回 | 菜单/暂停/结算不跑逻辑 |
| P6 | dt 钳制 + 扫描碰撞 | dt ≤ 0.04s + sweptV 保证高速帧稳定 | 兼顾性能与正确性 |

**量化结论（perf_sim.js，≈4 秒游戏进程后统计单帧）：**

| 指标 | v1.2 | v1.3 | 降幅 |
| --- | --- | --- | --- |
| 总绘制调用 | 1625 | 84 | **-94.8%** |
| fillRect | 1613 | 58 | **-96.4%** |
| 状态切换（fillStyle 等） | 1540 | 76 | **-95.1%** |

> 注：以上为 API 调用次数（模拟桩统计），GPU 实际耗时与设备相关，但调用量降低两个数量级可直接转化为 CPU/渲染线程负载的大幅下降，对低端移动设备与高 DPI 显示尤为有效。

## 6. 跨环境稳定性保障

| 环境 | 保障措施 |
| --- | --- |
| Chrome / Edge / Firefox（桌面） | 标准 Canvas2D + WebAudio；`image-rendering: pixelated/crisp-edges` |
| Safari / iOS / Android（移动） | `touch-action:none`、viewport 缩放禁用、pointer 事件拖动、`-webkit-tap-highlight-color` |
| `file://` 双击打开（离线） | 零外部依赖；localStorage 读写 try/catch 容错 |
| 隐私模式 / localStorage 禁用 | 高分读写降级为内存态，不影响运行 |
| 无 Canvas2D 的旧环境 | 判空 + 页面提示，不再白屏 |
| 无 `requestAnimationFrame` | setTimeout(16ms) 降级；`performance.now()` 取时间 |
| 无 AudioContext | `snd()` 内部 try/catch，静默降级 |
| 标签页隐藏/失焦 | 自动暂停 + 恢复后 dt 钳制，无跳变/误撞 |
| Node（无 DOM） | 自动导出 PX 纯逻辑模块，可无缝单元测试 |
