# PIXEL RACER — 像素赛车游戏设计文档

> 交付物：`deliverables/pixel-racer/index.html`（单文件、零依赖、可直接在浏览器打开游玩）
> 技术栈：HTML5 Canvas + 原生 JavaScript（Web Audio API 合成音效），逻辑分辨率 320×480，CSS 像素放大渲染。

---

## 1. 玩法规则

### 1.1 核心循环
- 玩家驾驶一辆像素跑车，在 4 车道高速公路上无尽行驶（竖版俯视、路面向下滚动）。
- 躲避同向/慢速的车流，收集金币得分，跑得越远得分越高。
- 撞车扣 1 条命（共 3 条），生命归零则游戏结束；得分破纪录会标记 `NEW RECORD!`。

### 1.2 计分系统
| 行为 | 得分 |
|---|---|
| 每行驶 1 秒（按里程折算） | +0.05 × 当前速度 |
| 超越一辆车（从其后滑到其前） | +10 |
| 收集 1 枚金币 | +50 |
| 最高分 | 本地存储 `localStorage`（跨会话保留） |

### 1.3 生命与惩罚
- 初始 3 条命（HUD 左下角心形显示）。
- 撞车后：扣除 1 命、速度清零、2.2 秒无敌闪烁期、火花粒子爆炸特效。
- 无敌期内可自由穿车，避免连续扣命带来的挫败感。

### 1.4 难度曲线
- 最高速度随里程线性提升：`maxSpeed = 175 → 260 km/h`。
- 车流生成间隔随里程缩短：`1.5s → 0.55s`。
- 无输入时自动巡航 100 km/h；加速（↑/W/空格）、刹车（↓/S）可控制速度。

## 2. 像素风格界面

### 2.1 分辨率与放大策略
- 逻辑分辨率 **320×480**（2:3 竖屏），所有精灵/文字用整数像素块绘制。
- CSS：`image-rendering: pixelated` + 等比放大（桌面最大 520px，移动端自适应视口），保证放大后边缘锐利、无模糊插值。

### 2.2 自绘 5×7 像素字体
- 内置 ASCII 像素字体（A–Z、0–9、符号），全部游戏文案（SCORE / SPEED / GAME OVER 等）由该字体逐像素绘制，不依赖任何外部字体或网络加载，离线可用且风格统一。
- 支持 scale 缩放与左/中/右对齐。

### 2.3 界面状态机
| 状态 | 内容 |
|---|---|
| `menu` 主菜单 | 大标题 PIXEL RACER、车辆颜色选择（红/蓝/绿/金）、操作说明、闪烁的"PRESS ENTER / TAP TO START"，背景为缓慢滚动的演示车流 |
| `playing` 游戏中 | HUD（分数/金币/最高分/声音状态/速度条/生命）+ 完整赛道场景 |
| `paused` 暂停 | 画面冻结 + `PAUSED` 半透明遮罩（P/Esc 切换） |
| `over` 结算 | GAME OVER、最终分数、最高分、金币、里程、超车数、重开提示 |

### 2.4 HUD 布局（playing）
- 顶栏：左 `SCORE`，中 `COINS n`（金色），右 `BEST` 与 `M:ON/OFF`。
- 底部中央：大字速度 `NNN KM/H`。
- 左侧：垂直速度条（绿→黄→红 三档配色）。
- 左下：3 颗像素心形生命。

## 3. 车辆与赛道元素

### 3.1 玩家车辆
- 程序化像素绘制（`fillRect` 组合），约 12×24 逻辑像素：
  - 4 个黑色车轮、车身主体、引擎盖高光、侧影暗部、浅蓝挡风玻璃、深色车顶、黄色车头灯、红色尾灯、白色玩家识别条。
- 可选 4 种车身颜色：红 / 蓝 / 绿 / 金。
- 碰撞盒略小于贴图（6×12 半宽高），提升手感。

### 3.2 敌方车流
- 6 种配色（灰、紫、青、橙、蓝、粉），随机速度 35–130 km/h。
- 12% 概率生成"大车"（更长更宽，视觉与碰撞盒同步放大）。
- 只在固定车道直行（无换道），相对玩家向后滑动；被超过后标记并计分。

### 3.3 赛道元素
| 元素 | 绘制方式 |
|---|---|
| 草地 | 深绿底 + 预生成 70 个伪随机小草斑点（滚动取模循环） |
| 路面 | 深灰沥青带 |
| 路肩 | 红/白相间 24px 交替块，随路面同步滚动 |
| 车道线 | 3 条白色虚线（18px 段 + 18px 间隔），按滚动取模无缝循环 |
| 行道树 | 两侧周期性出现的像素树（树干 + 双层树冠），间隔 150px 滚动 |
| 金币 | 8×8 金色方块 + 高光，亮度按正弦闪烁 |

### 3.4 特效
- 碰撞火花粒子：橙/黄/红/白 2px 方块，带初速度与重力，寿命内渐隐。
- 无敌闪烁：玩家贴图以 12Hz 交替显隐。

## 4. 控制方式

### 4.1 键盘（桌面）
| 按键 | 功能 |
|---|---|
| ← / → 或 A / D | 左右转向（车道内自由移动） |
| ↑ / W / 空格 | 加速（空挡自动巡航 100 km/h） |
| ↓ / S | 刹车/减速 |
| P / Esc | 暂停 / 继续 |
| M | 静音 / 恢复声音 |
| Enter / 空格 | 菜单开始 / 结算重开 |
| ← / → | 主菜单切换车辆颜色 |

### 4.2 触摸（移动端）
- 拖动手指控制车辆横向位置（手指 x 坐标映射到道路范围）。
- 触摸期间自动巡航加速；菜单/结算界面轻触即可开始或重开。
- `touch-action: none` 禁用浏览器默认手势，防止误滚动。

## 5. 音效方案（Web Audio API 合成，零音频文件）

| 音效 | 合成方式 |
|---|---|
| 引擎声（循环） | 锯齿波振荡器 + 低通滤波；频率 `50+速度×0.85Hz` 随速度实时升高，音量随速度增大，营造加速感 |
| 收集金币 | 方波 1250→1850Hz 短促上滑"叮"声 |
| 撞车 | 锯齿波 170→38Hz 下滑 + 白噪声爆发 |
| 超车 | 方波 880→1320Hz 轻快"哔" |
| 开始 / 选择 / 暂停 | 方波双音 / 620→880 / 520Hz 短音 |
| 游戏结束 | 锯齿波 330→55Hz 长下滑 |

- 所有音效运行时合成（`AudioContext` 懒初始化，首次用户交互后启动，符合浏览器自动播放策略）。
- 全局主音量增益节点统一控制，`M` 键静音；HUD 右上实时显示 `M:ON / M:OFF`。

## 6. 技术实现要点

- **主循环**：`requestAnimationFrame` + 增量时间（clamp ≤ 33ms），逻辑与渲染分离，全部按 dt 缩放保证帧率无关。
- **伪随机**：草地斑点使用确定性线性同余生成器（固定种子），避免每帧抖动。
- **滚动无缝**：路面标记/路肩/树木/金币均按 `scrollY % 周期` 取模绘制，无限循环不漂移。
- **对象池简化**：数组 + 越界剔除；碰撞使用 AABB 矩形相交检测。
- **数据持久化**：最高分写入 `localStorage('pixelRacerBest')`，异常时安全降级。
