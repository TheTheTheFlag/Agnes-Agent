# PIXEL RACER — 游戏设计文档（子任务：游戏设计）

> 子任务编号：T2 游戏设计
> 目标：确定「像素风格」「赛道布局」「赛车属性」「控制方式」「核心玩法规则」五大设计项，作为后续代码实现、测试与交付的唯一设计依据。
> 技术基调：HTML5 Canvas + 原生 JavaScript，单文件、零外部依赖，逻辑分辨率 320×480，CSS `image-rendering: pixelated` 整数倍放大渲染。
> 本文件为设计定稿；后续实现如与本文冲突，以本文为准并记录到变更说明。

---

## 1. 设计总览（Design Pillars）

| 支柱 | 说明 |
|---|---|
| **复古像素** | 全程程序化绘制，无位图资源；所有元素由整数像素块构成，放大后边缘锐利 |
| **易上手** | 30 秒内学会：一个方向键躲车、一个加速键冲分 |
| **正反馈** | 超车/吃金币/破纪录即时给分、给音效、给粒子特效 |
| **无尽挑战** | 里程驱动的难度曲线，跑得越远越刺激，无终点 |

## 2. 像素风格（Pixel Style）

### 2.1 分辨率与渲染
- 逻辑分辨率 **320×480**（2:3 竖屏，适配移动端竖持习惯）。
- 画布由 CSS 等比放大：桌面最大宽度 520px，移动端占满视口宽度。
- 关键 CSS：`image-rendering: pixelated; image-rendering: crisp-edges;` 禁用插值模糊。
- 所有精灵（车、树、金币、文字）用 `fillRect` 整数坐标绘制，禁止亚像素坐标。

### 2.2 自绘像素字体
- 内置 **5×7 像素字体**（A–Z / 0–9 / 常用符号），逐像素点阵渲染。
- 支持 scale 缩放、左/中/右对齐；用于 SCORE、SPEED、GAME OVER 等全部文案。
- 不依赖外部字体/CDN，离线可用，风格与游戏整体统一。

### 2.3 调色板（限定色域，保证统一感）
| 用途 | 建议色值（HEX） |
|---|---|
| 草地 | `#2d7a3a`（深绿底）、`#3fa64f`（草斑点） |
| 路面 | `#3a3d44`（沥青）、`#4a4e57`（车辙） |
| 路肩 | `#e03a3a`（红）与 `#f2f2f2`（白）交替 |
| 车道线 | `#e8e8e8` 半透明白虚线 |
| 玩家车身 | 可选：红 `#d22` / 蓝 `#26a` / 绿 `#2a8` / 金 `#db0` |
| 敌方车 | 灰 `#8a8a93`、紫 `#7a5aa0`、青 `#3aa8b0`、橙 `#e07a2a`、蓝 `#3a6ac8`、粉 `#c85a8a` |
| 金币 | `#ffd23f` 金 + `#fff7c0` 高光 |
| UI 文字 | `#ffffff`、高亮 `#ffd23f`、警告 `#ff5a5a` |

### 2.4 像素化表现细节
- 车 12×24 逻辑像素：黑色车轮、车身、引擎盖高光、挡风玻璃、车灯、尾灯。
- 草地散布 70 个伪随机小草斑点，滚动取模循环，避免重复感。
- 特效粒子为 2px 方块；无敌状态 12Hz 交替闪烁（保持像素"闪屏"复古感）。

## 3. 赛道布局（Track Layout）

### 3.1 结构
- **竖版无尽高速路**：路面自下向上滚动（模拟车向前行驶），玩家在画面内横向移动。
- 赛道宽度 4 条车道，逻辑宽度约 200px（居中于 320px 画面），两侧为草地与行道树。
- 车道由 3 条白色虚线分隔（18px 段 + 18px 间隔，取模无缝循环）。
- 两侧路肩为红/白 24px 交替块，随路面同步滚动。

### 3.2 滚动静物（装饰层）
| 元素 | 间距 | 行为 |
|---|---|---|
| 行道树 | 每 150px 一棵 | 树干 + 双层像素树冠，左右两侧交替出现 |
| 小草斑点 | 预生成 70 个 | 伪随机分布，滚动取模循环 |
| 路肩块 | 24px 一块 | 红/白交替，滚动循环 |

### 3.3 动线（可移动物体层）
- 金币：8×8 金色方块 + 高光，亮度按正弦闪烁；随机出现在车道内。
- 敌方车：固定车道直行（不换道），速度 35–130 km/h，相对玩家后移。
- 玩家车：不滚动（屏幕固定），仅横向移动 + 纵向视觉随加速轻微前倾。

### 3.4 布局约束
- 敌方车生成间隔随里程缩短：`1.5s → 0.55s`（难度曲线）。
- 相邻车道同帧必留可通行缝隙，保证永远存在"逃生路线"（可玩性底线）。
- 车道边缘禁止贴边出生，避免"出生即撞"的不公。

## 4. 赛车属性（Car Attributes）

### 4.1 玩家车
| 属性 | 数值 | 说明 |
|---|---|---|
| 尺寸 | 12×24 px | 逻辑像素 |
| 碰撞盒 | 6×12 px（半宽高） | 小于贴图，提升手感（宽容判定） |
| 巡航速度 | 100 km/h | 无加速输入时的自动行驶速度 |
| 最高速度 | 175 → 260 km/h | 随里程线性提升 |
| 加速度 | 约 +45 km/h/s | 按住加速键时 |
| 刹车减速度 | 约 -70 km/h/s | 按住刹车键时 |
| 横向移动速度 | 约 3.2 px/帧（60fps） | 左右移动 |
| 生命 | 3 条 | HUD 心形显示 |
| 可选配色 | 红/蓝/绿/金 | 主菜单切换 |

### 4.2 敌方车
| 属性 | 数值/说明 |
|---|---|
| 尺寸 | 12×24 px；12% 概率为大车（约 16×32 px，碰撞盒同步放大） |
| 速度 | 35–130 km/h 随机 |
| 配色 | 6 种（灰/紫/青/橙/蓝/粉） |
| 行为 | 固定车道直行、不换道、无 AI 变线 |

### 4.3 属性平衡原则
- 玩家速度永远高于最慢车流（保证"超车"这一核心快感可稳定触发）。
- 大车速度更慢且更长 → 制造"绕行决策"，增加策略性。
- 碰撞盒小于贴图 → 容错，避免"蹭到就算撞"的挫败。

## 5. 控制方式（Controls）

### 5.1 键盘（桌面端）
| 按键 | 功能 |
|---|---|
| ← / → 或 A / D | 左右转向（车道内自由移动） |
| ↑ / W / 空格 | 加速（按住）；松开回到巡航 100 km/h |
| ↓ / S | 刹车 / 减速 |
| P / Esc | 暂停 / 继续 |
| M | 静音 / 恢复声音 |
| Enter / 空格 | 菜单开始 / 结算重开 |
| ← / →（主菜单） | 切换车辆颜色 |

### 5.2 触摸（移动端）
- **拖拽控制**：手指水平拖动 → 车辆横向跟随（手指 x 映射到道路范围）。
- 触摸期间自动巡航加速；菜单/结算界面轻触即开始或重开。
- `touch-action: none` 禁用浏览器默认滚动/缩放手势。

### 5.3 输入设计原则
- 加速、转向可同时按住（多键无冲突）。
- 无输入 = 自动巡航，不会"静止罚站"。
- 全部按键有桌面 + 移动双通道，保证任何设备可玩。

## 6. 核心玩法规则（Core Gameplay Rules）

### 6.1 核心循环
`躲避车流 → 收集金币 → 超车得分 → 里程提升难度 → 撞车扣命 → 生命归零结算`

### 6.2 计分系统
| 行为 | 得分 |
|---|---|
| 行驶（按里程折算） | +0.05 × 当前速度 / 秒 |
| 超越一辆车（后→前） | +10 |
| 收集 1 枚金币 | +50 |
| 最高分 | localStorage 持久化，破纪录显示 `NEW RECORD!` |

### 6.3 生命与惩罚
- 初始 3 命；撞车 -1 命，速度清零，2.2 秒无敌闪烁期，火花粒子爆炸。
- 无敌期内可自由穿车（避免连环扣命）。
- 生命归零 → GAME OVER，显示最终分数 / 最高分 / 金币 / 里程 / 超车数。

### 6.4 难度曲线（里程驱动）
| 里程（m） | 玩家最高速 | 车流生成间隔 |
|---|---|---|
| 0 起 | 175 km/h | 1.5 s |
| 递增 | 线性至 260 km/h | 线性至 0.55 s |

### 6.5 界面状态机
| 状态 | 说明 |
|---|---|
| `menu` | 大标题、配色选择、操作说明、闪烁 "PRESS ENTER / TAP TO START"、背景演示车流 |
| `playing` | HUD（分数/金币/最高分/声音/速度条/生命）+ 完整赛道 |
| `paused` | 画面冻结 + PAUSED 半透明遮罩 |
| `over` | 结算面板 + 重开提示 |

### 6.6 HUD 布局（playing 态）
- 顶栏：左 `SCORE`、中 `COINS n`（金色）、右 `BEST` 与 `M:ON/OFF`。
- 底部中央：大字速度 `NNN KM/H`。
- 左侧：垂直速度条（绿→黄→红）。
- 左下：3 颗像素心形生命。

### 6.7 胜负与循环规则
- 无通关终点；一局结束 = 生命耗尽。
- 重开 = 数据清零、难度回到初始、最高分保留。
- 支持中途暂停/续玩，暂停不计时不计分。
