# PIXEL RACER · 像素赛车 — 版本更新记录（Release Notes）

## v1.1（正式发布版 / 2026-02-17）

**发布状态**：✅ 稳定版。功能完整、60FPS、通过全部回归测试（见 TEST_REPORT.md）。

### 新增 / 优化
- 失焦（切后台 / 切窗口）自动暂停，恢复焦点后手动继续。
- 移动端支持拖动连续转向（原仅支持点按）。
- 静音增加视觉反馈：HUD「MUTE」文字 + 右下角 🔊 / 🔇 悬浮按钮。
- 绘制距离自适应：低端设备帧率偏低时自动缩短视距（100~160 段），保证流畅。
- 远距离阴影裁剪 + 渲染常量化，性能进一步提升。

### 缺陷修复
| 级别 | 问题 | 修复 |
|---|---|---|
| 严重 | 高速（9000u/s 以上）可穿透车流 / 金币（隧穿） | 碰撞判定窗口随本帧位移动态扩展 |
| 严重 | 禁用存储（隐私模式）时页面加载即崩溃 | 封装安全存取，异常时静默降级 |
| 中等 | 撞车重开后按键状态残留，出现自动加速 | 开局统一清零按键状态 |
| 中等 | 切后台空转耗电 / 恢复时瞬移 | visibilitychange + blur 自动暂停 |
| 中等 | 移动端无法拖动连续转向 | 增加 pointermove 处理 |
| 低 | 静音无任何提示 | HUD 文字 + 图标按钮 |

### 已知限制（低优先级，不影响交付）
- 未提供降速 / 减帧无障碍选项；键盘 Tab 无法聚焦画布内元素。
