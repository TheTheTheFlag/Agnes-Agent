## 1. 游戏简介

《Pixel Racer》是一款复古像素风格的纵版赛车小游戏。您操控一辆赛车在高速公路
上疾驰，躲避迎面驶来的车流与障碍，收集金币与道具提升分数。速度越快、连续
无碰撞时间越长，得分越高。游戏全部使用原生 HTML5 Canvas + JavaScript 实现，
无需安装任何第三方依赖，单文件即玩。

## 4. 运行方法

### 方式一：直接打开（推荐，最简单）
1. 解压 `dist/pixel-racer-v1.1.zip`；
2. 双击 `index.html`；
3. 浏览器将自动打开游戏画面。

### 方式二：通过本地服务器运行（可选）
```bash
# 在游戏目录下，任选其一
python -m http.server 8080
# 或
npx serve .
```
然后访问：`http://localhost:8080`。

## 6. 玩法与目标

1. 点击「开始游戏」或按空格开始；
2. 控制赛车躲避迎面而来的**敌方车辆**与**障碍物**；
3. 收集**金币**加分，拾取**道具**获得加速/护盾等增益；
4. 游戏随里程增加而逐渐提速，难度递增；
5. **撞车即游戏结束**——坚持越久、得分越高；
6. 游戏结束后按空格可立即重新开始。

### 得分规则
- 生存时间：每存活 1 秒累计基础分；
- 金币：每个 +10 分；
- 连续无碰撞奖励：无碰撞时间越长，连击倍率越高；
- 最终得分 = 生存分 × 连击倍率 + 金币分。

## 7. 常见问题（FAQ）

**Q1：双击后浏览器没有打开？**
→ 请右键 `index.html` → 选择「打开方式」→ 选择 Chrome 或 Edge。

**Q2：画面卡顿？**
→ 关闭其他占用 GPU 的标签页；游戏自动使用 60fps 循环，性能较差设备会自动降帧。

**Q3：键盘没反应？**
→ 点击游戏画面使其获得焦点后再操作；确认输入法为英文状态。

**Q4：想修改难度？**
→ 用记事本打开 `index.html`，搜索 `SPEED` 或 `obstacleInterval` 等常量即可微调。
