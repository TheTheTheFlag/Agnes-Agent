# 像素极速 PIXEL RACER — 游戏交付

像素风格街机竞速小游戏，依据 `deliverables/pixel-racer-gameplay-design.md` v1.0 实现。

## 文件说明

| 文件 | 说明 |
|---|---|
| `index.html` | 游戏本体（单文件、零依赖，可直接用浏览器打开） |
| `../../config/tuning.json` | 策划可热调参数表（启动时尝试加载，失败用内置默认值） |

## 运行方式

- 直接双击 `index.html`，或本地起一个静态服务器：
  ```bash
  python -m http.server 8080
  # 浏览器打开 http://localhost:8080/deliverables/pixel-racer/
  ```
- 推荐横屏；桌面键盘操作，移动端自动出现虚拟按键。

## 操作

| 按键 | 功能 |
|---|---|
| ← / → 或 A / D | 转向 |
| ↑ / W / 空格 | 油门（按住加速至巡航 480px/s） |
| ↓ / S | 刹车 |
| Shift | 氮气冲刺（漂移集气，最多存 2） |
| P / Esc | 暂停 |
| M | 静音 |

## 已实现特性（对照设计文档）

- **像素画风渲染**：480×270 逻辑分辨率 + 像素锐利放大、程序化像素精灵（玩家车 / 多彩车流 / 4 帧旋转金币 / 道具图标）、3 层视差背景、霓虹赛道与护栏。
- **赛车控制**：累计位移转向 + 每帧 0.86 阻尼、三档速度（巡航/刹车/氮气极速）、触屏虚拟按键。
- **碰撞检测**：AABB 外扩 1px 容错；撞击车流/路障减速 45%+扣 10% 金币+连击清零+震屏闪红；撞护栏减速 15% 不清连击；氮气期间碰撞免疫。
- **计分**：里程分（无尽每 10m +1）、金币 +10、金币桶 +500、贴边 +2/秒/层、漂移 +50、漂移门 +500、氮气 +30/0.5s、关卡通关 +1000 与提前时间奖励；连击倍率 ×1~×3；分数上限 9,999,999。
- **界面显示**：7 段式大数字分数、金币/距离/速度/生命/氮气条 HUD、连击弹出、关卡进度条、主菜单 / 关卡选择 / 排行榜 / 帮助 / 暂停 / 结算界面、本地排行榜（Top10，localStorage 存档）。
- **游戏模式**：无尽模式（里程递增难度，3 次撞击结束）+ 6 关主线（星级评定、逐关解锁、时间/收集率结算）。
- **道具**：氮气 / 护盾 / 磁铁 / 双倍分 / 慢速云 / 金币桶。

## 可调参数

数值集中在 `config/tuning.json`（与设计文档 §7 一致），修改后刷新页面即可生效。
