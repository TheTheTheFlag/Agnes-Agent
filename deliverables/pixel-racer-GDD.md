## 1. 核心玩法（Core Gameplay）

### 1.1 游戏定位与核心乐趣

- **一句话概述**：玩家驾驶像素小赛车，在俯视像素赛道上与 AI 对手竞速 3 圈，通过**漂移积攒氮气**、**氮气冲刺**、**切弯超车**获得名次。
- **核心乐趣三支柱**：
  1. **漂移的爽感**——手刹漂移、轮胎烟、氮气反馈、屏幕震动；
  2. **竞速的悬念**——AI 动态调速（rubber-banding），胜负咬到最后一圈；
  3. **复古的怀旧**——16-bit 像素美术、芯片音乐（Chiptune）、街机式结算。

### 1.2 游戏循环（Core Loop）

```
选车（属性取舍）→ 选赛道/难度 → 倒计时起跑（抢跑判定）
  → 竞速 3 圈（漂移攒氮气 → 氮气冲刺 → 道具互动 → 检查点）
  → 冲线结算（名次/用时/单圈/漂移分）
  → 解锁新赛道/新车 → 回到选车
```

### 1.3 游戏模式

| 模式 | 说明 | 解锁条件 |
|------|------|----------|
| 快速比赛 Quick Race | 单场 3 圈，可选赛道 × 难度（简单/普通/困难） | 默认开放 |
| 锦标赛 Championship | 3 场连赛积分制（10/8/6/5/4/3/2/1），总积分夺冠 | 完成 1 场快速赛 |
| 计时赛 Time Attack | 无 AI，刷最快圈速，配 Ghost 影子车回放 | 完成 2 场快速赛 |
| 漂移练习 Drift School | 空旷场地，仅练漂移与氮气，附教学提示 | 默认开放 |

### 1.4 操作方式

| 按键 | 功能 | 备注 |
|------|------|------|
| ↑ / W | 油门 | 按住持续加速 |
| ↓ / S | 刹车 / 倒车 | 低速时可倒车 |
| ← → / A D | 转向 | 速度越高转向半径越大 |
| Shift | 手刹漂移 | 转弯时按住进入漂移 |
| 空格 Space | 氮气喷射 | 需氮气条有存量 |
| P / Esc | 暂停 | 呼出暂停菜单 |
| M | 小地图开关 | 切换 HUD 小地图显隐 |
| R | 快速重开（结算页） | 结算界面可用 |

**触屏**：左下虚拟方向键（十字）、右下漂移键与氮气键（支持多点触控）。

### 1.5 车辆属性与物理

**车辆 5 项基础属性**（选车界面展示为像素条）：

| 属性 | 取值范围 | 效果 |
|------|----------|------|
| 极速 TOP | 140～180 km/h（像素车速计） | 决定最高速度 |
| 加速 ACC | 0～10 | 决定从 0 到极速所需时间 |
| 操控 HAN | 0～10 | 决定转向灵敏度与漂移稳定性 |
| 抓地 GRI | 0～10 | 抓地越高漂移半径越小、越易失控 |
| 氮气 NIT | 0～10 | 决定氮气容量与喷射加速度 |

**物理模型（简化数值）**：
- 每帧 `速度 += 加速度 * dt - 阻力 * 速度 * dt`；
- 转向角速度 = `基础角速度 * (HAN/10) * (1 - 速度/极速 * 0.6)`（高速转向迟钝）；
- 漂移中转向半径 ×1.6，横向滑移速度按 `0.35 * 当前速度` 叠加；
- 撞墙损失 35% 动能并反弹，0.5s 硬直；
- 出界（草地/沙地）减速至 45%、转向灵敏度下降、漂移不积攒氮气。

### 1.6 漂移与氮气系统（核心乐趣）

- **触发**：转弯时按住 `Shift`（或高速入弯自动进入轻漂移）。
- **积攒**：漂移每持续 1 秒积攒 25 单位氮气；漂移结束（回正）一次性结算入账，断漂不保留。
- **喷射**：空格喷射持续 1.2s，提速 28%，车尾喷蓝火粒子 + FOV 轻微拉近；冷却 0.8s。
- **奖励加成**：贴内线 +20%、漂移全程不撞墙 +10%、1s 内连续两次漂移衔接 +15%。

### 1.7 比赛规则细节

1. **起跑**：`3-2-1-GO` 每 1s 一帧大字；GO 前 0.3s 内松开发车键判为抢跑，罚时 2s。
2. **圈数与检查点**：默认 3 圈；赛道布设 6～8 个检查点，须顺序通过，漏检本圈无效并强制回退（提示 "MISSED CHECKPOINT!"）。
3. **冲线**：以车头越过终点线为准；按顺序结算名次。
4. **道具**（锦标赛 / 困难难度开启）：
   - 油桶（红白条纹）：撞击引爆，撞击者 -25% 速度 + 屏幕震动，可刷新；
   - 加速带（绿箭）：外侧弯道，压上 1.5s 提速 20%；
   - 轮胎路障（橙黑）：玩家撞上减速 20%，可推动滑行。

### 1.8 AI 对手

- 玩家 1 名；AI：简单 4 名 / 普通 5 名 / 困难 6 名。
- AI 沿预录"理想线"行驶 + 随机走线扰动；对玩家 ±2 车宽内避让。
- 难度越高，AI 越贴弯心、失误率越低。
- **动态调速**：落后玩家时提速至 105%，领先时回到 95%（幅度 ≤10%，保证悬念）。

### 1.9 计分与胜利条件

| 维度 | 规则 |
|------|------|
| 名次分 | 第1名 10 / 2nd 8 / 3rd 6 / 4th 5 / 5th 4 / 6th 3 / 7th 2 / 8th 1 |
| 漂移分 | 每累计 100 单位氮气计 50 分；漂移奖励加成按比例折算 |
| 单圈奖励 | 最快单圈 +20 分 |
| 胜利条件 | 快速赛：按冲线名次；锦标赛：3 场总积分最高者夺冠 |

### 1.10 关键数值平衡表（初版，待 Playtest 调参）

| 参数 | 初值 | 说明 |
|------|------|------|
| 基础加速度 | 18 px/s² | 车辆默认（ACC=5） |
| 最大速度 | 420 px/s | 车辆默认（TOP 对应） |
| 漂移氮气积攒 | 25/s | 漂移持续每秒 |
| 氮气容量 | 100 | 满条喷射约 1.2s |
| 氮气提速 | +28% | 相对当前最大速度 |
| 撞墙动能损失 | 35% | 单次撞击 |
| AI 调速范围 | ±10% | rubber-banding |
| 单圈长度 | 2200～2800 px | 3 圈总时长约 2～4 分钟 |

## 2. 界面布局（Interface Layout）

### 2.1 画布与缩放

- 逻辑分辨率：**960 × 540**（16:9，像素风格基准 1px = 1 逻辑像素）。
- 显示缩放：整数倍缩放（1× / 2× / 3×）+ 居中黑边（letterbox），保持像素锐利（`image-rendering: pixelated`）。
- 坐标原点：左上角 (0,0)，X 向右，Y 向下。

### 2.2 界面总览与状态流

```
启动 Logo → 主菜单 → [快速比赛 | 锦标赛 | 计时赛 | 漂移练习]
  → 选车 → 选赛道/难度 → 倒计时 → 比赛（HUD）
  → 冲线结算 → [再玩一局 | 回到主菜单]
                  主菜单 → 设置（音乐/音效音量、按键、画质）
```

### 2.8 设置界面（Settings）

- 音乐音量（0-100，步进 5）、音效音量（0-100）；
- 按键重绑定（键位冲突红色提示）；

### 2.9 UI 通用规范

- 像素字体（8×8 或 8×16，ASCII + 少量符号），中文采用 12px 位图化字体；
- 按钮状态：`normal / hover / pressed / disabled` 四态，hover 放大 1px + 高亮描边；
- 选中反馈：确认音效 + 白闪；菜单切换：方向音效；
- 所有 UI 元素绘制在独立 UI 层，与游戏世界层分离，支持震动时独立位移。

## 3. 像素美术风格（Pixel Art Style）

### 3.1 总体风格定位

- **风格关键词**：16-bit 复古、高饱和、强对比、霓虹点缀、街机感。
- **参考作品**：《OutRun》的落日配色、《RC Pro-Am》的俯视赛道、《Chase HQ》的都市夜景。
- **基调**：白天沙漠/海滨赛道为主，傍晚/夜景赛道为辅；背景为双层视差卷轴。

### 3.2 基础色板（Palette）

采用受限色板（每场景 ≤ 32 色），保证统一感：

| 类别 | 色值（HEX） | 用途 |
|------|-------------|------|
| 赛道沥青 | #3a3d4a / #4a4e5e | 主路面 |
| 路肩红白 | #e0403a / #f2f2f0 | 路缘、油桶 |
| 草地 | #2f7a3a / #55a34a | 赛道外草地 |
| 沙地 | #d8b25a / #c49a44 | 出界区/沙地陷阱 |
| 天空渐变 | #ff9a4a → #ffd27a | 黄昏背景（日出/日落场景）|
| 霓虹青 | #22d3ee / #67e8f9 | 氮气、加速带 |
| 霓虹粉 | #f472b6 | 玩家高亮、特效 |
| 阴影 | #1e1e28 | 描边、阴影、文字 |

**用色纪律**：
1. 单幅素材 ≤ 16 色；同一场景全局 ≤ 32 色；
2. 禁止抗锯齿渐变涂抹；采用色块 + 抖动（dithering）表达过渡；
3. 轮廓统一使用比基色深 2 级的同色相描边（outline）。

### 3.3 分辨率与缩放规格

| 对象 | 像素规格 | 缩放 |
|------|----------|------|
| 车辆（顶视） | 16×24 px | 2×（渲染 32×48）|
| 车辆（侧视，菜单用） | 48×20 px | 2× |
| 赛道瓦片（tile） | 16×16 px | 1× |
| 背景层（远景） | 视差横幅 960×180 | 1× |
| HUD 数字/图标 | 8×8 / 16×16 px | 2× |
| 粒子 | 2×2 / 4×4 px | 1× |

**缩放规则**：所有像素素材使用 `image-rendering: pixelated` 整数缩放；运行时绘制禁止浮点模糊（坐标取整）。

### 3.4 车辆美术规范

- 提供 6 辆车，每辆含**顶视图（比赛用）**与**侧视图（选车/结算用）**两个朝向（默认朝上/朝右）。
- 车辆像素图必须包含：车头灯、尾灯（刹车点亮）、车窗、车号（1～8 可自定义）。
- 转向动画：车身以车辆中心为轴旋转（旋转后保持像素锐利，必要时预渲染 8 个方向帧）；
- 漂移状态：增加尾翼反光 + 轮胎烟粒子。

### 3.5 赛道与环境美术

| 元素 | 规格/表现 |
|------|-----------|
| 路面瓦片 | 沥青底 + 随机噪点、车道线（白虚线）、路肩红白斜纹 |
| 检查点 | 横跨路面的半透明绿门 + 旗标 |
| 起点/终点 | 黑白棋盘格横条 + 拱门 |
| 装饰物 | 棕榈树、路灯、广告牌、沙丘、集装箱（16×16/32×32）|
| 出界区 | 草地（静态）+ 沙地（粒子飞溅）|
| 障碍物 | 油桶（16×16）、轮胎路障（32×12）、加速带（绿箭 16×16 循环帧）|

### 3.6 粒子与特效规范

| 特效 | 形态 | 触发 |
|------|------|------|
| 轮胎烟 | 白/灰 4×4 像素，上升扩散淡出 | 漂移持续 |
| 氮气火焰 | 蓝/青 4×4 喷射粒子 | 氮气喷射 |
| 撞击火花 | 橙黄 2×2 星点 + 屏幕震动 | 撞墙 |
| 油桶爆炸 | 橙红火焰环 + 黑烟 | 油桶引爆 |
| 速度线 | 半透明白竖线（视口边缘）| 高速（>80% 极速）|
| 终点彩带 | 彩色彩带横穿视口 | 冲线 |

### 3.7 动画帧率规范

- 角色/车辆动画：6～8 帧/s；装饰物循环动画：4 帧/s；
- 粒子：60 FPS 实时计算，寿命 0.2～1.5s；
- 所有 UI 动画：10 帧/s 像素风补间（禁止平滑缓动，用阶梯式 easing）。

### 3.8 字体与文本

- 主字体：8×8 位图字体（ASCII）；标题：16×16 位图字体；
- 中文：12×12 位图子集（覆盖菜单常用字，≤256 字）；
- 文本描边：1px 深色描边保证可读性。

## 4. 音效需求（Sound & Music）

### 4.1 音频整体策略

- **风格**：芯片音乐 Chiptune（方波/三角波/噪声，复古街机质感），可程序合成或 8-bit 采样。
- **格式**：Ogg Vorbis（Web 主用），48kHz / 16-bit；总包体积 ≤ 3MB。
- **混音层级**：BGM < SFX（BGM 0.7 : SFX 1.0），UI 音效音量介于两者之间。

### 4.2 音乐（BGM）需求清单

| 编号 | 曲目 | 使用场景 | 风格/速度 | 长度/循环 |
|------|------|----------|-----------|-----------|
| BGM-01 | 主菜单 Theme | 主菜单/选车 | 律动 Disco 风，112 BPM | 30s 无缝循环 |
| BGM-02 | 沙漠疾走 Desert Rush | 白天赛道 | 快节奏 128 BPM | 60s 无缝循环 |
| BGM-03 | 午夜霓虹 Neon Night | 夜景赛道 | Synthwave 120 BPM | 60s 无缝循环 |
| BGM-04 | 冠军之路 Champion | 锦标赛结算 | 激昂 140 BPM | 30s 循环 |
| BGM-05 | 漂移课堂 Drift School | 练习模式 | 轻快 Funk 100 BPM | 30s 循环 |

**BGM 需求细节**：
- 每首 BGM 提供**双版本**：正常版 / 低通滤波版（速度接近极速时切换，增强速度感）；
- 结尾 3 秒进入"压轴段"（冲线瞬间触发）。

### 4.4 音效触发细节

- **引擎音高跟随速度**：引擎 Loop 播放速率随 `速度/极速` 在 0.6×～1.3× 间线性变速（实现"踩油门的耳朵反馈"）；
- **音量衰减**：SFX 根据与玩家车辆距离做音量衰减（其他 AI 撞击/爆炸声）；
- **防重叠**：同一 SFX 最短播放间隔 40ms，超限则丢弃（防爆音）；
- **震动联动**：撞墙/爆炸时，SFX 与屏幕震动同步触发。

### 4.5 音频无障碍

- 提供"字幕/视觉提示"模式：撞击、漂移、氮气、检查点等关键事件同时输出屏幕图标（如撞击震动图标、漂移烟提示），保证关闭声音时仍可游玩。

## 5. 性能约束与验收标准

### 5.1 性能约束

| 项 | 指标 |
|----|------|
| 帧率 | 60 FPS（低配 30 FPS）|
| 画布 | 960×540 逻辑分辨率 |
| 同屏实体 | ≤ 16（1 玩家 + 6 AI + 障碍物）|
| 同屏粒子上限 | ≤ 300（超出时按创建时间淘汰最老粒子）|
| 音频 | 同时播放 ≤ 8 通道，超限丢弃低优先级 |

### 5.2 验收标准（针对本文档）

1. **核心玩法**：可实现快速赛 3 圈完整流程，漂移攒氮气→喷射链路成立；结算数值正确。
2. **界面布局**：主菜单/选车/比赛 HUD/暂停/结算 5 界面可完整走通；960×540 下无元素越界。
3. **像素美术**：所有素材像素整数缩放、无模糊；赛道/车辆/特效符合 §3 色板与规格。
4. **音效需求**：BGM 至少 3 首可用；SFX 清单 ≥ 12 条全部有资源与触发；音量可调、防爆音。
