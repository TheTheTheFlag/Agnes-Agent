关于

这是一个使用 Flask + HTML/CSS/JavaScript 构建的简单博客系统。

技术栈

  • 后端：Python + Flask
  • 前端：HTML5 + CSS3 + 原生JavaScript
  • 存储：JSON文件
  • 渲染：Markdown

功能

  • ✍️ 创建和编辑文章
  • 📄 Markdown 支持
  • 🏷️ 标签分类
  • 📱 响应式设计

开始使用

# 安装依赖
pip install -r requirements.txt

# 启动服务
python run.py

# 访问
http://localhost:5000
