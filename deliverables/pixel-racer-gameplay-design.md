## 1. 游戏概述

### 1.1 一句话定义
一款竖屏/横屏自适应、俯视或伪 3D 追尾视角的**像素风格街机竞速游戏**：玩家驾驶像素赛车在无尽或分关卡的赛道上躲避车流、收集金币、使用道具冲刺，追求最高分与最快通关。

### 1.2 目标用户
- 核心：休闲玩家，单局 1–3 分钟，随时可玩可停。
- 次核心：街机高分挑战玩家，追求连击与排行榜。

### 1.3 核心体验（Core Loop）
```
选择关卡 → 驾驶（加速/转向/漂移/道具） → 收集金币 & 连击 → 抵达终点或里程目标
        → 结算（分数 + 星级 + 排名） → 解锁新关卡/车辆/皮肤 → 再开一局
```

## 2. 核心机制（Core Mechanics）

### 2.1 驾驶模型
- **速度系统**：速度分三档——巡航档、加速档、极速档（氮气）。
  - 基础速度由车辆属性决定；按住油门自动加速至巡航上限。
  - 撞车（撞击车流/路障）后速度骤降并进入 1.5s 硬直，随后自动恢复。
- **惯性漂移**：高速转向时产生横向滑动；漂移期间集气（见 2.3），漂移结束无惩罚。
- **贴边奖励**：贴近赛道护栏行驶获得「贴边」增益（+2% 分数/秒，上限叠加 5 层），鼓励高风险走线。

### 2.2 赛道构成（无尽 + 关卡双模式）
- **无尽模式**：里程无限，里程 = 分数基数，撞车 3 次游戏结束；距离越远车流密度与速度越高。
- **关卡模式**：固定赛道长度（4000m / 6000m / 9000m …），以「通关时间」与「收集率」双重结算。

### 2.3 能量与道具（Pickups）
| 道具 | 图标色 | 效果 | 持续 |
|---|---|---|---|
| 氮气瓶 ⚡ | 蓝 | 极速冲刺（+60% 速度，碰撞免疫） | 2.5s |
| 金币桶 💰 | 金 | 立即 +50 金币 | 即时 |
| 磁铁 🧲 | 紫 | 自动吸取附近金币 | 6s |
| 护盾 🛡 | 青 | 抵消 1 次撞击 | 直至触发 |
| 双倍分 ×2 | 红 | 期间得分翻倍 | 8s |
| 慢速云 ☁ | 灰 | 减速所有车流（无尽模式） | 5s |

- 漂移集气：漂移每 0.5s 累积 20% 氮气条，满 100% 自动获得一次氮气使用权（上限存 2 次，Shift 键释放）。

### 2.4 碰撞与惩罚
- 撞击车流/路障：速度 -45%，金币 -10%（最少为 0），连击清零，屏幕震动 + 红色闪烁。
- 撞击护栏：速度 -15%，不丢金币，不清连击。
- 三连撞（关卡模式）或三次撞击（无尽模式）→ 游戏结束。

### 2.5 难度曲线（动态难度）
- 车流密度随里程/关卡进度线性上升（0% → 100%）。
- 每 30s 车流速度提升 3%（上限 +45%）。
- 关卡模式提供 3 档难度（普通 / 困难 / 疯狂），影响车流密度、间距与金币分布。

## 3. 操作方式（Controls）

### 3.1 键盘（PC 默认）
| 按键 | 功能 |
|---|---|
| ← / A | 左移 |
| → / D | 右移 |
| ↑ / W / 空格 | 油门（按住持续加速） |
| ↓ / S | 刹车 / 减速 |
| Shift | 氮气冲刺 |
| P / Esc | 暂停 |
| M | 静音 |

### 3.2 触屏（移动端）
- 左侧虚拟摇杆：上下=油门/刹车，左右=转向。
- 右侧「氮气」按钮：点击释放氮气。
- 支持横屏与竖屏自适应（推荐横屏，视野更宽）。

### 3.3 手柄（可选，扩展）
- 左摇杆 = 转向，RT = 油门，LT = 刹车，A = 氮气。

### 3.4 操作手感参数（供程序参考）
- 转向灵敏度：基础 1.0，可设置 0.5–2.0。
- 横向速度上限：420 px/s（巡航），氮气时 640 px/s。
- 转向阻尼：0.86（每帧速度衰减系数），保证松手后平滑停住。
- 输入采用「累计位移」而非直接映射坐标，避免抖动。

## 4. 美术风格（Art Style）

### 4.1 总体风格
- **16-bit 复古像素**：参考 90 年代街机（OutRun / Top Gear）风格，饱和度高的霓虹色。
- 逻辑分辨率：480×270（16:9），放大 4 倍显示 1920×1080，保持像素锐利（无插值）。

### 4.2 色板（Palette）
| 用途 | 主色 | 辅色 |
|---|---|---|
| 赛道沥青 | #3a3f4a | #2c3038 |
| 车道线 | #ffd54a | #ffb300 |
| 玩家赛车（红） | #ff5252 | #b71c1c |
| 车流（多彩） | #4fc3f7 / #81c784 / #ba68c8 | 深一档描边 |
| 金币 | #ffd700 | #ff8f00 |
| 霓虹装饰 | #00e5ff / #ff4081 | 透明渐变 |

### 4.3 像素规范
- 车流车辆：16×32 px（侧视）/ 32×16 px（俯视），2 帧滚动动画（轮胎转动）。
- 玩家赛车：24×40 px，含转向倾斜 0/±8° 三态帧。
- 金币：8×8 px，4 帧旋转动画。
- 道路纹理：256×256 可平铺，双滚动层（路面 + 护栏）制造纵深。
- 背景：3 层视差（远景山/城市剪影 0.2x、中景建筑 0.5x、近景路灯 0.8x）。

### 4.4 动效与反馈
- 氮气：车尾拖曳 8×8 像素火焰粒子（3 帧）。
- 撞击：白色闪屏 + 车体倾斜 12° + 碎片粒子 6 个。
- 连击：屏幕顶部弹出像素字体「COMBO ×5」+ 音效 pitch 递增。
- 残影：高速时保留前 3 帧车影（透明度 30%）。

### 4.5 UI 风格
- 像素字体（8×8 位图字体，支持中文使用 12×12 像素字体）。
- 按钮：凸起描边 2px，悬停/按下两态。
- 分数使用 7 段式大数字，结算界面滚动计数动画。

## 5. 关卡设计（Levels）

### 5.1 无尽模式
- 单一无尽赛道（城市环线，夜晚），难度随时间递增，适合短时刷分。

### 5.2 关卡模式（6 关主线）
| 关卡 | 主题 | 里程 | 目标时间(★) | 车流密度 | 特色机制 |
|---|---|---|---|---|---|
| 1-1 新手大道 | 白天城市 | 4000m | 55s | 低 | 教学：直线 + 金币带 |
| 1-2 霓虹夜港 | 夜晚港口 | 5000m | 70s | 中低 | 首次出现漂移弯道 |
| 1-3 山脊隧道 | 隧道 + 山路 | 6000m | 82s | 中 | 隧道内视野收窄 |
| 2-1 沙漠高速 | 沙漠公路 | 7000m | 95s | 中高 | 热浪视效，车流提速快 |
| 2-2 雪原弯道 | 雪地山路 | 8000m | 110s | 高 | 冰面低摩擦（漂移加长） |
| 2-3 霓虹终章 | 未来都市 | 10000m | 135s | 极高 | 全道具密度最高，BOSS 车流墙 |

### 5.3 解锁规则
- 每关获得 ≥1 星解锁下一关；3 星通关额外解锁对应车辆皮肤。
- 无尽模式累计里程 20000m 解锁「疯狂」难度。

### 5.4 道路事件（每关随机种子生成，保证可复现测试）
- 金币弧线 / 金币直线 / 金币"S"弯。
- 路障（油桶 / 锥桶）与车流车队。
- 每关固定 2 个「完美漂移门」（穿过 +500 分）。

## 6. 计分规则（Scoring）

### 6.1 分数构成
```
总分 = 里程分 + 收集分 + 技巧分 + 通关奖励分
```

| 项目 | 规则 | 分值 |
|---|---|---|
| 里程分（无尽） | 每 10m | +1 分 |
| 里程分（关卡） | 通关基础 | +1000 分 |
| 金币 | 每枚金币 | +10 分 |
| 金币桶 | 每个 | +500 分 |
| 贴边 | 每秒（每层） | +2 分 |
| 漂移 | 每次漂移（≥0.8s） | +50 分 |
| 完美漂移门 | 穿过一次 | +500 分 |
| 氮气极速 | 冲刺每 0.5s | +30 分 |
| 通关时间奖励 | 目标时间内完成 | 每提前 1s +100 分 |

### 6.2 连击系统（Combo）
- 连续拾取金币 / 穿过漂移门且 **3s 内未撞击** 则连击数 +1。
- 连击倍率：`×1, ×1.5, ×2, ×2.5, ×3`（上限 ×3，对应连击 10 次）。
- 倍率作用于「收集分 + 技巧分」，不作用于里程分。
- 撞击 / 超时（3s 无操作加分项）→ 连击清零。

### 6.3 星级评定（关卡模式）
| 星级 | 条件 |
|---|---|
| ★ | 到达终点 |
| ★★ | 到达终点且 ≤ 目标时间 |
| ★★★ | 到达终点 且 金币收集率 ≥ 80% 且 ≤ 目标时间 |

### 6.4 结算与排行榜
- 结算页展示：总得分、里程、金币、最高连击、漂移次数、星级、用时。
- 本地排行榜：每关 Top 10（总分降序）；无尽模式 Top 10（里程降序）。
- 分数溢出保护：单局总分上限 9,999,999（超出按此封顶）。

### 6.5 数值示例（1-1 新手大道理论满分）
- 通关 +1000；提前 5s +500；金币 120 枚 ×10 = 1200；金币桶 2 ×500 = 1000；
- 贴边 40s×2 = 80；漂移 3 次 = 150；漂移门 2×500 = 1000；
- 连击 ×3 覆盖收集+技巧分（1200+1000+80+150+1000）×3 = 10290。
- **理论满分 ≈ 12,790 分**（可作关卡平衡的验收基准）。

## 7. 平衡性与可调参数（Tuning Table）

| 参数 | 默认值 | 可调范围 |
|---|---|---|
| 巡航最高速 | 480 px/s | 400–600 |
| 氮气加速倍率 | +60% | +40%–+80% |
| 撞击减速 | -45% | -30%–-60% |
| 撞车硬直 | 1.5s | 1.0–2.0s |
| 漂移集气率 | 20% / 0.5s | 15%–30% |
| 车流密度斜率 | 0.5 辆/100m | 0.3–0.8 |
| 连击窗口 | 3s | 2.5–4s |
| 游戏结束判定 | 3 次撞击 | 2–4 次 |

> 所有数值集中存放于 `config/tuning.json`，便于策划热调，无需改代码。

## 8. 技术要点（与实现衔接）

- 游戏循环固定 60 FPS，逻辑帧与渲染帧分离。
- 输入采样使用累积位移；移动端虚拟摇杆为相对坐标（免漂移）。
- 碰撞检测：车与车流用 AABB（外扩 1px 容错，降低挫败感）。
- 赛道生成：预置关卡由种子生成事件序列，保证自动化测试可复现。
- 存档：localStorage / 文件保存 关卡进度、金币、设置、排行榜。

## 9. 验收标准（Acceptance Criteria）

1. 三种输入方式（键盘 / 触屏 / 手柄）均可完整游玩一关。
2. 计分公式实现与 6.1–6.5 一致；关卡 1-1 理论满分可被手工复现（误差 < 1%）。
3. 撞击、金币、连击、氮气、漂移门五类事件均有明确视觉/音效反馈。
4. 连续游玩 10 局无崩溃；暂停/恢复、结算、重开流程无状态残留。
5. 无尽模式第 3 次撞击正确触发 Game Over，并记录排行榜。
