# 像素飙车 · Pixel Racer — 操作指南（玩家手册）

> 目标：让任何人在 1 分钟内学会安装并开始游戏。

---

## 1. 一分钟快速开始

1. 拿到交付包中的 **`pixel-racer.html`** 文件。
2. **双击**它（或用任意现代浏览器打开）。
3. 按下 **空格** 或 **回车** → 开始飙车！🏁

> 不需要安装任何软件、不需要联网、不会写入任何系统配置。

## 2. 安装与启动（分平台）

### Windows
- 方式 A（推荐）：双击 **`启动游戏.bat`**，脚本会用默认浏览器打开游戏。
- 方式 B：直接双击 **`pixel-racer.html`**，在浏览器中打开。

### macOS
- 双击 **`pixel-racer.html`** 用默认浏览器打开；或终端执行 `bash run.sh`。

### Linux
- 终端执行 `bash run.sh`（会自动调用 xdg-open）；或手动用浏览器打开 `pixel-racer.html`。

### 手机 / 平板
- 将 `pixel-racer.html` 通过微信/邮件/网盘发送到设备，使用手机浏览器（Chrome / Safari 等）打开即可。
- 建议横屏游玩；按住屏幕左 / 右半区即可变道。

## 3. 操作键位表

| 按键 | 功能 |
| --- | --- |
| ← / → 或 A / D | 向左 / 向右变道 |
| ↑ 或 W | 加速（按住，速度 ×1.22） |
| ↓ 或 S | （预留减速位，当前版本无减速设定，速度自动提升） |
| 空格 / 回车 | 开始 / 重开 / 继续 |
| R | 游戏结束后快速重开 |
| P / Esc | 暂停 / 继续 |
| M | 静音 / 取消静音 |

### 触摸操作（手机 / 平板）
- 按住屏幕 **左半区**：向左变道
- 按住屏幕 **右半区**：向右变道
- 任意点击：开始 / 重开

## 4. 玩法技巧

1. **提前观察**：盯着屏幕中上方的车流，提前一档判断变道方向。
2. **贴边不贪**：除非冲刺纪录，否则不要长期按住加速，高速下反应窗口极小。
3. **金币路线**：金币通常出现在车流间隙，顺手拾取即可，不要强行绕路。
4. **同车道连车**：连续两辆敌车可能出现在同一车道，看到上一辆通过后不要立刻回原道。
5. **节奏感**：速度超过 400 后，刷新间隔变短，保持小幅微调、少做大范围横移更安全。

## 5. 界面说明

| 界面元素 | 说明 |
| --- | --- |
| 左上「分数」 | 当前局累计分数（距离分 + 金币分） |
| 上方居中「最高」 | 历史最高分（自动保存） |
| 右上「时速」 | 当前速度显示（单位 km/h，为内部速度换算值） |
| 路旁树木 | 纯装饰，用于体现路面滚动感 |
| 车道虚线 | 每 66px 循环滚动，用于感知车速 |

## 6. 常见问题（FAQ）

**Q1：双击 HTML 打不开？**
A：确认用浏览器打开（Chrome / Edge / Firefox / Safari），而非记事本。若被设为记事本打开，右键 → 打开方式 → 选择浏览器。

**Q2：没有声音？**
A：浏览器要求首次交互后才允许播放声音——按一下任意键或点击屏幕即可。也可按 M 确认未静音。

**Q3：最高分怎么不见了？**
A：最高分存在浏览器本地（localStorage）。清空浏览器缓存 / 换浏览器 / 无痕模式都会导致不显示。

**Q4：手机上怎么玩？**
A：触摸左右半区变道即可；屏幕会自动适配宽度，无需缩放。

**Q5：游戏会卡顿吗？**
A：游戏画面为简单矩形绘制，主流设备均可流畅 60 帧。窗口切后台再回来不会瞬移（内置限幅）。

## 7. 卸载

- 本游戏是**绿色免安装**的单文件，不需要“卸载”。
- 直接删除 `pixel-racer.html`（及可选的两个启动脚本）即可彻底移除。
- 如需清除最高分：浏览器设置 → 清除站点数据 / localStorage。
