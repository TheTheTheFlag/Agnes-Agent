# 2048 网页版

单文件实现的 2048 游戏，纯 HTML + CSS + 原生 JavaScript（无任何依赖、无需构建），双击 `index.html` 即可在浏览器中运行。

## 文件结构

```
deliverables/2048/
├── index.html   # 游戏全部实现（结构 / 样式 / 逻辑内联，单页可直接运行）
└── README.md    # 本说明
```

`index.html` 内部分区（按顺序）：

| 区块 | 内容 |
| --- | --- |
| `<style>` | 全局样式、棋盘网格、方块配色与动画、胜负遮罩、响应式规则 |
| DOM 结构 | 顶部标题 + 得分/最高分面板、重新开始按钮、4×4 棋盘容器、胜负遮罩层 |
| `<script>` | 核心逻辑：状态、渲染、移动合并、胜负判定、键盘/触摸输入、初始化 |

## 玩法

- **目标**：通过移动与合并相同数字，拼出 **2048**。
- **操作**
  - 方向键 `↑ ↓ ← →` 或 `W A S D` 移动方块；
  - 移动端在棋盘上**滑动**即可移动（阈值 24px，防误触）；
  - 每次有效移动后，随机空格会新生成一个方块（90% 为 2，10% 为 4）。
- **合并规则**：朝移动方向的同值方块碰撞时合并为其和，每个方块一次移动中最多合并一次（如 `[2,2,2,2]` 向左为 `[4,4,_,_]` 而非 `[8,_,_,_]`）。
- **胜负**
  - 首次出现 2048 弹出「你赢了」，可选择**继续挑战**或重新开始；
  - 棋盘填满且任意方向都无法移动/合并时判负，弹出「游戏结束」。
- **计分与最高分**：每次合并的数值累加到得分；最高分自动写入浏览器 `localStorage`（键名 `game2048_best`），刷新后仍保留；隐私模式下 localStorage 不可用时静默降级、不报错。

## 功能点与实现位置

| 功能点 | 实现说明 |
| --- | --- |
| 棋盘逻辑 | `emptyGrid()` 构建 4×4 二维数组 `grid[r][c]`（0 表示空），`addRandomTile()` 随机落子 |
| 四方向合并 | `slideAndMerge(line)` 做「压缩 + 单向合并」，`move(dir)` 按方向取出每行/列并写回，四个方向共用同一套逻辑 |
| 键盘操作 | `KEY_MAP` 映射方向键与 WASD，`keydown` 监听并 `preventDefault()` 阻止页面滚动 |
| 触摸操作 | 棋盘上 `touchstart/move/end` 计算滑动位移与主轴方向，`touchmove` 中 `preventDefault()` 阻止下拉刷新 |
| 计分 | `score` 累加每次合并值，`render()` 同步 DOM，并显示 `+N` 浮动提示 |
| 最高分持久化 | `loadBest()` / `saveBest()` 读写 `localStorage['game2048_best']` |
| 胜负判定 | `checkGameState()` 检测 2048 触发胜利遮罩；`canMove()` 检测满盘无可合并触发失败遮罩 |
| 响应式界面 | `viewport` meta、`.container` 居中限宽、`aspect-ratio:1/1` 棋盘、`clamp()` 自适应字号、`max-width:500px` 适配移动端与桌面 |

## 校验结论

已对 `index.html` 做静态校验与逻辑测试，结果**全部通过**：

- **结构/语法**：`html/head/body/style/script/div` 标签开合配对（div 27/27），存在 DOCTYPE 与 viewport meta，`<script>` 内容经 `new Function` 解析无语法错误，脚本在 DOM 桩环境中可成功执行。
- **合并逻辑（含边界）**：`[2,2,4,4]→[4,8,_,_]`（+12，两次合并）、`[2,4,8,16]` 无相邻同值不合并、`[2,0,0,2]→[4,_,_,_]` 跨空格合并、`[2,2,2,2]→[4,4,_,_]` 同值只合并一次、`[1024,1024]→2048`。
- **四方向移动**：left/right/up/down 均能把合并结果落到正确一侧。
- **满盘不可移动**：棋盘为 `[[2,4,2,4],[4,2,4,2],...]` 时 `canMove()===false`，四个方向 `move()` 均返回 `false` 且棋盘不变、不加分、不生成新方块。
- **最高分持久化**：写入 `localStorage['game2048_best']` 成功。

> 调试接口：脚本末尾暴露 `window.game2048`（含 `newGame / move / slideAndMerge / canMove`、`grid`、`score` 的读写访问器），便于在控制台手动验证，不影响正常游戏。

## 浏览器要求

支持所有现代浏览器（Chrome / Edge / Firefox / Safari，含移动端）。使用了 `CSS Grid`、`aspect-ratio`、`clamp()`；IE 不支持。
