# 🐍 Neon Snake - 霓虹贪吃蛇

一个复古风格的网页版贪吃蛇游戏，采用霓虹灯视觉效果，流畅的操作体验。

## 🎮 游戏玩法

- **目标**：控制蛇吃到食物，获得分数，尽可能活得久
- **控制**：
  - 方向键 ↑↓←→ 或 WASD 控制移动方向
  - 空格键 暂停/继续
  - 触屏设备支持滑动控制
- **得分**：每个食物基础 10 分 × 当前关卡
- **升级**：每吃 5 个食物升一级，速度加快
- **失败条件**：撞墙或撞到自己

## 🚀 快速开始

双击打开 `index.html` 即可开始游戏，无需任何安装！

```bash
# 或者用 Python 启动本地服务器
python -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 🛠️ 技术细节

### 架构
- **单文件游戏**：所有逻辑封装在 `game.js`，无外部依赖
- **Canvas 渲染**：使用 HTML5 Canvas 2D API
- **requestAnimationFrame**：流畅的动画循环，自动调节帧率
- **状态机**：IDLE → RUNNING → PAUSED → GAME_OVER

### 核心算法
1. **蛇移动**：每帧在头部添加新坐标，移除尾部（除非吃到食物）
2. **食物生成**：随机生成，确保不与蛇身重叠
3. **碰撞检测**：边界检测 + 自碰撞检测
4. **方向缓冲**：每帧只处理一次方向改变，防止 180° 反转

### 性能优化
- 使用 `requestAnimationFrame` 而非 `setInterval`
- 只重绘必要区域
- 避免内存泄漏（及时清理定时器）
