# 网页版贪吃蛇游戏 - 开发规划

## 目标
开发一个功能完整、可玩的网页版贪吃蛇游戏，包含基本的蛇移动、食物生成、计分系统，以及进阶功能如：加速、关卡、暂停、重新开始等。

## 技术选型
- **前端**：HTML5 Canvas + Vanilla JavaScript（零依赖）
- **风格**：复古霓虹风格，适配桌面键盘操作
- **交付物目录**：`deliverables/snake/`

## 核心功能（P0 必须）
1. **蛇移动**：WASD / 方向键控制，支持连续按键缓冲（防止一帧两方向反转自杀）
2. **食物生成**：随机生成不可与蛇身体重叠的食物
3. **吃食物**：长度+1，得分+10，新食物重新生成
4. **碰撞检测**：撞墙或撞自己 → 游戏结束
5. **计分显示**：实时分数 + 最高分（localStorage 持久化）
6. **开始/结束界面**：按任意键开始，死亡后显示最终分数 + 重开按钮

## 进阶功能（P1 建议）
7. **暂停**：空格键暂停/继续
8. **速度递增**：每吃 N 个食物，移动速度小幅提升
9. **关卡系统**：吃到一定数量食物升级，出现障碍物或特殊食物
10. **音效**：吃食物、碰撞、升级的简单 Web Audio 音效
11. **移动端适配**：触屏滑动控制 + 响应式布局

## 开发步骤
1. **初始化**：创建目录结构，编写 HTML 骨架和基础 CSS
2. **核心循环**：实现 Canvas 渲染循环 + 蛇数据结构 + 移动逻辑
3. **输入处理**：绑定键盘事件，加入方向缓冲防反转
4. **食物系统**：随机生成食物，检测碰撞吃食物
5. **计分与最高分**：localStorage 持久化最高分
6. **游戏状态机**：开始/运行/暂停/结束状态切换
7. **特效打磨**：霓虹发光效果、粒子特效（可选）
8. **测试验证**：单元测试 + 手动试玩
9. **文档整理**：编写 README 和接口文档

## 时间估算
- 核心功能（P0）：2-3 小时
- 进阶功能（P1）：1-2 小时
- 测试与打磨：30 分钟
- **总计：约 4-5 小时**

## 风险点
1. **蛇反转自杀**：必须在同一帧内只处理一次方向改变
2. **食物重叠**：生成食物时检查不与蛇身体重叠
3. **Canvas 性能**：800×600 分辨率下每帧重绘，确保 60fps

## 验收标准
- [ ] 蛇能正常移动，方向键控制响应流畅
- [ ] 食物随机生成且不重叠蛇身
- [ ] 吃食物后蛇身增长，分数增加
- [ ] 撞墙或撞自己后游戏结束，显示最终分数
- [ ] 空格键暂停/继续
- [ ] 最高分持久化到 localStorage
- [ ] 游戏结束后可重新开始
- [ ] 代码无语法错误，可在浏览器直接打开运行
