贪吃蛇 - 基础类架构

子任务：画布初始化、网格设置、蛇对象初始化（位置/长度/方向）

📦 类结构概览

GameConfig

游戏配置常量：网格尺寸、单元格大小、画布尺寸、游戏速度

Direction

方向枚举与工具：上下左右方向、向量映射、相反方向判断

Position

坐标类：x/y位置、移动、克隆、相等比较

Snake

蛇类：蛇身段管理、方向控制、指令队列、移动逻辑

CanvasManager

画布管理器：画布初始化、网格绘制、蛇/食物渲染

FoodSpawner

食物生成器：随机生成食物位置、避免与蛇身重叠

⚙️ GameConfig - 游戏配置类

集中管理所有游戏相关的配置常量，便于调整和扩展

// 核心配置 GRID_SIZE = 20 // 网格尺寸（20x20） CELL_SIZE = 20 // 单个单元格像素 CANVAS_SIZE = 400 // 画布总尺寸 GAME_SPEED = 150 // 每帧间隔（ms） // 动态计算 COLS = CANVAS_SIZE / CELL_SIZE // 20列 ROWS = CANVAS_SIZE / CELL_SIZE // 20行

🧭 Direction - 方向枚举类

统一管理四个方向的定义、向量和关系判断

// 四个方向常量 UP: 'up', DOWN: 'down', LEFT: 'left', RIGHT: 'right' // 方向向量（用于计算下一位置） VECTORS = { 'up': { x: 0, y: -1 }, 'down': { x: 0, y: 1 }, 'left': { x: -1, y: 0 }, 'right': { x: 1, y: 0 } } // 相反方向（防止180度反转） OPPOSITES = { 'up': 'down', 'down': 'up', ... } // 工具方法 isOpposite(dir1, dir2) // 判断两方向是否相反 getVector(dir) // 获取方向对应的向量

📍 Position - 坐标类

封装坐标操作，提供位置计算和比较功能

// 创建坐标 pos = new Position(5, 10) // 基础属性 pos.x // 5 pos.y // 10 // 方法 pos.clone() // 返回副本 pos.move('right') // 返回新位置 (6, 10) pos.equals(otherPos) // 比较是否相同 pos.toGridObj() // 转换为 {x, y} 对象

🐍 Snake - 蛇类（核心）

管理蛇的位置、长度、方向和移动逻辑

// 初始化蛇（蛇头在 x=5, y=10，长度3） snake = new Snake(5, 10, 3) // 属性 snake.head // 蛇头位置 (Position) snake.length // 蛇身长度 (3) snake.direction // 当前方向 ('right') snake.pendingMoves // 待处理的指令队列 // 方法 snake.queueMove('up') // 添加方向到队列 snake.move(newHead, grow=false) // 移动蛇身 snake.checkSelfCollision(pos) // 检测自撞 snake.reset(5, 10, 3) // 重置到初始状态

🎨 CanvasManager - 画布管理器

封装所有画布操作：初始化、网格绘制、游戏元素渲染

// 初始化 canvasManager = new CanvasManager('gameCanvas') // 绘制方法 canvasManager.clear() // 清空画布 canvasManager.drawGrid() // 绘制网格线 canvasManager.drawSnake(snake) // 渲染蛇身 canvasManager.drawFood(pos) // 渲染食物 canvasManager.drawGameOver(score) // 游戏结束画面

🐍 蛇对象初始化示例

演示如何初始化蛇对象（位置、长度、方向）

// 创建蛇：蛇头在 (5, 10)，初始长度 3，向右 snake = new Snake(5, 10, 3) // 内部初始化逻辑： // segments[0] = Position(5, 10) ← 蛇头 // segments[1] = Position(4, 10) ← 身体 // segments[2] = Position(3, 10) ← 尾巴 // direction = 'right' // 添加移动指令到队列 snake.queueMove('up') // ✓ 成功 snake.queueMove('left') // ✓ 成功（队列长度<3） snake.queueMove('down') // ✗ 失败（与当前方向相反） // 下一帧消费指令 snake.consumeNextDirection() // 返回 'up'，direction 变为 'up'
