# PIXEL RACER · 像素飙车（GDD 实现版）

依据 `deliverables/pixel-racer-GDD.md`（v1.0）实现的可玩原型。单文件、零依赖、离线可玩。

## 运行方式

直接双击打开 `index.html`（或 `python -m http.server` 后访问），无需构建。

## 操作

| 按键 | 功能 |
|------|------|
| ↑ / W | 油门 |
| ↓ / S | 刹车 |
| ← → / A D | 转向 |
| Shift | 手刹漂移（漂移积攒氮气，松键一次性结算） |
| 空格 Space | 氮气喷射（+28% 提速） |
| P / Esc | 暂停 / 继续 |
| M | 小地图开关 |
| O | 声音开关 |
| R | 结算页快速重开 |
| F | FPS 显示 |
| 触屏 | 左/右下角转向，上半屏氮气，自动油门 |

## 本实现与 GDD 的对应关系

| GDD 章节 | 实现 |
|----------|------|
| §1.5 车辆物理 | 加速/刹车/阻力、高速转向迟钝、出界减速至 45%、撞车 35% 动能损失 + 0.5s 硬直 |
| §1.6 漂移与氮气 | 漂移 25/s 积攒、松键结算、氮气 ×1.28、尾焰粒子、胎烟 |
| §1.7 比赛规则 | 3 圈、4 检查点顺序判定（漏检罚速）、终点线、油桶/加速带 |
| §1.8 AI | 5 名 AI、沿道走线 + 扰动、弯道减速、落后提速 106% / 领先 94% 动态调速 |
| §2 界面 | 主菜单 / 倒计时 / 比赛 HUD（名次·圈数·计时·氮气条·时速表·小地图）/ 暂停 / 结算 |
| §3 像素美术 | 960×540、`pixelated` 整数缩放、GDD 色板（沥青/路肩红白/草地/黄昏天空/霓虹青）、16×26 像素车辆精灵、粒子、伪3D 投影 |
| §4 音效 | WebAudio 程序合成：引擎随速、漂移胎噪、碰撞、油桶爆炸、倒计时、冲线旋律、UI 音效 |
| §5 性能 | 固定时间步长 1/60s、同屏粒子 ≤300、整数坐标绘制 |

## 已知取舍（相对 GDD 的简化，后续可扩展）

- 模式：仅"快速比赛"（普通难度，5 AI）开放；锦标赛/计时赛/漂移练习为占位。
- 检查点数量为 4（GDD 为 6~8）。
- 赛道为程序化曲线（左右曲率对称闭环），长度约 4464px/圈。
- 中文 UI 使用系统等宽字体（像素字体子集为后续美术资源项）。
