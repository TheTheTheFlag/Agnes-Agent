# 像素飙车 · Pixel Racer — 游戏说明文档

> 版本：v1.0（交付版）　类型：单文件网页版像素赛车小游戏　语言：中文

---

## 1. 游戏概述

《像素飙车》（Pixel Racer）是一款竖版无尽跑道赛车小游戏。玩家驾驶一辆红色像素赛车，在 3 车道的公路上高速行驶，需要**躲避迎面滚动的车流、收集金币、在越来越快的速度中坚持更久**。

- **风格**：复古 8-bit 像素风，全部画面由程序逐像素绘制，无任何外部图片素材。
- **形态**：单个 HTML 文件（`pixel-racer.html`），双击即可在浏览器中运行，**无需安装、无需联网、无任何依赖**。
- **平台**：Windows / macOS / Linux / Android / iOS 上所有现代浏览器（Chrome、Edge、Firefox、Safari 均可）。

## 2. 核心玩法与规则

1. 游戏开始后，赛车自动向前行驶，速度随距离逐渐提升（最高 560 px/s）。
2. 玩家通过左右变道躲避从前方滚来的敌方车辆。
3. 撞上敌方车辆即游戏结束；结束时若刷新纪录，最高分会自动保存到本地浏览器。
4. 道路上有旋转的金币（¥），拾取一个立即 **+100 分**。
5. 按住 **↑ / W** 可以临时加速（速度 ×1.22），分数增长更快，但反应时间更短——高风险高收益。

## 3. 计分体系

| 项目 | 规则 |
| --- | --- |
| 距离分 | 随行驶距离持续累积（分数 = 距离 × 系数） |
| 金币 | 每个 +100 分 |
| 最高分 | 自动记录于浏览器 `localStorage`（键：`pixelRacerHi`），刷新页面不丢失 |

## 4. 难度曲线

| 阶段 | 大约时间 | 速度 | 敌车刷新间隔 |
| --- | --- | --- | --- |
| 起步 | 0 ~ 20 秒 | 220 → 300 px/s | 约 1.0 ~ 1.4 秒 |
| 巡航 | 20 ~ 60 秒 | 300 → 420 px/s | 约 0.7 ~ 1.1 秒 |
| 高速 | 60 秒以上 | 420 → 560 px/s | 约 0.45 ~ 0.85 秒 |

速度无上限封顶，后期极其考验反应与预判。

## 5. 技术实现说明

- **渲染**：HTML5 `<canvas>`（480×640 逻辑分辨率），`image-rendering: pixelated` 保持像素锐利。
- **像素画**：车辆以 16×18 字符矩阵 + 调色板定义，按 3 倍放大绘制；敌车通过对同一模板换色生成 4 种配色（蓝 / 绿 / 橙 / 紫），零美术资源成本。
- **游戏循环**：`requestAnimationFrame` + delta-time 驱动，逻辑与帧率解耦；窗口失焦时自动限幅（dt ≤ 50ms），避免卡顿后瞬移。
- **碰撞**：AABB 矩形相交检测，带少量宽容余量，手感公平。
- **音频**：WebAudio API 程序合成（引擎启动 / 金币 / 撞击 / 结束音效），可按键 M 静音，不依赖音频文件。
- **状态机**：`menu → play ⇄ pause → over → play`，覆盖开始、暂停、重开全流程。
- **移动端**：触摸支持（按住屏幕左 / 右半区变道），`touch-action:none` 防止误滚动。
- **数据持久化**：最高分使用 `localStorage`，隐私安全，纯本地。

## 7. 运行方式（摘要）

| 平台 | 方式 |
| --- | --- |
| Windows | 双击 `启动游戏.bat`，或直接双击 `pixel-racer.html` |
| macOS / Linux | 终端执行 `bash run.sh`，或直接双击 `pixel-racer.html` |
| 手机 / 平板 | 将 `pixel-racer.html` 发送到设备，用浏览器打开 |

详细步骤见《操作指南.md》。

## 8. 兼容性与已知问题

- 需要支持 ES5+ 与 Canvas 的现代浏览器（2018 年后发布的版本均可）。
- 音频需用户首次按键/点击后才会初始化（符合浏览器自动播放策略）。
- 最高分保存在本机浏览器，清空浏览器数据会一并清除。
- 已知无重大缺陷；若发现异常，刷新页面即可恢复。
