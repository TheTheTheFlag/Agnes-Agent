# 《像素飙车 Pixel Racer》设计文档

- 文档版本：v2.0（重构版，聚焦核心玩法 / 赛道布局 / 车辆属性 / 视觉风格四大模块）
- 目标平台：浏览器（HTML5 Canvas，单文件可运行，零依赖）；预留桌面端（Pygame/Electron）移植接口
- 渲染风格：16-bit 复古像素风（致敬《OutRun》《RC Pro-Am》《地平线 Chase HQ》）
- 视角：俯视角（Top-down）卷轴式，伪 3D 缩放增强速度感
- 目标帧率：60 FPS（低配自动降 30 FPS，采用固定时间步长 + 渲染插值）
- 单局时长：2～4 分钟
- 控制方式：键盘（方向键 / WASD + Shift 漂移 + 空格氮气）+ 可选触屏虚拟按键

## 1. 核心玩法（Core Gameplay）

### 1.1 游戏循环（Core Loop）

```
选车（属性取舍）→ 倒计时起跑（抢跑判定）→ 竞速 3 圈
    → 漂移积攒氮气（Drift → Nitro）→ 道具/油桶互动
→ 冲线结算（名次 / 单圈 / 漂移分）→ 解锁赛道与车辆 → 回到选车
```

### 1.2 游戏模式

| 模式 | 说明 | 解锁条件 |
|------|------|----------|
| 快速比赛 Quick Race | 单场 3 圈，可选赛道 × 难度（简单/普通/困难） | 默认开放 |
| 锦标赛 Championship | 3 场连赛积分制（10/8/6/5/4/3/2/1），总积分夺冠 | 完成 1 场快速赛 |
| 计时赛 Time Attack | 无 AI，刷最快圈速，配 Ghost 影子车回放 | 完成 2 场快速赛 |
| 漂移练习 Drift School | 空旷场地，仅练漂移与氮气，附教学提示 | 默认开放 |

### 1.3 比赛流程与规则

1. **起跑**：`3-2-1-GO` 倒计时，每 1s 一帧大字。倒计时期间按住油门可预转转速表；**抢跑判定**：GO 亮起前 0.3s 内松开发车键视为抢跑，比赛开始后罚时 2s（计入总成绩）。
2. **圈数**：默认 3 圈。赛道布设 6～8 个检查点（Checkpoint），必须顺序通过；漏检则本圈无效，车辆强制回退至最近通过检查点（屏幕提示“MISSED CHECKPOINT!”）。
3. **冲线**：以车头越过终点线为准；显示排名、总用时、最快单圈、漂移总积分。
4. **碰撞与出界**：
   - 撞墙（护栏/山体）：按当前速度的 35% 损失动能，车辆反弹，产生火花粒子与“咚”音效，0.5s 硬直。
   - 出界（草地/沙地）：速度衰减为 45%，转向灵敏度下降，漂移不再积攒氮气。
   - 车对车碰撞：轻推不伤速；高速追尾使前车获得小推速、后车损失 15% 速度。
5. **道具（可选，锦标赛/困难难度开启）**：
   - 油桶（红白条纹）：可被撞击引爆——对撞击者造成 25% 减速 + 屏幕震动，附近 AI 也会减速；会刷新。
   - 加速带（绿箭）：位于部分弯道外侧，压上获得 1.5s 提速 20%。
   - 路障轮胎（橙黑）：AI 避让点，玩家撞上减速 20%，可推动滑行。

### 1.4 漂移与氮气系统（核心乐趣）

- **触发漂移**：转弯时按住 `Shift`（或高速入弯自动进入轻漂移）。
- **漂移状态**：车辆转向半径增大、横向滑移，尾部拖出轮胎烟粒子。
- **氮气积攒**：漂移持续时间内按每秒 25 单位积攒氮气（计入“漂移分”），漂移结束（回正）时结算并一次性入账；断漂不结算、不保留。
- **氮气使用**：空格键喷射，持续 1.2s，提速 28%，车尾喷蓝火粒子 + FOV 轻微拉近；喷完冷却 0.8s。
- **漂移奖励加成**：贴内线漂移 +20%，漂移中不撞墙 +10%，连续两次漂移衔接（1s 内）额外 +15%。

### 1.5 难度与 AI 对手

- 玩家固定 1 名；AI 4 名（简单）/ 5 名（普通）/ 6 名（困难）。
- AI 行为：沿“理想线”（预先录制的路线点）行驶，带随机走线扰动；对玩家在 ±2 车宽内时做出避让；难度越高，理想线越贴弯心、失误（撞墙/出界）概率越低。
- AI 名次动态调速：落后于玩家时提速至 105%，领先时回到 95%，保证比赛有悬念（rubber-banding，幅度 ≤10%）。

### 1.6 计分与结算

```
总成绩 = 排名分(10/8/6/5/4/3/2/1) + 漂移分累计 + 完美圈速奖励(单圈最快 +5)
结算页：名次 / 总用时 / 最快单圈 / 漂移总分 / 解锁提示 / 重赛与下一关
```

## 2. 赛道布局（Track Layout）

### 2.1 赛道通用规范

| 参数 | 取值 |
|------|------|
| 画布逻辑尺寸 | 960 × 540（缩放渲染，适配任意窗口） |
| 赛道宽度 | 3 车道（每车道 48px），总宽 144px；弯道可收窄至 120px |
| 坐标系 | 世界坐标连续，屏幕为跟随玩家的卷轴视口 |
| 赛道数据格式 | 中心线样条（Catmull-Rom）→ 左右偏移生成路面，便于任意形状 |
| 检查点 | 每赛道 6～8 个，间隔约 400～600px |
| 圈长 | 3200～4600px（约 90～130 秒/圈，匹配单局时长） |

### 2.2 赛道列表（3 条首发 + 2 条解锁）

#### 赛道 ① 「海湾日落 Bay Sunset」— 新手 / 入门
- 圈长 ≈ 3400px，宽度 144px 恒定，弯道平缓（最大曲率半径 ≥ 260px）。
- 布局：一个长直道 → 两个缓右弯（U 型大弯）→ 高速左弧 → 发夹弯前减速区 → 终点直道。
- 路面：柏油（深灰）；两侧棕榈树 + 沙滩像素块；海面在赛道一侧随视差滚动。
- 教学要素：首次游玩内置箭头导航线与“减速提示”标牌。

```
[S]───▶ 直道(长) ─▶ (右缓弯) ─▶ (右缓弯) ─▶ 左弧高速段
  │                                              │
  └── 终点直道 ◀── 发夹弯(减速区) ◀── 沙地出界区 ◀─┘
```

#### 赛道 ② 「霓虹都市 Neo City」— 进阶 / 技术
- 圈长 ≈ 4200px，路面宽度 120～144px 变化，含 2 处 S 型连续弯 + 1 处 90° 直角弯。
- 布局：发车直道 → 直角右弯（贴墙点）→ S 弯（漂移连击点）→ 隧道（灯光渐暗）→ 高架桥段（两侧护栏，出界即撞墙）→ 终点。
- 路面：深蓝沥青 + 霓虹灯带（品红/青色）作路缘；隧道内粒子灯光、广告牌像素字。
- 特色：S 弯是氮气积攒宝地，直角弯是 AI 事故高发点（超车机会）。

```
[S]──▶ 直角右弯 ─▶ S弯(漂移连击) ─▶ 隧道 ─▶ 高架桥(护栏)
                                        │
  终点 ◀──────────────── 霓虹大道 ◀──────┘
```

#### 赛道 ③ 「荒野峡谷 Canyon Rush」— 高难 / 越野
- 圈长 ≈ 4600px，路面宽度 120px，含碎石弯、沙地捷径与弹跳坡。
- 布局：发车 → 砂石直道 → 左碎石弯（漂移易甩尾）→ 峡谷窄桥（宽 96px，两侧无护栏）→ 弹跳坡（腾空 0.4s，落地加速）→ 沙地捷径（近路但慢 30%）→ 终点。
- 路面：土黄砂石 + 岩壁纹理；两侧仙人掌与岩柱像素；天空出现秃鹫剪影点缀。
- 特色：窄桥是勇气与风险的博弈，弹跳坡是氮气衔接点。

```
[S]──▶ 砂石直道 ─▶ 左碎石弯 ─▶ 窄桥(96px) ─▶ 弹跳坡
                                              │
  终点 ◀── 沙地捷径(慢但近) ◀── 峡谷直道 ◀─────┘
```

#### 赛道 ④ 「雪岭环线 Alpine Loop」— 解锁：锦标赛冠军
- 圈长 ≈ 4000px，冰面路段降低摩擦系数（漂移更持久、更难控制）。
- 布局：雪道直道 → 冰面湖弯（低抓地力）→ 松林 S 弯 → 雪坡下坡（加速）→ 终点。
- 路面：白/浅蓝雪地 + 冰面镜面高光像素；雪松与滑雪小屋点缀。

#### 赛道 ⑤ 「午夜赛车场 Midnight Circuit」— 解锁：计时赛进入前 10%
- 圈长 ≈ 3000px，标准椭圆 + 内场发夹，专为刷圈速设计。
- 路面：全封闭赛车场，路缘红白相间，看台像素人群，夜间探照灯。

## 3. 车辆属性（Vehicle Attributes）

### 3.1 属性总览

每辆车 4 项核心属性（数值 0～10 浮动），影响物理表现：

| 属性 | 影响 | 公式关键项 |
|------|------|-----------|
| 极速 Top Speed | 最大速度上限 | `v_max = 240 + 极速 × 22` (px/s) |
| 加速 Acceleration | 从静止到极速的快慢 | `a = 150 + 加速 × 30` (px/s²) |
| 操控 Handling | 转向灵敏度、漂移可控性 | `turn = 2.6 + 操控 × 0.24` (rad/s) |
| 抓地 Grip | 过弯抓地力、漂移结束回正速度 | 摩擦系数 `μ = 0.55 + 抓地 × 0.06` |

### 3.2 车辆列表（6 辆，含 2 辆隐藏）

| 车辆 | 类型 | 极速 | 加速 | 操控 | 抓地 | 主题色 | 解锁 |
|------|------|------|------|------|------|--------|------|
| 小蜜蜂 Honeybee | 入门均衡 | 5 | 5 | 5 | 5 | 黄/黑 | 默认 |
| 赤焰 Blaze | 高速型 | 9 | 4 | 3 | 4 | 红/橙 | 默认 |
| 涡轮 TURBO-8 | 加速型 | 4 | 9 | 6 | 5 | 蓝/白 | 完成 1 场快速赛 |
| 幻影 Phantom | 操控型 | 6 | 6 | 9 | 7 | 紫/青 | 完成 2 场快速赛 |
| 山猫 Lynx | 漂移型 | 7 | 7 | 7 | 3 | 绿/金 | 锦标赛亚军 |
| 金色闪电 Gold Rush | 隐藏全能 | 8 | 8 | 8 | 8 | 金/银 | 全赛道金牌 |

### 3.3 物理模型（简化公式，供实现层）

```
每帧 t=1/60s 更新：
  a_eff   = a × (1 - v / v_max)           // 自然加速随速度衰减
  v      += (油门? a_eff : -brake) × t     // brake 减速 260 px/s²
  v      *= 1 - drag × t                   // 风阻 drag = 0.18
  v_max_cur = v_max × surface_factor × nitro_factor

转向（非漂移）：
  heading += turn × steer × (1 - v/v_max × 0.55) × t   // 高速转向灵敏度降低

漂移状态：
  turn *= 1.35；抓地 μ *= 0.35；每帧积氮气 25/s；出界/撞墙强制退出漂移

氮气喷射：
  v_max ×= 1.28；v 向 v_max 靠近；粒子发射；持续 1.2s 后冷却 0.8s
```

### 3.4 手感调校原则

- **响应优先**：转向输入到车头转动延迟 ≤ 1 帧，不引入转向阻尼动画。
- **速度感强化**：随速度提升，视口滚动 + 背景视差层加速 + 路面虚线拉长 + 轻微屏幕抖动（v > 75% v_max）。
- **宽容判定**：漂移判定在入弯后 0.15s 内连续按 Shift 即可稳定进入，避免挫败感。
- **碰撞容错**：车宽碰撞盒略小于精灵图（留 4px 视觉余量），减少“看着没撞却撞了”的抱怨。

### 3.5 性能升级（可选成长系统，锦标赛贯穿）

跑完比赛获得金币，可给选定车辆升级（每项 3 级，+1 属性/级）：

| 升级项 | 每级效果 | 金币 |
|--------|----------|------|
| 引擎引擎 | 加速 +1 | 150/300/500 |
| 涡轮 | 极速 +1 | 150/300/500 |
| 轮胎 | 操控 +1 | 120/240/400 |
| 悬挂 | 抓地 +1 | 120/240/400 |

## 4. 视觉风格（Visual Style）

### 4.1 总体美学

- **基调**：16-bit（SNES 级）像素风，低饱和复古配色 + 高对比霓虹点缀，避免纯现代高饱和。
- **像素规格**：逻辑分辨率 960×540，渲染倍率 2（1 逻辑像素 = 2 物理像素），精灵 16×16～32×32px 为单元绘制。
- **精灵绘制原则**：硬边、无抗锯齿、有限色板（每精灵 ≤ 16 色）、2 帧动画循环（轮胎滚动/尾焰闪烁/人物不出现）。
- **界面字体**：像素字体（如 Press Start 2P / 自绘 8×8 位图字库），HUD 用大字号 + 描边。

### 4.3 分层渲染（视差 + 伪 3D）

```
渲染顺序（从远到近）：
  L0 天空/远景（纯色 + 云朵/飞鸟像素，随车速横向缓慢移动，视差 0.1）
  L1 远景地貌（山/城市天际线剪影，视差 0.3）
  L2 赛道外地面（草地/沙地/雪地，视差 0.6）+ 装饰物（树木/路灯）
  L3 赛道路面 + 车道线 + 检查点/路缘（视差 1.0，随玩家移动）
  L4 道具（油桶/加速带/轮胎）
  L5 车辆（玩家 + AI，按 y 排序，近者后绘制）
  L6 粒子层（漂移烟 / 尾焰 / 火花 / 碰撞碎片）
  L7 HUD（速度表 / 圈数 / 名次 / 氮气槽 / 检查点提示）
```

- **伪 3D 速度感**：当 v > 60% v_max 时，对 L3～L5 施加极轻微的纵向缩放（1.0 → 1.03）与 FOV 推近，模拟前冲视角；恢复时平滑回弹。
- **屏幕震动**：撞墙/油桶爆炸时，视口位移 2～4px 随机抖动 0.2s（震幅随撞击速度）。

### 4.4 HUD 设计

- 左上：圈数指示（当前圈/总圈）+ 检查点提示（MISSED CHECKPOINT 红色闪烁）。
- 左下：名次（第 1/6）+ 与前后车距离。
- 右下：速度表（像素指针表盘，红区 80%+ 变红）+ 氮气槽（品红渐变，满槽闪烁）。
- 右上：总用时 / 当前圈计时。
- 顶部中央：赛道名 + 倒计时/漂移中连击提示（“DRIFT x2!”）。

### 4.5 音效与音乐（风格配套）

- **音乐**：8-bit 芯片音乐（square/triangle 波），每赛道 1 首循环，节奏随速度略升调。
- **音效**：引擎（随转速变调）、漂移胎响（白噪声滤波）、氮气喷射（上滑音）、碰撞（低频“咚”）、金币拾取（上行双音）、倒计时哔声（GO 为高音）。
- 全部音效用 Web Audio API 程序化合成，**零外部资源**，保证单文件可运行。

### 4.6 界面风格（菜单/结算）

- 主菜单：像素标题大字 + 车辆剪影旋转展示 + 赛道缩略图（像素小图）。
- 选车界面：车辆 3/4 视角大图 + 六边形属性图（雷达图）。
- 结算界面：领奖台剪影 + 金/银/铜奖杯像素 + 每项统计逐行弹出动画。

## 5. 技术约束与验收标准

### 5.1 技术约束

- **单文件交付**：`pixel-racing-game.html` 内含 HTML/CSS/JS，无外部依赖、无网络请求。
- 固定时间步长 `requestAnimationFrame` + 累加器（120Hz 逻辑步进，插值渲染）。
- 状态机：`MENU → GARAGE → COUNTDOWN → RACE → FINISH → RESULT`，便于测试驱动。
- 可测试性：核心逻辑（物理/检查点/名次）与渲染解耦，暴露 `window.PixelRacerAPI`（含 `start/step/teleport` 等测试钩子）。

### 5.2 验收标准（核心玩法维度）

| 检查项 | 标准 |
|--------|------|
| 起跑 | 倒计时、抢跑罚时、起步加速均生效 |
| 漂移→氮气 | 漂移积氮、断漂丢失、喷射提速闭环可复现 |
| 检查点 | 漏检无效圈 + 强制回退正确 |
| 圈数与结算 | 3 圈后正确排名、统计完整 |
| 赛道 | 3 条首发赛道可玩、无穿模（碰撞盒有效） |
| 车辆 | 6 辆车属性差异可感知（极速车 vs 操控车） |
| 视觉 | 像素风统一、视差与粒子正常、HUD 无遮挡赛道 |
| 性能 | 60 FPS 稳定，降级 30 FPS 不丢逻辑步长 |
