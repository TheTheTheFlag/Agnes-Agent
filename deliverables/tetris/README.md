# 俄罗斯方块 Tetris（网页版）

单文件 HTML/CSS/JS 实现的俄罗斯方块，无需构建、无需依赖，双击即玩。

## 运行方式

1. 直接双击打开 `deliverables/tetris/index.html`（推荐 Chrome / Edge / Firefox 等现代浏览器）。
2. 或在浏览器地址栏输入该文件的绝对路径（`file:///.../deliverables/tetris/index.html`）。
3. 无需服务器、无需安装任何依赖。

打开后会看到「俄罗斯方块」开始遮罩层，点击 **开始游戏** 或按 **P / 空格** 即可开始。

## 操作说明

| 按键 | 功能 |
| --- | --- |
| ← / → | 左右移动 |
| ↓ | 加速下落（软降） |
| ↑ | 顺时针旋转 |
| 空格 | 硬降（直接落底） |
| P | 暂停 / 继续 |
| 空格 / Enter | 未开始或已结束时开始新局 |

界面按钮：**开始 / 重开**、**暂停 (P)**，以及遮罩层上的 **开始游戏 / 继续游戏 / 重新开始**。

## 技术说明

- 棋盘 10×20，单元格 30px（画布 300×600）；预览画布 120×120。
- 使用 Canvas 2D 绘制，`requestAnimationFrame` 驱动主循环，`dropInterval` 控制自动下落节奏。
- 已固定方块存于 `board` 二维数组，活动方块为 `current = {type, matrix, x, y}`。
- 提供调试接口 `window.__tetris.getState()`，可在控制台查看当前分/等级/状态。
