# 像素风格赛车游戏 — 设计文档

- 文档版本：v1.0
- 目标平台：浏览器（HTML5 Canvas / 可选 Pygame 桌面版）
- 渲染风格：16-bit 复古像素风（致敬《OutRun》《RC Pro-Am》）
- 目标帧率：60 FPS（低配可降至 30 FPS）
- 单局时长：2～4 分钟

---

## 1. 游戏概述

一款**俯视角（Top-down / 伪 3D 缩放）像素赛车游戏**，玩家驾驶像素赛车在环形赛道上与 AI 对手竞速，通过漂移、道具与走线争取名次。核心乐趣：**"快节奏漂移 + 复古像素美学 + 简单上手的操控深度"**。

### 1.1 核心循环（Core Loop）

```
选车（属性取舍） → 倒计时起跑 → 竞速（漂移积攒氮气）→ 3 圈完赛 → 结算（名次/时间/奖励）→ 解锁新赛道/车辆
```

### 1.2 模式

| 模式 | 说明 |
|------|------|
| 快速比赛（Quick Race） | 单场 3 圈，可选赛道与难度 |
| 锦标赛（Championship） | 3 场连赛积分制，总积分排名 |
| 计时赛（Time Attack） | 无对手，刷最快圈速（Ghost Car 影子车） |
| 练习漂移（Drift Practice） | 空旷场地练习漂移与氮气机制 |

## 2. 玩法规则

### 2.1 比赛流程

1. **起跑**：3-2-1-GO 倒计时；倒计时期间按住油门可使转速预加载，绿灯亮起瞬间获得小幅度起步加速（失误判定：提前 0.3s 起步触发"抢跑"警告，比赛开始后罚时 2s）。
2. **圈数**：默认 3 圈；每圈必须完整通过所有检查点（Checkpoint），漏过检查点则本圈无效并强制回退到最近检查点。
3. **完赛**：冲线后按到达顺序排名；显示单圈最快、总用时、漂移积分。

### 2.2 漂移与氮气（Drift & Nitro）

- 高速过弯时按住 **漂移键** 进入漂移状态：车辆侧滑、轨迹留下像素轮胎痕。
- 漂移持续 0.5s 以上开始积累 **氮气槽**（Nitro Meter），漂移角度越接近理想角度（约 45°～75°）积累越快，撞墙会打断积累。
- 氮气槽满后可释放 **氮气加速（Nitro Boost）**，持续 2.5s，期间速度提升 30%，车尾喷出像素火焰。
- 连续 3 次"完美漂移"（未撞墙且保持理想角度）触发 **Combo**，氮气获取量 ×1.5。

### 2.3 碰撞与惩罚

| 事件 | 后果 |
|------|------|
| 撞赛道护栏 | 速度损失至当前速度的 55%，氮气积累清零，短暂硬直 0.4s |
| 撞 AI 车辆 | 双方降速至 70%，被撞方获得 0.5s 无敌帧 |
| 驶离赛道（草地/沙地） | 持续减速至 40%，抓地力下降（易打滑） |
| 撞锥桶/轮胎墙 | 轻微减速，无硬直 |

### 2.4 道具（路面拾取）

赛道上的问号方块拾取后随机获得（按权重）：

| 道具 | 权重 | 效果 |
|------|------|------|
| 氮气罐 | 35% | 立即 +50% 氮气槽 |
| 机油（地雷） | 25% | 在身后留下机油，后车碾过打滑 1.2s |
| 护盾 | 20% | 免疫一次碰撞惩罚 |
| 磁铁 | 15% | 3s 内自动向正前方最近对手吸附靠近 |
| 金币 | 5% | 结算时额外 +100 分 |

### 2.5 计分与结算

- 排名分：第 1 名 100 / 第 2 名 70 / 第 3 名 50 / 第 4+ 名 30。
- 漂移分：每次漂移按角度与时长计分，完美漂移 ×1.5。
- 金币：每个 +10 分。
- 结算画面展示：名次、总时间、最快圈、漂移总分，并提示解锁项。

### 2.6 AI 对手

- 每场 1～5 名 AI 车手（根据赛道宽度决定）。
- AI 难度三档：休闲（失误多、速度 70%）、标准（90%）、竞技（100% 且会使用氮气）。
- AI 会躲避障碍、沿理想线路走线，竞技难度下会主动使用道具。

## 3. 像素美术风格定义

### 3.1 总体风格

- **参考系**：SNES 16-bit 时代赛车游戏，色彩饱和、轮廓清晰、颗粒感强。
- **分辨率规范**：逻辑分辨率 **320×224**（经典 4:3），4 倍整数放大渲染到 1280×896 窗口（或自适应缩放），保证像素完全对齐、无模糊。
- **调色板**：全局限制在 **48 色**以内（每场景 32 色 + 共享 UI 16 色），营造复古硬件的"色带感"。

### 3.2 主色调板（示例 HEX）

| 用途 | 颜色 |
|------|------|
| 沥青主色 | `#3a3a3c` / 次色 `#4a4a4e` |
| 赛道白线 | `#e8e8e8` |
| 路肩红白格 | `#d23b3b` / `#f2f2f2` |
| 草地 | `#3fae49` / 深 `#2f8c38` |
| 沙地 | `#e0c068` |
| 水面/反光 | `#3d7fd6` |
| 车体红 | `#e04040`，黄 `#f0c040`，蓝 `#4080e0`，绿 `#40c060` |
| 阴影 | `#1c1c1e` |
| 天空（UI 边框） | `#2b2b4a` |

### 3.3 像素规格

| 对象 | 尺寸（像素） | 说明 |
|------|------|------|
| 玩家赛车 | 16×24 | 俯视车身，含车顶、尾翼、前窗 |
| AI 赛车 | 16×24 | 同规格不同配色 |
| 轮胎痕 | 4×4 单个 | 半透明深灰，逐渐淡出 |
| 路肩/护栏 | 8×8 图块 | 红白相间 |
| 道具方块 | 12×12 | 带问号，闪烁动画 4 帧 |
| 树木 | 16×16 | 圆形树冠 + 阴影 |
| HUD 图标 | 8×8 | 氮气、道具、名次 |

### 3.4 动画与细节规范

- 所有动画帧率 **8 FPS**（像素风经典节奏），与游戏 60FPS 主循环分离。
- 赛车尾部排气管在加速时冒 4×4 像素灰烟；氮气时变为 6×6 橙蓝火焰。
- 漂移时轮胎痕持续 3s 后渐隐。
- 起跑灯为红→黄→绿的三灯像素指示灯。
- 车辆被撞时 0.1s 闪烁（无敌帧表现）。
- 背景装饰（观众、旗帜、云朵）静止或极缓慢滚动，突出前景速度感。
- 禁止使用线性渐变/抗锯齿外轮廓；阴影用纯色错位像素实现。

### 3.5 缩放规则

- 画布按整数倍放大（1x/2x/3x/4x），每像素渲染为 `scale × scale` 实心方块。
- 使用 `image-rendering: pixelated`（Web）或 `NEAREST` 采样（桌面），禁用平滑插值。

## 4. 赛道布局

### 4.1 赛道数据模型

赛道由 **中心线（Centerline）点列 + 半宽（Half-Width）** 定义，渲染时沿中心线法线方向扩展成路面带，并在两侧生成草地/护栏。所有赛道以 JSON 描述，便于编辑器与程序化生成。

```json
{
  "id": "sunset_circuit",
  "name": "落日湾赛道",
  "difficulty": 1,
  "length_m": 2400,
  "laps": 3,
  "half_width": 90,
  "surface": ["asphalt", "dirt", "sand"],
  "checkpoints": 12,
  "start_grid": [[0, 0], [0, 40], [0, 80]],
  "nodes": [
    {"x": 160, "y": 112, "curve": 0},
    {"x": 240, "y": 112, "curve": 0.2},
    {"x": 300, "y": 60,  "curve": 0.6}
  ]
}
```

### 4.2 首个赛道示例：「落日湾赛道 Sunset Circuit」

布局形状：**左半环 + 右发卡弯的 8 字形**（长度约 2400m，标准难度）。

```
        ════════════╗
        ║   S/F   ╔═╝      S/F = 起终点线
        ║         ║        弯道 1：右缓弯
        ╚═╗   ┌───╝        弯道 2：左发卡（U 型）
          ║   │            弯道 3：S 型组合
          ║   │            弯道 4：右高速弧
          ╚═══╝
```

| 弯道 | 类型 | 半径（px） | 建议档位/策略 |
|------|------|------|------|
| T1 | 右缓弯 | 240 | 全油门通过，可轻度漂移 |
| T2 | 左发卡 U 弯 | 90 | 重刹 + 大角度漂移，氮气最佳积累点 |
| T3a/T3b | S 型组合 | 150/180 | 连续小漂移，保持节奏 |
| T4 | 右高速弧 | 300 | 贴内线全油门，可释放氮气 |

- 发车区直道约 300px，足以在第一弯前完成一次氮气充能。
- 路面 3 段材质：沥青（抓地 1.0）/ 沙土（抓地 0.7，扬起尘土）/ 草地（抓地 0.4，减速带）。
- 赛道边缘放置轮胎墙与路肩；固定位置摆放道具方块 8 个。

### 4.3 赛道清单（规划）

| 赛道 | 主题 | 难度 | 特点 |
|------|------|------|------|
| 落日湾 Sunset Circuit | 海滨小镇 | ★ | 8 字形，适合入门 |
| 霓虹都市 Neon Downtown | 夜景城市 | ★★ | 窄道 + 大量发卡弯 |
| 火山熔岩 Volcanic Ridge | 火山公路 | ★★★ | 长直道 + 高速弯，护栏少 |
| 雪原赛道 Snow Peak | 雪山 | ★★ | 低抓地力，易漂移 |

### 4.4 检查点与计时

- 每圈 12 个隐形检查点，沿中心线等距分布；经过时播放"滴"音效并刷新小地图进度。
- 计时采用"最佳圈速"分圈记录；漏检自动回退到上一检查点。

## 5. 车辆属性

### 5.1 属性面板（7 项）

| 属性 | 范围 | 说明 |
|------|------|------|
| 最高速度 Top Speed | 80～130 km/h（游戏内 0～1 归一化） | 直道极限 |
| 加速 Acceleration | 0.6～1.0 | 0→100km/h 用时（越小越快） |
| 操控 Handling | 0.5～1.0 | 转向灵敏度与最大转向角 |
| 抓地力 Grip | 0.5～1.0 | 抗侧滑能力（越高越稳） |
| 漂移倾向 Drift | 0.3～1.0 | 进入漂移的容易度与氮气获取率 |
| 氮气 Nitro | 0.4～1.0 | 氮气槽容量与释放强度 |
| 耐久 Armor | 0.4～1.0 | 碰撞惩罚减免（撞墙速度保留比例） |

### 5.2 初始车辆（3 台）

| 车辆 | 定位 | 极速 | 加速 | 操控 | 抓地 | 漂移 | 氮气 | 耐久 |
|------|------|------|------|------|------|------|------|------|
| 闪电 S1（平衡） | 新手首选 | 105 | 0.80 | 0.80 | 0.80 | 0.60 | 0.70 | 0.70 |
| 烈马 GT（速度） | 直道狂魔 | 125 | 0.90 | 0.65 | 0.70 | 0.50 | 0.80 | 0.60 |
| 暴风 X（漂移） | 弯道大师 | 90 | 0.70 | 0.90 | 0.60 | 0.95 | 0.85 | 0.55 |

### 5.3 物理参数（实现参考）

- 采用 **类卡丁车（Kart）物理**：速度分解为前向与侧向分量，侧向分量被"抓地力"阻尼吸收，漂移时降低阻尼系数。
- 转向随速度衰减：速度越高，转向响应越低（`turnRate = baseTurn × (1 - v/vmax × 0.5)`）。
- 地面摩擦系数与轮胎痕纹理由赛道材质决定。
- 氮气释放：目标速度 ×1.3，随时间线性回落。

### 5.4 升级系统（可选）

- 每场结算获得金币，可在车库里购买属性 +5% 改装（最多 3 级），改装带视觉变化（尾翼、涂装条纹、轮毂颜色）。

## 6. 控制方案

### 6.1 键盘（默认）

| 按键 | 功能 |
|------|------|
| `↑` / `W` | 油门（按住蓄力起步转速） |
| `↓` / `S` | 刹车 / 倒车（速度 < 5 时） |
| `←` / `A` | 左转 |
| `→` / `D` | 右转 |
| `Space`（空格） | 漂移（与转向方向叠加） |
| `Shift` | 氮气释放 |
| `E` / `Enter` | 使用道具 |
| `C` | 切换视角（俯视 / 近距离） |
| `Esc` / `P` | 暂停菜单 |
| `R` | 重置回赛道（卡住时，罚时 3s） |

### 6.2 手柄（Xbox/兼容）

| 手柄 | 功能 |
|------|------|
| 左摇杆 | 转向（+前后推为油门/刹车） |
| RT / LT | 油门 / 刹车 |
| A 键 | 漂移 |
| B 键 | 氮气 |
| X 键 | 使用道具 |
| 十字键上 | 视角切换 |
| Start | 暂停 |

### 6.3 触摸（移动端适配，可选）

- 左侧：虚拟方向摇杆（左下，拇指）。
- 右侧：漂移按钮（右下）+ 氮气按钮（右中）+ 道具按钮（右上）。
- 支持横屏锁定，UI 缩放至安全区。

### 6.4 输入缓冲与辅助

- **起步转速**：倒计时按住油门会蓄力（0→100%），绿灯瞬间松开或保持均可获得加速；需避免抢跑。
- **输入缓冲**：转向/漂移输入缓冲 120ms，减少连打损失。
- **辅助选项（可关闭）**：转向辅助（轻微自动贴线）、刹车辅助（弯前自动轻刹）、漂移辅助（自动维持理想角度）。

### 6.5 按键重映射

- 全部键位可在设置菜单重映射，并支持保存/恢复默认。

| 名次 | 左上 | 当前名次 / 总车数 |
| 圈数 | 左上（名次下） | LAP 2/3，本圈用时 |

| 小地图 | 右上 | 赛道轮廓 + 车辆点 + 检查点进度 |

## 8. 音频规范（简）

- 引擎音：音调随转速升高（合成方波/锯齿波，复古 FM 感）。
- 漂移音：持续的沙沙白噪声。
- 氮气音：上升音效。
- 撞墙/道具：8-bit 短音效。
- 背景音乐：2 首 chiptune 循环（BPM 140 主菜单 / BPM 150 比赛），16 通道追踪器格式（如 .mod/.it）。

## 9. 技术规格摘要

| 项 | 规格 |
|----|------|
| 渲染 | HTML5 Canvas 2D，`image-rendering: pixelated`；或 Pygame 缩放表面 |
| 逻辑分辨率 | 320×224（@4x → 1280×896） |
| 主循环 | requestAnimationFrame，固定时间步长 16.67ms，物理插值 |
| 输入 | Keyboard / Gamepad API / Touch |
| 存档 | localStorage（成绩、解锁、改装） |
| 资源 | 单张精灵表 PNG + JSON 元数据，减少 HTTP 请求 |
| 测试 | 起跑判定、碰撞回退、检查点计数、漂移积分、AI 走线单元测试 |
