# 《像素狂飙 Pixel Racer》游戏设计文档（GDD）

> 版本：v1.0
> 类型：像素风格竖版赛车小游戏（Top-down Vertical Scrolling Racer）
> 目标平台：桌面浏览器（桌面键盘 + 移动端触屏自适应）
> 技术栈：HTML5 Canvas + 原生 JavaScript（单文件，无外部依赖）
> 目标时长：单局 60~120 秒，支持无尽模式与三关制限时模式

---

## 1. 游戏概述

### 1.1 一句话概念
一辆 8-bit 像素赛车在一条无限向下的像素高速公路上疾驰，躲避车流、收集金币与油桶，在限时内尽可能跑得更远、拿更高分。

### 1.2 设计愿景（Vision）
- **怀旧但不粗糙**：以 NES/Game Boy 时代 16×16 像素粒度的美术为基底，配合现代配色（高饱和霓虹 + 复古 CRT 滤镜感），做出"一眼像素、细节耐看"的画面。
- **上手即玩**：三键操作（左/右/刹车），10 秒内理解规则，30 秒内产生"再来一局"的冲动。
- **节奏感优先**：赛车加速/减速、换道、碰撞都有明确的"手感"反馈（速度线、抖动、粒子、屏幕震动、音效）。

### 1.3 核心循环（Core Loop）
行驶加速 → 观察前方车流 → 换道/刹车躲避 → 擦车得分（近距超车）→ 拾取金币/道具 → 撞车（减命或结束）→ 结算分数 → 再来一局

### 1.4 与同类游戏差异点
- 加入"近距超车（Near Miss）"得分系统：贴近对手车擦身而过可获得额外分数与连击倍率，鼓励"险中求胜"。
- 双层赛道视觉（主车道 + 路肩/护栏），通过滚动速度差营造纵深感。

## 2. 玩法规则

### 2.1 游戏状态机
```
BOOT(加载) → TITLE(标题) → COUNTDOWN(3-2-1) → RACING(进行中) 
           → PAUSE(暂停) → GAME_OVER(结算) → RANKING(成绩) → TITLE
```
- 任意时刻按 `P` 或 `Esc` 暂停/恢复；暂停时显示半透明遮罩 + 选项。
- GAME_OVER 后展示本局统计（距离、分数、最高连击、拾取数），按回车或点击"再来一局"重开。

### 2.2 比赛规则
1. **目标**：在 90 秒倒计时结束前跑出尽可能远的距离（米），并累计最高分。
2. **生命机制（限时模式）**：初始 3 条命；撞车 -1 命并损失当前连击倍率、赛车闪烁 2 秒无敌；命归零立即结束。
3. **无尽模式**：无倒计时，速度随时间/里程递增，撞一次即结束（Hardcore）。
4. **失败条件**：
   - 限时模式：命 = 0；或倒计时归零。
   - 无尽模式：碰撞一次。
5. **胜利/结算**：计时结束后按"总得分 = 距离分 + 金币分 + 近距超车分 × 连击倍率"结算，显示评级（S/A/B/C/D）。

### 2.3 得分规则
| 行为 | 得分 | 说明 |
|---|---|---|
| 行驶距离 | +1 分/10 米 | 实时累计 |
| 金币 | +50 分/枚 | 普通金币 |
| 金砖/宝石 | +200 分 | 稀有，出现率低 |
| 近距超车（Near Miss） | +100 × 连击倍率 | 判定：横向重叠区间 < 12px 且未碰撞 |
| 连击（Combo） | 3 秒内连续 Near Miss 递增 | 倍率 1x→2x→3x…上限 5x；撞车/超时清零 |
| 油桶 | +150 分 | 撞碎油桶不扣命（视为"破桶特技"） |

### 2.4 道具系统
| 道具 | 效果 | 时长 |
|---|---|---|
| 闪电 | 全屏短暂减速（慢动作 0.6x） | 3 秒 |
| 盾牌 | 抵挡一次碰撞（免死） | 直到被消耗 |
| 磁铁 | 自动吸附一定范围内的金币 | 5 秒 |
| 氮气 | 提速 1.5 倍 + 无敌擦车 | 3 秒 |
- 道具以闪烁方块形式出现于车道，拾取后左上角显示图标与剩余时间。

### 2.5 难度曲线
- 基础车速 V0 = 240 px/s，每 10 秒 +20 px/s，上限 560 px/s（无尽模式无上限，逐步逼近极限反应）。
- 车流密度：开局 3~5 辆同屏，随难度上升至 10~12 辆。
- 车流模式：直线慢车、变速车（忽快忽慢）、并排堵路、快速穿插车（运动轨迹可预测）。
- 限时模式分 3 个 Stage（城市黄昏 → 霓虹夜路 → 高速公路黎明），每 30 秒切换主题并提升密度。

## 3. 赛车与赛道像素美术风格

### 3.1 总体风格定位
- **像素粒度**：逻辑像素 1 单位 = 显示 1 个像素格；采用 **16×16 精灵格（sprite grid）**，赛车 16×32（半格宽、两格高）。
- **分辨率**：画布逻辑分辨率 320×568（16:9 竖版变体），渲染时整数倍放大（2x/3x）以保持像素锐利；主循环在固定 60 FPS 下按 `dt` 更新。
- **配色方向**：高饱和霓虹（洋红 #FF2E97、青 #00E5FF、黄 #FFD500、橙 #FF7A00）+ 深色背景（#101018、#1A1030）+ 少量低饱和灰度（路面、阴影），营造"赛博复古"感。

### 3.2 色板（16 色主色板）
```
#101018 背景夜空        #1A1030 远景山体        #2A2040 路面深色带
#3A3050 路面浅色带      #FFFFFF 高光/车灯       #FF2E97 玩家车主色（洋红）
#00E5FF 对手车青色      #FFD500 金币/黄线       #FF7A00 油桶橙
#22DD55 道具绿          #8866FF 宝石紫          #AA2233 撞车红
#555566 护栏/轮胎       #999999 远处车辆         #333333 阴影           #00AA88 生命/UI绿
```

### 3.3 玩家赛车（Player Car，16×32 精灵）
- 车身两格（上格车头+挡风、下格车体+尾灯），车头微尖、尾翼明显。
- 三种配色方案：**红白（默认）**、**青黑**、**黄黑**，标题界面可切换。
- 动作帧：
  1. `idle`（直行，尾灯微弱）
  2. `left-1 / left-2`（左移，车身左倾 1px 循环两帧模拟漂移）
  3. `right-1 / right-2`（右移）
  4. `brake`（刹车，尾灯高亮红光 + 车头微沉）
  5. `hit`（碰撞，车身破碎/倾斜 + 火花粒子）
- 阴影：车身下方 2px 半透明黑块，随"离地高度"（氮气/跳跃时）缩小。

### 3.4 对手车（Traffic，16×32）
- 6 种车型：轿车（青）、面包车（灰+条纹）、卡车（长车 16×48，更慢更占道）、跑车（橙，快车）、警车（白蓝，可触发彩蛋）、摩托车（8×16，灵活穿插）。
- 每车 2~3 帧轮转动画（轮胎旋转 + 车身轻微上下浮动）。
- 前车尾灯常亮红色，便于玩家判断距离。

### 3.5 赛道（Track）
- **路面**：三车道（每道宽 56px）+ 两侧路肩（24px 沥青 + 白色虚线护栏）。
- 路面滚动：以 4 条 64px 高的路面纹理带循环下移，纹理带含随机接缝、油渍、裂缝。
- 车道分隔线：黄色虚线（32px 亮 + 24px 暗），滚动速度与路面一致。
- 路肩：红白相间锯齿块（vintage 风格）+ 偶尔出现广告牌（像素文字"PIXEL OIL / TURBO RAMEN"）。
- 环境（伪 3D 视差，两层）：
  - **远层**：城市剪影/霓虹建筑，滚动速度为赛道 30%；
  - **近层**：路灯/棕榈树/广告牌，滚动速度为赛道 70%。
- 主题：每 Stage 更换路面配色与环境（黄昏橙粉 → 霓虹紫蓝 → 黎明金黄）。

### 3.6 特效
- 氮气尾焰：车尾 3~5 个 2×2 像素粒子（青→白渐退）。
- 擦车火花：碰撞判定边缘生成 8 个黄色/橙色 1px 粒子，持续 0.4s。
- 撞车爆裂：车体碎片 6~10 块向四周飞散 + 全屏白闪 80ms + 屏幕震动 4px/0.3s。
- 得分飘字：+50 等以 8px 像素字体上浮 0.6s 后淡出。
- 速度线：车速 > 420 时画面上下边缘出现 1px 白色速度线。

## 4. UI 布局

### 4.1 整体布局（320×568 逻辑坐标）
```
┌──────────────────────────────┐
│ 状态栏(0-28)                  │
│  ❤❤❤  ●●○○ (道具)   02:31    │
├──────────────────────────────┤
│                              │
│      游戏区域 (28-536)        │
│      (Canvas 主渲染区)        │
│                              │
├──────────────────────────────┤
│  操作提示区 (536-568)         │
│  ◀ ▶ 控制   空格=刹车          │
└──────────────────────────────┘
```
- 状态栏像素风格深蓝半透明底 + 白字，字体用 `monospace` + `image-rendering: pixelated`。

### 4.2 界面清单
| 界面 | 内容 | 交互 |
|---|---|---|
| 标题页 | 游戏 LOGO（抖动像素字）、车辆预览（循环行驶）、"开始/无尽/设置/操作说明" | 键盘/点击 |
| 倒计时 | 3-2-1-GO 大字，逐帧放大淡出 | 无 |
| 游戏中 HUD | 生命、道具、倒计时、距离(m)、得分、Combo 显示 | 实时刷新 |
| 暂停 | 继续 / 重开 / 回主菜单 / 音量 | 键盘/点击 |
| 结算页 | 本局统计 + 评级 S~D + 历史最高分（localStorage） | 回车/点击再来 |
| 设置 | 音效/音乐音量、震动开关、画质（粒子量） | 滑杆/开关 |

### 4.3 HUD 细节
- 得分居中顶部大号显示（如 `012345`），随分数滚动轻微缩放。
- Combo 位于右侧：`x3!` 黄色闪光 + 像素火焰小图标，快消失时闪烁提示。
- 道具图标显示剩余时间（外圈圆形进度条）。
- 结算评级动画：字母由小到大弹出，颜色随评级变化（S=金、A=紫、B=蓝、C=绿、D=灰）。

## 5. 操作方式

### 5.1 键盘（桌面）
| 按键 | 功能 |
|---|---|
| ← / A | 左移一车道方向（按住连续左移） |
| → / D | 右移一车道方向（按住连续右移） |
| 空格 / ↓ / S | 刹车（减速至 65% 车速，尾灯亮） |
| P / Esc | 暂停 |
| Enter | 开始 / 确认 / 再来一局 |
| M | 静音切换 |

- 手感参数：横向速度 260 px/s，松开后有 0.08s 惯性滑行，避免"瞬移式"操作。
- 边界碰撞：碰护栏不会死，但被弹回 + 减速 15%（惩罚但宽容）。

### 5.2 触屏（移动端）
- 屏幕左半区触摸 = 左移，右半区触摸 = 右移；双指按下 = 刹车。
- 游戏区下方显示虚拟按钮（◀ ▶ 与刹车图标）作为提示。

### 5.3 手柄（可选）
- 十字键左右移动，A 键刹车，Start 暂停（预留，不做强制）。

## 6. 音效风格

### 6.1 总体风格
- **Chiptune 复古风**：8-bit 方波/三角波合成音效，用 Web Audio API 实时合成（无音频文件，零加载成本）。
- 主音量可调；默认音乐 60%、音效 80%。

### 6.2 背景音乐（BGM）
- 标题页：柔和 8-bit 循环（约 8 小节，速度 100 BPM，C 大调）。
- 比赛：鼓点 + 贝斯驱动的快节奏（140~170 BPM 随 Stage 提速），主旋律简单洗脑，2 小节循环变奏。
- 结算：短促结束音（胜利上扬 / 失败下行）。
- 实现：16 通道 step sequencer，用 `setInterval`/`AudioContext` 定时器驱动方波振荡器。

### 6.3 音效清单（SFX）
| 事件 | 音效设计 |
|---|---|
| 倒计时 | 每拍"嘀"（短方波 880Hz），GO 为上扬双音 |
| 换道 | 轻"嗖"（噪声扫频 200→600Hz，80ms） |
| 刹车 | 尖锐"吱"（方波 300Hz 滑音 + 噪声） |
| 拾取金币 | 清脆"叮"（三角波 1318Hz，60ms） |
| 拾取宝石/道具 | 三连上升音（C-E-G） |
| 近距超车 | 短促"嗡-呼"（带通噪声 + 音高微升），连击时音高逐级升高 |
| 碰撞 | 重低音"砰"（低频方波 80Hz 衰减 + 白噪爆音） |
| 氮气 | 持续引擎轰鸣（锯齿波滤波扫频） |
| 结算 | 等级音（S 级为四连上升琶音） |

### 6.4 音量/静音策略
- `M` 全局静音；设置页分别控制 BGM/SFX 音量。
- 页面失焦自动暂停 BGM 与游戏计时，恢复焦点续跑（防刷分）。

## 7. 技术规格与实现要点

### 7.1 渲染
- 单 `<canvas>`，`ctx.imageSmoothingEnabled = false`，CSS `image-rendering: pixelated`。
- 精灵用二维 0/1 字符数组定义（如 `"1111000111"`），启动时绘制到离屏 canvas 以复用。
- 滚动采用"余数累加"避免像素抖动：`offset = (offset + speed*dt) % tileHeight`。

### 7.2 碰撞
- 使用 AABB 且**收窄 30%**（视觉比判定宽，提供宽容度）。
- 命中顺序：先判定道具，再判定金币，最后判定车（Near Miss 单独检测横向间隔）。
- 无敌帧：碰撞后 2s 内赛车半透明闪烁且不参与碰撞。

### 7.3 存档
- `localStorage` 保存：最高分、最佳距离、解锁车辆配色、总游戏局数、设置项。

### 7.4 性能目标
- 60 FPS 稳定；粒子上限 120；同屏车辆上限 12；移动端自动降粒子量（画质开关）。

## 11. 验收标准（Definition of Done）

1. 单 HTML 文件可离线运行（无外部请求、无框架）。
2. 三种操作方式（键盘/触屏/可选手柄）可用。
3. 完整状态机（标题→倒计时→比赛→暂停→结算→重开）无死锁。
4. 碰撞、Near Miss、Combo、道具、计分逻辑通过单元测试/自测用例。
5. 画面保持像素锐利（无模糊缩放），60 FPS 达标（Chrome 桌面中端配置）。
6. 音效全部为程序合成，静音/音量调节生效。
7. localStorage 存档读写正常。
