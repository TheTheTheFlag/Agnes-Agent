## 2. 游戏内嵌资源明细（无任何外部文件）

| 资源 | 说明 | 实现方式 |
| --- | --- | --- |
| 玩家赛车 | 红色像素赛车（16×18 像素图案 ×3 倍放大） | 代码内字符矩阵 + 调色板 |

| 金币道具 | 旋转的金币（¥） | Canvas 圆弧 + 缩放动画 |
| 爆炸粒子 | 撞车火花粒子特效 | Canvas 粒子系统（42 个粒子） |
| 音效 ×4 | 开始 / 金币 / 撞击 / 结束 | WebAudio 程序合成（Oscillator），不占文件体积 |
| 字体 | 系统等宽字体（Courier New / monospace） | 无字体文件 |

## 3. 运行环境要求

- 任意现代浏览器：Chrome / Edge / Firefox / Safari（2018 年后版本均可）。
- 无需安装运行时、无需联网、无第三方库依赖。
- 移动端支持触摸操作。
