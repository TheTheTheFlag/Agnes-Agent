## 1. 游戏概述

### 1.1 一句话描述
玩家驾驶一辆像素赛车，在一条纵向滚动的公路上躲避车流、收集金币与道具，尽可能存活更久并获得更高分数。

### 1.2 游戏类型
- 玩法类型：单跑道纵向无限竞速（类似经典《Road Fighter》《Top Gear》的简化版）
- 视角：俯视（Top-down），固定竖屏跑道，道路自上而下滚动
- 进程模式：无尽模式（Endless），无终点，以里程/分数为目标

### 1.3 核心体验目标
1. **三秒上手**：操作只有"左右移动"，任何人无需教程即可游玩。
2. **紧张刺激**：速度随时间提升，车流密度增大，产生持续挑战。
3. **复古情怀**：8-bit 像素美术、CRT 扫描线、复古芯片音乐，唤起怀旧感。
4. **碎片化娱乐**：单局 1~3 分钟，随时可暂停/重开。

### 1.4 游戏规则总览（一句话版）
> 在速度不断加快的公路上左右闪避车辆，撞车即游戏结束；拾取金币加分，拾取道具获得护盾/加速/磁铁效果；坚持越久、得分越高。

## 2. 核心循环与玩法规则

### 2.1 核心循环（Core Loop）

```
开始游戏 → 加速行驶 → 躲避车流 → 收集金币/道具
                ↑                    │
                └──── 存活（继续） ────┘
                ↓（撞车）
          游戏结束 → 结算分数 → 刷新最高分 → 再来一局
```

每个循环周期（约 5~10 秒）内玩家经历一次"观察车流 → 决策变道 → 执行躲避 → 收获反馈"的微型挑战。

### 2.2 基础规则

| 规则项 | 说明 |
|---|---|
| 跑道 | 固定 3 车道（可在高难度阶段扩展至 4 车道），纵向滚动 |
| 玩家车辆 | 始终位于画面下方约 1/4 处，只能左右移动，不能上下移动 |
| 敌方车辆（AI 车流） | 从上向下驶来，速度略慢于道路滚动速度（表现为相对前进） |
| 碰撞判定 | 使用 AABB 包围盒，带 4px 的"宽容收缩"（玩家更友好的判定） |
| 游戏结束条件 | 玩家车辆与任意敌方车辆发生碰撞；玩家生命归零 |
| 生命系统 | 初始 3 条命；被撞后扣 1 条命并进入 2 秒无敌闪烁；生命耗尽则游戏结束 |
| 得分 | 距离分（每 10 米 +1 分）+ 金币分（每枚 +10 分）+ 连击奖励 |

### 2.3 难度曲线（无尽模式的推进）

游戏采用"阶段式加速"而非线性加速，让难度有可感知的波峰。

| 阶段 | 里程（米） | 基础速度(px/s) | 车流密度 | 特殊事件 |
|---|---|---|---|---|
| 热身 | 0 ~ 200 | 240 | 稀疏（1 车道 1 辆/6s） | 无 |
| 巡航 | 200 ~ 600 | 300 | 中等（每 3~4s 一批） | 开始出现金币串 |
| 繁忙 | 600 ~ 1200 | 360 | 高（2~3 辆并行） | 出现道具车 |
| 疯狂 | 1200 ~ 2000 | 420 | 极高（连环车流） | 出现速度漂移的"快车" |
| 极限 | 2000+ | 480 | 饱和 | 车流随机生成墙缝 |

> 具体数值在联调阶段微调，原则：**保证 90% 新手存活超过 30 秒**。

### 2.4 道具系统

道具以"道具车"（带星标的特殊车辆）形式出现在车流中，撞到即拾取（碰撞判定优先于伤害判定）。

| 道具 | 图标 | 效果 | 持续时间 |
|---|---|---|---|
| 护盾 SHIELD | 🛡 | 免疫一次碰撞，外观套上蓝色光罩 | 直到被击破或 10s |
| 磁铁 MAGNET | 🧲 | 自动吸取范围内金币 | 8s |
| 加速 BOOST | ⚡ | 速度 +40%，期间无敌 | 3s |
| 减速 SLOW | 🐢 | 道路减速 30%，便于穿插 | 5s |

**设计约束**：同一时刻最多持有一个道具（新道具覆盖旧道具），避免强度叠加失控。

### 2.5 金币与连击

- 金币以"直线串"（6~10 枚）或"曲线串"（S 形）两种阵型出现。
- 吃到金币时若与上一枚金币间隔 < 1.5s，则连击数 +1；连击每 5 连给 +20 额外分。
- 连击显示在 HUD 上，带有像素字体放大/抖动动画。

### 2.6 计分规则汇总

```
总分 = 距离分（米 × 1） + 金币分（枚 × 10） + 连击奖励 + 道具加成分
```

结算界面额外展示三档评价：
- 分数 ≥ 3000 → ★★★ 车神（Pixel Legend）
- 分数 ≥ 1500 → ★★ 老司机（Pro Driver）
- 分数 < 1500 → ★ 新手（Rookie）

## 3. 界面布局

### 3.1 全局屏幕结构（960×640 设计分辨率，实际按比例缩放）

```
┌────────────────────────────────┐
│ HUD 顶栏（高 48px）             │
│  [分数] [里程] [生命 ♥♥♥] [道具] │
├────────────────────────────────┤
│                                │
│          游戏画面               │
│     （跑道 + 玩家 + 车流）       │
│                                │
│                                │
├────────────────────────────────┤
│ 底部操作提示区（高 40px）       │
│  ← → 移动   P 暂停             │
└────────────────────────────────┘
```

### 3.2 各界面状态（Screen States）

| 状态 | 内容 | 进入/退出方式 |
|---|---|---|
| 标题界面 TITLE | Logo、赛车动画、"点击开始"、"最高分" | 启动时进入；点击后进入玩法 |
| 玩法界面 PLAYING | HUD + 跑道 + 车流 | 游戏主状态 |
| 暂停界面 PAUSED | 半透明遮罩 + "继续/重开/回主菜单" | P 键或点击暂停按钮 |
| 结算界面 GAMEOVER | 分数、评价星级、最高分、金币数、"再来一局/主菜单" | 生命耗尽时进入 |
| 帮助界面 HELP | 操作说明图文 | 主菜单/暂停界面点击"帮助" |

### 3.3 HUD 明细

| 元素 | 位置 | 说明 | 样式 |
|---|---|---|---|
| 分数 SCORE | 左上 | 当前总分，实时刷新 | 白色像素字 20px |
| 里程 DISTANCE | 分数右侧 | 显示 "1234m" | 灰色像素字 16px |
| 生命 HEARTS | 右上 | 3 颗心形像素图标，扣血变灰 | 8×8 像素心 |
| 道具槽 ITEM | 生命下方 | 当前持有道具图标 + 剩余秒数 | 16×16 图标 |
| 连击 COMBO | 屏幕中央偏上 | 连击 ≥3 时弹出 "COMBO x5!" | 黄色大字 + 抖动动画 |
| 速度条 SPEED | 右边缘竖条 | 显示当前速度档位 | 红黄绿渐变像素条 |

### 3.4 界面配色规范

- HUD 文字主色：`#FFFFFF`
- 高亮/警告色：`#FF4757`（红）、`#FFD32A`（黄）
- 信息色：`#70A1FF`（蓝）
- 遮罩：`rgba(0,0,0,0.6)`
- 全部使用系统字体 + `image-rendering: pixelated` 保证像素感

## 4. 操作方式

### 4.1 桌面端（主目标）

| 输入 | 功能 |
|---|---|
| ← / A | 向左变道/向左微移 |
| → / D | 向右变道/向右微移 |
| 空格 / ↑ / W | 使用当前道具（若有） |
| P / Esc | 暂停 / 继续 |
| Enter | 确认（菜单导航） |
| R | 快速重开（结算界面） |

> 移动采用"按住持续移动 + 松手惯性滑停"；不做锁定车道切换，保证操控手感流畅。

### 4.2 移动端（可选扩展）

| 输入 | 功能 |
|---|---|
| 触屏左半区按住 | 向左移动（按住越久速度越快） |
| 触屏右半区按住 | 向右移动 |
| 双击/道具按钮 | 使用道具 |
| 倾斜传感器（可选） | 重力左右倾斜控制 |

### 4.3 操作手感参数

| 参数 | 值 | 说明 |
|---|---|---|
| 玩家横向加速度 | 1200 px/s² | 起步响应快 |
| 最大横向速度 | 420 px/s | 可短时间横跨 2 个车道 |
| 摩擦减速 | 1800 px/s² | 松手后快速刹停，可控性强 |
| 输入缓冲 | 120ms | 防止按键连发误触 |
| 撞击无敌时间 | 2.0s | 闪烁频率 8Hz |

### 4.4 操作反馈
- 移动时车身轻微倾斜（旋转 ±3°）与轮胎粒子
- 变道时屏幕轻微横向位移（镜头跟手）
- 每次撞击：屏幕震动 0.3s + 红闪边框 + 震动音效

## 5. 美术风格设定

### 5.1 总体风格
- **8-bit 像素风格**，参考《OutRun》《Road Fighter》《像素冒险世界》
- 画布以 16px 基础像素格，逻辑分辨率 960×640，实际 3 倍放大（2880×1920）
- 色彩：高饱和、复古 32 色调色板（类似 NES 风格 + 少量现代点缀）
- 描边：物体使用 1px 深色描边（#222034），增强辨识度

### 5.2 调色板（核心 16 色）

| 色名 | HEX | 用途 |
|---|---|---|
| 沥青黑 | `#2B2B3C` | 道路底色 |
| 沥青深 | `#1E1E2E` | 道路阴影/路缘 |
| 车道白 | `#E8E8F0` | 车道线、道路标线 |
| 草地绿 | `#3E8948` | 两侧草地 |
| 草地亮绿 | `#4CAF50` | 草地斑纹 |
| 天空蓝 | `#6FA8DC` | 远山/天空（横向滚动装饰） |
| 玩家红 | `#E23B3B` | 玩家赛车主色 |
| 玩家黄 | `#FFD32A` | 玩家赛车点缀 |
| 车流蓝 | `#3B6FE0` | 普通 AI 车 |
| 车流紫 | `#8E44AD` | 高难度 AI 车 |
| 道具金 | `#FFC312` | 金币、星标 |
| 道具青 | `#12CBC4` | 护盾光效 |
| 加速红 | `#FF4757` | 加速道具 |
| 生命粉 | `#FF6B81` | 生命图标 |
| UI 白 | `#FFFFFF` | 文字 |
| UI 灰 | `#95A5A6` | 次要文字 |

### 5.3 车辆造型规范（Sprite 规格）

| 对象 | 尺寸(px) | 帧数 | 说明 |
|---|---|---|---|
| 玩家赛车 | 32×64 | 4（直行/左倾/右倾/受损冒烟） | 红色流线型，车灯黄色 |
| AI 轿车 | 32×64 | 2（正常/受损） | 蓝、紫、绿随机配色 |
| AI 卡车 | 40×80 | 2 | 大体积，尾部红色挡板 |
| 道具车 | 32×64 | 2 + 星标旋转帧 | 车顶带金色旋转星标 |
| 金币 | 12×12 | 4（旋转动画） | 金色圆片，闪烁高光 |
| 护盾罩 | 40×72 | 1（半透明叠加） | 蓝色半透明圆角罩 |

### 5.4 环境与装饰

- **道路**：3 车道，路面铺"细碎石噪点"，两侧白色实线 + 草地
- **动态元素**：道路边缘的道钉/灯杆以 2 帧闪烁向后移动，营造速度感
- **背景远景**：山丘、太阳、云朵以 0.3 倍速横向视差滚动
- **天气/时段**（可选彩蛋）：每 2000 米切换一次"黄昏/夜晚"色调，夜晚上路灯亮起
- **速度线**：速度 ≥ 400px/s 时在屏幕上下边缘出现白色速度线粒子

### 5.5 屏幕特效
- 撞击：全屏红色边框闪烁 + 白色闪光
- 拾取金币：金币位置爆出 4 个金色粒子
- 道具拾取：道具图标放大 1.5 倍后缩回
- 加速：屏幕两侧出现放射状光线 + 轻微 FOV 拉伸感
- 撞车瞬间：慢动作 0.3s（time-scale 0.2）再恢复，增强打击感

### 5.6 字体与 UI 风格
- 使用像素字体（如 "Press Start 2P" 或内置 8×8 位图字库）
- 按钮：双层描边像素按钮，按下时整体下移 2px 并变暗
- 角标：界面四角带"胶片打孔"装饰，强化复古感

## 6. 音效方案

### 6.1 技术方案
- 全部音效采用 **Web Audio API 程序化合成**（无外部音频文件），保证体积小、加载快、风格统一。
- 通过振荡器 + 包络（ADSR）+ 低通滤波合成 8-bit 风格音色。
- 背景音乐：程序化生成的循环乐句（低音行进 + 方波主旋律），2 个段落（普通/疯狂）无缝切换。
- 音量分级：主音量 / 音效 / 音乐 三档独立滑杆（默认各 100%）。

### 6.2 音效清单（SFX）

| 事件 | 波形 | 频率/时长 | 效果描述 |
|---|---|---|---|
| 金币拾取 | 方波 | 987Hz→1319Hz，80ms | 清脆上滑"哔" |
| 连击达成 | 方波 | 1319Hz→1568Hz，120ms | 高亢双音 |
| 撞击 | 锯齿波+噪声 | 200Hz 下降，300ms | 沉闷碰撞 + 噪声爆裂 |
| 拾取道具 | 正弦+方波 | 523Hz→784Hz→1046Hz，250ms | 三连上升音 |
| 使用道具（护盾） | 三角波 | 440Hz→880Hz，200ms | 柔和的充能"呜" |
| 使用道具（加速） | 锯齿波 | 220Hz→880Hz 扫频，350ms | 引擎嘶吼 |
| 生命扣减 | 方波 | 440Hz→220Hz，150ms | 下降"嘟" |
| 游戏结束 | 方波+三角波 | 下行三连音，1s | 悲壮落幕 |
| 按钮点击 | 方波 | 800Hz，40ms | 短促"咔" |
| 暂停 | 三角波 | 660Hz 双响，80ms | "叮叮" |
| 速度档位上升 | 方波 | 300Hz 上滑 100ms | 提示新难度 |
| 金币连串结束 | 三角波 | 660Hz 下滑，100ms | 提示本串结束 |

### 6.3 背景音乐（BGM）设计

**风格**：8-bit Chiptune（方波主旋律 + 三角波低音 + 噪声打击）。

- **普通段**（速度 < 360）：C 大调，BPM 120，4 小节循环，情绪轻快。
- **疯狂段**（速度 ≥ 360）：升到 F# 小调，BPM 150，加入噪声军鼓与更密集的低音，情绪紧张。
- **切换方式**：在 2 小节过渡小节内淡出淡入（crossfade 0.5s），避免生硬。
- **结束音**：游戏结束时播放 2 小节尾声下行乐句后停止。

### 6.4 音量与混音原则
- 音效峰值 -6dB，音乐峰值 -12dB（音效始终压过音乐）。
- 高频（≥6kHz）适度衰减，模拟 NES 喇叭的"闷响"质感。
- 所有音效在撞车/游戏结束时刻自动 duck（音乐音量降 50%，持续 1.5s）。

## 7. 数值平衡参考

| 参数 | 基准值 | 说明 |
|---|---|---|
| 玩家初始生命 | 3 | 可选项：金币满 100 加一条命 |
| 撞车惩罚 | -1 生命 + 1.5s 无敌 | 不扣分数，避免挫败感过强 |
| 金币价值 | 10 分/枚 | |
| 每 100 金币 | +1 生命（上限 5） | 正向激励长局玩家 |
| 单局理想时长 | 90~180 秒 | 玩家在第 600m 前后进入心流峰值 |
| 最高分记录 | localStorage 持久化 | 标题与结算界面展示 |
